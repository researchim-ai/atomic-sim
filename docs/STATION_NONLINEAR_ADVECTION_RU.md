# Нелинейная адвекция, взаимодействие мод и алиасинг v75

Дата: 17 ноября 2026.

После [граничных проверок v74](STATION_WALL_MOMENTUM_RU.md) реализован
`atomic_model_station_advection`: пространственное ядро нелинейного
члена `N=(u·grad)u` для реального поля в цилиндрической трубе.

Есть две реализации: прямая свёртка Fourier-мод и псевдоспектральное
вычисление на дополненной FFT-сетке. Проверены геометрические члены,
обмен энергией между модами, связь с Galerkin-нагрузкой и независимое
центробежное равновесие.

**Принято выбранное нелинейное пространственное ядро. Нелинейный
интегратор по времени ещё не реализован и не квалифицирован.**
Станционный и внешний backend не изменены.

## Поле и цилиндрическая геометрия

Используется полный знаковый спектр мод `exp(i*m*theta+i*alpha*k*z)`.
Для реального поля коэффициенты удовлетворяют условию:

```text
u(-k,-m) = conjugate(u(k,m))
```

Оно проверяется для скоростей и радиальных производных. Средняя мода
должна быть действительной. `signed_spectrum` строит такой спектр из
канонических регулярных мод v72; радиальные производные вычисляются
аналитически средствами v74.

Для каждой пары мод p и q, вносящей вклад в p+q:

```text
N_r     = ur_p*d_r(ur_q) + ut_p*i*m_q*ur_q/r
          + uz_p*i*alpha*k_q*ur_q - ut_p*ut_q/r
N_theta = ur_p*d_r(ut_q) + ut_p*i*m_q*ut_q/r
          + uz_p*i*alpha*k_q*ut_q + ut_p*ur_q/r
N_z     = ur_p*d_r(uz_q) + ut_p*i*m_q*uz_q/r
          + uz_p*i*alpha*k_q*uz_q
```

Последние геометрические члены первых двух компонент необходимы.
Их знаки проверены по независимому расчёту адвекции в декартовых
координатах через конечные разности физического поля.

Поточечные произведения вычисляются только при r>0. Ось не заменяется
малым положительным числом. В этой версии используется положительная
радиальная квадратура; оценка предельного нелинейного значения на оси —
отдельная задача для дальнейшего сильного аудита.

## Прямая свёртка и достаточное FFT-дополнение

Прямая реализация суммирует пары мод без циклического заворачивания частот.
Её результат служит независимым эталоном для FFT-реализации.

FFT-реализация строит физическое поле, его радиальную, угловую и осевую
производные, вычисляет нелинейный член в физических точках и преобразует
его обратно. Нормировки прямого и обратного преобразований заданы явно.

Если вход ограничен |k|≤K, |m|≤M, а требуемые выходы — |k|≤Kt, |m|≤Mt,
достаточно:

```text
Nz > 2*K + Kt
Ntheta > 2*M + Mt
```

Это достаточное условие по охватывающим полосам спектра. Оно предотвращает
попадание циклически завёрнутых продуктов в запрошенные выходные моды.
Для сохранённой входной полосы Kt=K получается Nz>3K. Для всего квадратичного
спектра Kt=2K требуется Nz>4K. Аналогично по азимутальному направлению.

Например, при K=M=2 вход представим на сетке 5×5, сохранённые моды требуют
7×7, а полный квадратичный спектр — 9×9. Недостаточное дополнение по
умолчанию отклоняется. Его можно явно разрешить только для диагностики;
квитанция отмечает отсутствие гарантии против алиасинга.

## Проверка энергии и реального обмена между модами

Для полного знакового спектра вычисляются:

```text
E = 1/2 sum_modes integral |u_mode|² r dr
P_adv = sum_modes Re integral conjugate(u_mode)·N_mode r dr
```

У регулярного несжимаемого поля с прилипанием и периодическими
направлениями P_adv должен быть нулевым. Объёмные множители здесь
не включены; кратности уже учтены полным знаковым спектром.

Проверка содержит шесть наборов с полосами 1/2, порядками регулярного
базиса 3–6 и радиальными квадратурами 32/64/96. В наиболее полном входе
25 знаковых мод. Отдельные моды действительно отдают и получают энергию;
не принимается тривиальный случай нулевого нелинейного взаимодействия.

Результаты:

- Прямая свёртка и дополненный FFT: максимальная ошибка коэффициентов
  **4,026·10⁻¹⁸**.
- Максимальный модуль суммарной мощности адвекции: **8,590·10⁻²¹**.
- Расхождение мощности после передачи нагрузки `-N` в регулярный
  Galerkin-базис: **1,761·10⁻²¹**.

Энергия не исправляется после вычисления. Результат обеспечивается
операторами и проверенной квадратурой. Сохранение энергии не доказывает
достаточность числа мод для произвольного течения: для этого потребуется
пространственная квалификация будущей динамики.

## Сохранённый отрицательный пример

На той же входной полосе K=M=2 при сетке 5×5, явно разрешённой для
диагностики, получены:

```text
ошибка нелинейных коэффициентов = 8,92110e-4
ложная мощность адвекции        = 3,19176e-7
```

Обычный вызов отказывается выполнять этот расчёт. Отрицательный пример
сохранён отдельно от принятых дополненных FFT-случаев.
Тест с намеренно неверными коэффициентами не проходит приёмку даже при
подложенном флаге «сетка достаточна».

## Независимое центробежное равновесие

Для стационарного невязкого вихря:

```text
ur=uz=0, ut=r(1-r²)
N_r=-r(1-r²)², N_theta=N_z=0
p=r²/2-r^4/2+r^6/6-1/8
```

Градиент давления компенсирует центробежный член: `grad(p)+N=0`.
Постоянная 1/8 задаёт нулевое среднее кинематическое давление.
Давление восстановлено алгоритмом v73 из вычисленной нагрузки `-N`.

Ошибка давления — **3,748·10⁻¹⁶**, ошибка баланса — **5,912·10⁻¹⁵**.
Это один независимый стационарный нелинейный эталон; он не объявляется
приёмкой вязкой турбулентной траектории или нелинейного шага по времени.

## Ограничения API

Входные целочисленные частоты ограничены |k|,|m|≤8, полный вход — не более
81 моды; запрошенные выходы ограничены |k|,|m|≤16 и 1089 модами.
Радиальная сетка содержит 2–512 строго положительных точек до r=1.
Для FFT отдельно ограничены размеры сетки и объём рабочего набора.
Неконечные поля, неполный сопряжённый спектр и недостаточная сетка
отклоняются. Передача только половины спектра в энергетическую проверку
не допускается.

Общий массивный API не доказывает согласованность произвольно заданной
радиальной производной со скоростью. Приёмочная матрица использует
аналитические регулярные поля и независимые геометрические эталоны.
Точность радиальной квадратуры проверяется отдельно от Fourier-дополнения:
FFT-дополнение не исправляет радиальную ошибку интегрирования.
