# Смешанная конвекция: ветви уравнения и радиальный эталон

Продолжение: [переходный радиальный benchmark v65](STATION_PIPE_BENCHMARK_RU.md). Нормировки и аналитическая база опубликованного примера воспроизведены отдельно; DNS и станционное замыкание пока не приняты.

Блок `atomic_model_station_mixed` добавляет проверяемые исследовательские
инструменты для следующего этапа теплоотдачи. Это самостоятельный компонент:
нового значения `film_model` для станции он не вводит. Станционная физика,
траектории и доказательства v63 сохранены. Полный выбег 1800 с пока не принят;
план остаётся на **48/76**, NPP-11.03/04 и общая R1 открыты.

## Почему недостаточно выбрать другую формулу Nu

Значимы направление потока относительно плавучести, тепловое условие стенки,
геометрия и температура, при которой вычислены свойства. Восходящий нагреваемый
поток может испытывать подавление турбулентного переноса; для нисходящего
нагреваемого потока механизм иной. Такое поведение обсуждается в главе 6.5
[IAEA-TECDOC-1746](https://www-pub.iaea.org/MTCD/Publications/PDF/TE-1746_web.pdf),
печатные страницы 177–179. Формулы сверены по изображению страницы 178,
а не только по распознанному тексту PDF.

Поэтому модуль раздельно проверяет алгебру нелинейной модели, независимый
ламинарный эталон и применимость опубликованных диапазонов. Ни одна из этих
проверок сама по себе не разрешает продолжать станционный расчёт.

## Явные ветви неявного уравнения

Реализовано уравнение 6.9 указанного отчёта, с явно выбранными приведёнными
в нём оценочными коэффициентами:

```
r = Nu / Nu_forced
r = |1 ± 100000 Bo_q r^(-2.1)|^0.46
Bo_q = Gr_q / (Re^3.425 Pr^0.8)
Gr_q = g beta q_wall D^4 / (k nu^2)
```

Минус относится к восходящему нагреву, плюс — к нисходящему.
Это конкретная версия уравнения: коэффициенты других публикаций и ветви
его иллюстративного графика не используются для подгонки.

Для восходящего случая существуют три положительных корня в части области.
API требует ветвь `upper`, `middle` или `inverted`; для нисходящего случая —
`unique`. Вынужденный предел верхней и единственной ветвей точно равен 1.
Нулевые пределы других преобразованных ветвей не принимаются как корни
исходного уравнения, содержащего отрицательную степень r.

Из уравнения аналитически находится точка слияния верхней и средней ветвей:
**Bo_q=2,56036992149·10⁻⁶**, **r=0,72117566212**. Это особенность выбранного
алгебраического уравнения, а не экспериментально определённая граница режима.
На ней чувствительность не возвращается как бесконечное число. Запрос
завершившейся ветви отклоняется через `mixed_branch_fold`; автоматического
перехода на инвертированную ветвь нет. Устойчивость ветвей, правило перехода
и гистерезис требуют отдельного физического обоснования.

Численное окно исследования: Bo_q=0 либо 10⁻¹⁰≤Bo_q≤10⁻³. Оно не объявляется
экспериментально подтверждённой областью. Проверяются исходное и устойчиво
преобразованное уравнения, производная и корни по отдельному обратному эталону
на 60-разрядной десятичной арифметике. Дополнительно проверен весь выбранный
логарифмический набор параметров, включая соседние числа у точки слияния.

## Радиальный эталон с совместным решением импульса и энергии

Другой инструмент решает стационарную осесимметричную задачу для гладкой
вертикальной трубы с постоянными свойствами и приближением Буссинеска.
Течение и температура считаются полностью развитыми, тепловой поток стенки
постоянен. Турбулентная вязкость, входной участок, осевая теплопроводность
и устойчивость течения не моделируются.

При x=r/R, v=u/Umean, theta=(T−Twall)k/(q_wall R):

```
L(v) + A + B theta = 0
L(theta) = 2v
L(f) = (1/x) d[x df/dx]/dx
integral_0^1 v x dx = 1/2
B = ± g beta q_wall R^3 / (k nu Umean) = ± Gr_q/(8 Re)
```

Знак B задаётся направлением потока. Совместно определяются скорость,
температура и градиент давления A при заданной средней скорости. В центре
действует симметрия, на стенке — прилипание. Условие theta(1)=0 задаёт
температурную шкалу относительно стенки: это **не** условие постоянной
температуры стенки вдоль оси. В полностью развитом UHF-режиме температуры
стенки и смешанного потока растут вдоль оси с одинаковым градиентом.

Конечно-объёмная схема использует веса настоящих кольцевых ячеек и сохраняет
интегральные уравнения. Проверяются средний расход, стеночный тепловой поток,
невязки импульса, энергии и положительная квадратичная форма температурного
градиента. Последняя не называется размерным производством энтропии:
абсолютная температурная задача здесь не задана.

Вынужденный предел проверен по профилю Пуазейля, f_D Re=64 и Nu=48/11.
Последнее значение относится к равномерному тепловому потоку;
[исходное исследование ламинарной теплоотдачи](https://experts.umn.edu/en/publications/steady-laminar-heat-transfer-in-a-circular-tube-with-prescribed-w/)
рассматривает именно такую постановку, в отличие от постоянной температуры
стенки. Независимый численный эталон использует `solve_bvp`, сингулярное
условие на оси, дополнительную интегральную координату расхода и адаптивную
квадратуру смешанной температуры. Конечно-объёмные веса в него не входят.

Для B=−40, 0, 40, 200 выполнены сетки 64, 128, 256. Максимальное относительное
расхождение Nu на наиболее подробной сетке — **7,47316·10⁻⁵**, минимальный
наблюдаемый порядок — **1,99923**. На сетке 512 ошибки вынужденного предела:
Nu — 2,77431·10⁻⁶, f_D Re — 3,81468·10⁻⁶; максимальная абсолютная ошибка
нормированного профиля Пуазейля — 5,72202·10⁻⁶.

В случаях B=−100 и 500 оба метода обнаружили локальное обратное течение
при положительной средней скорости. Конечно-объёмный адаптер его отклоняет
через `local_forward_velocity`; средний расход не используется для сокрытия
обращения профиля. Наличие полностью развитого ламинарного решения
не доказывает его устойчивости. Выбранное окно Re=1–2000, Pr=0,6–200,
|B|≤1000 ограничивает исследование; оно не заменяет критерий перехода.

Этот эталон показывает также, почему его нельзя использовать вместо
турбулентной теплоотдачи станции: ответ ламинарной задачи на помогающую
плавучесть отличается от ответа верхней турбулентной ветви.

## Проверка пригодности к состоянию станции

В поставку включён небольшой замороженный фрагмент численного checkpoint
v63 на 1475 с. Его исходный SHA256 сверяется с публичной квитанцией v63.
Это данные расчёта, **не измерения**; новая станционная траектория из них
не создаётся. В старой геометрии плёнки ориентация не задана, поэтому
восходящее и нисходящее направления исследуются как явные гипотезы.

Диапазоны для нисходящего нагрева взяты из таблицы 2 и условий раздела 2
[Motegi и соавт., 2024](https://onlinelibrary.wiley.com/doi/10.1155/2024/6029412).
Вычисления при объёмной и плёночной температурах разделены. Для состояния
v63 получено Re_bulk≈5692,90, Pr_bulk≈0,843792, Re_film≈5710,96,
Pr_film≈0,842836, Gr_film≈3,23740·10⁵, Ra_film≈2,72859·10⁵.

Даже при гипотезе нисходящего нагрева:

- Jackson–Fewster не проходит опубликованный диапазон Pr_bulk=2,5–7.
- Aicher–Martin не проходит Ra_film=3·10⁷–10⁹.
- Churchill не проходит приведённые диапазоны Re_film, Gr_film и Pr_film.

Для восходящего нагрева дополнительно не совпадает направление всех этих
конкретных формул. Прохождение отдельных пределов всё равно означало бы
только возможность сравнения с опубликованным диапазоном. Прямоугольник
маргинальных Re/Pr/Gr не доказывает совместного экспериментального покрытия,
совпадения геометрии, теплового условия, развития потока или неопределённости.
Станционная смешанная температура узла также не подменяет измеренное среднее
между входом и выходом экспериментального канала.

Ламинарный эталон отклоняет станционное Re>2000. Три корня уравнения МАГАТЭ
для сохранённого теплового потока выводятся только как диагностика: они
не образуют согласованное новое решение при прежних Tw и Tb и не разрешают
подменить замыкание станционной плёнки.

## Воспроизведение

```bash
python -m pytest tests/test_station_mixed_convection.py tests/test_station_mixed_qualification.py
python -m scripts.qualify_station_mixed_convection --output artifacts/my-mixed-study
python -m scripts.verify_local_library --output artifacts/my-library --phase-timeout-s 7200
python -m scripts.verify_station_mixed_delivery --output artifacts/my-installed-mixed --source-evidence artifacts/my-mixed-study --library-evidence artifacts/my-library
```

Квалификатор создаёт пять научных JSON: протокол, корни, радиальные задачи,
проверку применимости и сводку. Независимый повтор из установленного wheel
выполняет расчёты заново в свежем `Python -I` вне checkout и сравнивает все
пять файлов точно. Установка повторно использует локальные зависимости
офлайн. Эксплуатационные квитанции времени процессов отделены от научных
данных. CI и внешний runner не требуются.

Следующий станционный этап — выбрать и проверить закон для **восходящего
турбулентного нагрева** в фактическом диапазоне свойств, явно определить
ориентацию/геометрию и правило выбора ветви, затем согласовать его с сетевым
импульсом и повторить полные 1800 с. Нынешние исследовательские инструменты
проверяют необходимые части этой работы, но NPP-11.03 не закрывают.

Для следующего независимого сравнения при малом Pr найден подходящий
исследовательский ориентир: [Marensi, He, Willis, 2021](https://doi.org/10.1017/jfm.2021.371)
рассматривают подавление турбулентности в восходящей нагреваемой трубе,
включая расчёты при Re=5300 и Pr=0,7. Их периодическая осевая постановка
с фиксированным температурным условием отличается от нашего UHF-эталона.
Поэтому прямое сравнение Nu сейчас было бы некорректно. Сначала нужно
отдельно воспроизвести их нормировки, тепловую постановку и ламинарный
контрольный предел, затем переносить численные данные и оценивать
неопределённость сравнения. Это кандидат для последующего benchmark,
а не выполненная DNS-проверка v64. Для применения к выбегу также требуется
оценить время установления профиля относительно времени изменения режима.

## Квалификация и поставка v64

Итоговый локальный профиль прошёл **2018/2018 тестов без пропусков**,
включая 49 новых проверок этого блока, и все восемь этапов поставки.
Повтор из wheel в свежем `Python -I` вне checkout заново вычислил четыре
радиальные задачи, корни и проверку применимости: **все пять научных JSON
совпали точно**. Проверены байты 770 Python-модулей/скриптов и комплектность
ресурса с численным фрагментом checkpoint.

[Машинная квитанция v64](benchmarks/station_mixed_convection_v64.json)
содержит параметры уравнения, результаты сравнения, источник фрагмента v63,
его сверку с исходным checkpoint, SHA256 первичного PDF и квитанций поставки.
Результаты v63 сохранены, отпечаток исходников станционного backend совпал
с прежней приёмкой. Длинный станционный прогон здесь заново не выполнялся:
выполнено отдельное исследование математических инструментов. **Новый
станционный закон смешанной конвекции не принят; счётчик остаётся 48/76,
открыто 28 задач.** Экспериментальная валидация и полная R1 не заявлены.
