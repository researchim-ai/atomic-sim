# Реестр замыканий

| Идентификатор | Формула | Область | Статус |
| --- | --- | --- | --- |
| `if97-region-1-2-4` | IAPWS-IF97, области 1, 2 и насыщение | релиз 2007 до границы области 3 | verified по контрольным точкам |
| `if97-region-3-5` | фундаментальные уравнения областей 3 и 5 | однофазные состояния релиза IF97 | verified по точкам rho=500 кг/м³, 650 K и 1500 K |
| `iapws-2008-viscosity` | вязкость без критической добавки | обычная вода, rho и T > 0 | verified в точке 998 кг/м³, 298.15 K |
| `iapws-2011-conductivity` | теплопроводность без критической добавки | обычная вода | implemented, точка есть в коде поставщика формул |
| `dittus-boelter-heating` | Nu = 0.023 Re^0.8 Pr^0.4 | Re ≥ 10000, 0.7 ≤ Pr ≤ 160, нагрев | verified как формула |
| `laminar-nusselt-3.66` | Nu = 3.66 | Re < 2300, развитый поток | verified как формула |
| `incompressible-orifice` | m = Cd A sign(dp) sqrt(2 rho \|dp\|) | однофазная жидкость, малый перепад к модулю объёмного сжатия | verified |
| `ideal-gas-choke` | критический расход изоэнтропийного сопла | идеальный газ | verified по формуле и независимости от противодавления ниже порога |
| `pump-inertia` | J dw/dt = M_drive - M_hyd - M_loss | ω ≥ 0, расход вперёд | verified |
| `pump-polynomial-four-quadrant` | a1 W\|W\| + a2 W F + a3 F\|F\| | все знаки расхода и скорости этой полиномиальной модели | verified; это не заводская гомологическая кривая |
| `turbine-constant-eta` | постоянный изоэнтропийный КПД до давления конденсатора | расширение остаётся в двухфазной области конденсатора | verified по балансу энергии номинала |
| `drum-separator` | идеальное разделение фаз | обе фазы присутствуют | verified по уровню и останову при потере фазы |
| `heat-exchanger-wall` | C dT/dt = UA_p (T_p - T_w) - UA_s (T_w - T_s) | постоянные UA, заданные температуры контуров | verified по стационару и экспоненте |
| `dynamic-condenser` | давление из (rho, u) при фиксированном объёме | масса > 0, область IF97 | verified по изохоре и двухфазному восстановлению; паспорт ВВЭР не использует |
| `generator-swing` | J dw/dt = M_mech - M_elec | одна машина, положительная скорость | verified |
| `uo2-fink-2000` | теплопроводность Fink, 2000 | 298–3000 K | verified в точке 1000 K по записи формулы |
| `gap-conduction-radiation` | k/gap + излучение | открытый зазор | implemented; контакт не моделируется |
| `iodine-xenon` | цепочка I/Xe | постоянный поток на шаге, учебные выходы | verified против expm |
| `decay-heat-3g` | три экспоненты, равновесная доля 6.5% | не ANS-5.1 | verified по балансу энергии групп |
| `cram16-ipf` | неполная частичная факторизация CRAM16 | линейная цепочка с постоянной матрицей | verified против матричной экспоненты |

Вне таблицы замыкание не подставляется «по похожести».
