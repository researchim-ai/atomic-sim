# Согласованное стационарное состояние MUSCL с полной энергией

Дата: 31 октября 2026.

## Что изменено

`equilibrated_total_config` поддерживает `enthalpy_transport="muscl_mc"`
для `energy_formulation="compatible_total"`. Стационарный профиль решает
уравнения той же дискретной схемы, которая используется при интегрировании.
Донорный профиль служит начальным приближением. Для обратного потока
применяется прежнее отражение геометрии и резервуаров.

Это устраняет конкретную ошибку подготовки начальных условий: донорный
нагретый профиль при простом переключении на MUSCL не является равновесием.
На тестовой трубе его начальная энергетическая невязка превышает 100 Вт;
после уточнения она проходит допуск 1e-3 Вт по каждой ячейке.

Новый модуль: `physics/hydraulics/muscl_initialization.py`.
Старый донорный путь, его значения по умолчанию, snapshot schema и физические
уравнения динамики сохранены. Изменена подготовка IC, не паспорт физики.

## Решаемая система

На равномерной трубе неизвестны n давлений, n температур и единый
положительный расход F. Для обратной задачи сначала отражаются координаты.
Плотность и энтальпия вычисляются IF97 region 1. На соединениях используется
донорная плотность, как в производственной механике; на интерфейсах —
реальная MC-реконструкция энтальпии с теми же правилами входа и выхода.

```text
Delta p_j - zeta_j F²/(2 rho_donor,j A²) = 0       (n+1 уравнений)
Phi_i - Phi_i+1 + P/n = 0                        (n уравнений)
Phi_j = F [h_MUSCL,j + (F/(rho_donor,j A))²/2]
Tw_i = Tf_i + P/UA_total
```

При одинаковых расходах массы стационарны. При выполненных уравнениях
импульса производная кинетического запаса равна нулю, поэтому эта система
соответствует стационарной полной энергии производственного RHS.
Смещение стенки для теплового импульса добавляется **после** приёмки
невозмущённого равновесия, один раз.

Используется ограниченный `scipy.optimize.least_squares` с трёхточечной
разностной производной, линейной функцией потерь, масштабированными
невязками импульса и энергии. Остановка оптимизатора и малый градиент
не означают выполнения физических уравнений — см.
[официальную документацию SciPy](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html).

После поиска создаётся настоящий `DynamicWallChannel`, вызывается полный
RHS с обращением EOS, кинетическими работами, MC-гранями и проверками
паспорта. Независимые абсолютные критерии:

- производная расхода каждого соединения <=1e-6 кг/с²;
- производная внутренней энергии каждой ячейки <=1e-3 Вт;
- производная температуры стенки <=1e-9 К/с.

Если они не пройдены, возвращается `DomainError`, даже если оптимизатор
сообщил об успехе. Это отдельно проверено внедрённым ложным успехом.
Никаких проекций состояния или фиктивных прошлых интегралов нет.

## Применение

```bash
python -m scripts.generate_total_energy_case \
  --transport muscl_mc --heat-w 3000 --sign -1 --output /tmp/muscl_reverse.json
atomic-dynamic-experiment /tmp/muscl_reverse.json --output /tmp/muscl_reverse_run
```

Генератор принимает `--transport donor|muscl_mc` и `--heat-w`.
Нагрев сохраняется в течение сценария; wall_pulse добавляет к равновесной
стенке 2 К. Прежние значения по умолчанию — donor и 0 Вт.

## Проверки и ограничения

Новые 19 тестовых случаев включают сетки 3/8/16, оба знака потока,
0/3000 Вт, несимметричные сопротивления, разные температуры резервуаров,
точный snapshot roundtrip, смещение стенки, интегрирование BDF/Radau,
отклонение ложного успеха и недопустимых входов. Отдельный воспроизводимый
аудит `scripts/verify_muscl_equilibria.py` сохраняет размерные невязки
12 равновесий, критерии и runtime fingerprint.

Три полных нагретых перехода (3000 Вт, импульс стенки +2 К, 8 с)
завершены: прямой, обратный и прямой с ужесточённой точностью.
Оба энергетических бюджета пройдены. Временное сравнение использует
прежние критерии из `validation/batch12_temporal_budget.json`:
максимальная разница давления 0.09914 Па при допуске 1 Па,
расхода 7.30e-8 кг/с при допуске 1e-4 кг/с. Зеркальная проверка даёт
0.00533 Па и 5.00e-9 кг/с; все её критерии также пройдены.
Это отдельные временные и симметрийные проверки, не измерение порядка
пространственной сходимости. Свидетельства:
`validation/muscl_total_heated_temporal_v1.json` и
`validation/muscl_total_heated_reflection_v1.json`.

Поиск локальный, с донорным стартом; существование, единственность и
нахождение всех стационарных решений не доказаны. Область поиска расхода:
0.01–100 донорной оценки; температуры 273.15–623.15 К; давления до 100 МПа.
Ограничения IF97, жидких граней и Mach проверяются дополнительно.
Недопустимая термодинамическая проба отклоняется, глобальный поиск по
раздельным допустимым областям не реализован. Нелинейный MC-ограничитель
имеет кусочные производные. Сильное возмущение и близость к кипению могут
привести к контролируемому отказу подготовки IC.

Стационарная сходимость уравнений не доказывает пространственную точность
нестационарной полной энергии. Конвекция импульса, двухфазные замыкания,
акустическая/энтропийная квалификация и независимые данные установки
остаются открытыми.
