# Первое сравнение с опубликованным физическим экспериментом

Дата: 5 ноября 2026. Статус: воспроизводимое экспериментальное сравнение ограниченного режима; полная физическая валидация открыта.

## Что сравниваем

Существующее замыкание `physics.hydraulics.closures.friction_darcy` использует формулу Хааланда. Проверяем безразмерный коэффициент Дарси по измерениям прямой медной трубы из [NIST TN 2294, рисунок 18](https://doi.org/10.6028/NIST.TN.2294): диаметр 20,11 мм, принятая в отчёте оценка шероховатости 0,0015 мм. Сохранены 38 маркеров четырёх повторных серий; диапазон оцифрованных центров Re примерно 14 296–100 594.

Это проверка однофазного стационарного гидравлического сопротивления. Теплообмен, кипение, реакторная кинетика, переходные процессы и вся установка этим опытом не проверяются. Коэффициенты исходной модели не изменялись.

## Воспроизведение

После установки проекта:

```bash
atomic-model-validate run-pipe --output artifacts/my-nist-pipe
atomic-model-validate verify artifacts/my-nist-pipe
```

Без установки entry point:

```bash
python -m atomic_model_validation run-pipe --output artifacts/my-nist-pipe
python -m atomic_model_validation verify artifacts/my-nist-pipe
```

Результат содержит `report.json`, график `comparison.png`, исходные данные и хеш-манифест. Повторная проверка исполняет текущий native-код, заново вычисляет коэффициенты и ошибки и сравнивает весь численный отчёт. Изменение замыкания или инструмента требует нового результата; старый отчёт не получает новую квалификацию автоматически. Ошибка критерия возвращает код 2.

Независимое повторное извлечение маркеров требует `pypdf`, включённого в dev-зависимости:

```bash
python -m atomic_model_validation.digitize atomic_model_validation/data/nist_tn2294/source.pdf --output /tmp/nist-vectors.json
```

Тест сравнивает результат с замороженным `vectors.json`. CSV вычисляется из векторных координат; легенда исключена по фиксированной области, остальные маркеры сохранены независимо от отклонения модели. Исходная страница визуально проверена.

## Критерий и результат

До первого вычисления модели зафиксирован допуск максимальной относительной ошибки **5%** для каждого центра маркера, включая каждую повторную серию. Это выбранный нами инженерный screening-критерий, не критерий NIST и не метрологическая неопределённость.

Максимальная абсолютная относительная ошибка — **2,5613%**. По сериям: 2,5613%; 0,8221%; 2,4688%; 1,0627%. Все центры проходят критерий. Полная точность значений и остатки каждого маркера сохранены в отчёте.

Для проверки вызывается именно `friction_darcy`; результат переводится обратно в коэффициент Дарси и сверяется с прямым вызовом корреляции. Плотность и вязкость здесь служат явно синтетической нормировкой безразмерного результата. Они не являются восстановленными измерениями установки. Расчёт не заявляет экспериментально проверенный перепад давления в Па.

## Что известно о неопределённости

Читаем центр ограничивающего прямоугольника векторного символа. Для каждой оси сохраняем полный полупоперечник символа плюс небольшой запас на округление координат. Это консервативные границы чтения рисунка. Они не учитывают все ошибки приборов, геометрии и оценки шероховатости и не являются доверительными интервалами. Расположение треугольного символа также входит в этот запас.

Влияние координатных границ считается отдельно: варьируем Re в границах чтения и сравниваем интервал модели с границами чтения коэффициента. Наличие пересечения не может превратить отказ основного критерия в успех.

Полного бюджета экспериментальной неопределённости для каждой точки в этом пакете нет. Полоса ±3% исходного рисунка относится к сравнению с Colebrook; она не присваивается измерениям как погрешность. Не выдаём число прошедших маркеров за вероятность достоверности модели.

## Происхождение и ограничения

Исходный PDF сохранён без изменений, рядом находятся NOTICE, протокол, векторные координаты, CSV и SHA-манифест. Условия переиспользования указаны по [официальной политике NIST](https://www.nist.gov/open/copyright-fair-use-and-licensing-statements-srd-data-software-and-technical-series-publications); они отделены от лицензии нашего кода. Republished courtesy of the National Institute of Standards and Technology.

Файл содержит оцифрованные опубликованные измерения, а не исходные записи датчиков. Четыре серии не считаются четырьмя независимыми физическими установками. Независимость от исторических данных, использованных при создании корреляции Хааланда, не установлена. Подгонки на этих данных не выполняли.

`validated=false` и `plant_referenced=false` сохраняются. Следующие этапы: исходные машинные таблицы с полной неопределённостью, независимый набор с другими условиями и системный переходный эксперимент. AI-09.02 переведён в работу, а не закрыт целиком.
