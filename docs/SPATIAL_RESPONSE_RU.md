# Прямая, сопряжённая задачи и чувствительности зоны — v109

[English](SPATIAL_RESPONSE_EN.md)

Добавлен пакет `atomic_model_spatial_response`. Он расширяет существующую одномерную многогрупповую FV-модель статическим сопряжённым решателем и локальными производными коэффициента размножения. Исходная сборка операторов и станционный интегратор сохранены.

## Математический контракт

Для собранных матриц потерь A и рождения F решаются:

`A φ = F φ / k`, `Aᵀ ψ = Fᵀ ψ / k`.

Используется сопряжение **дискретной** задачи. Объёмы одномерных ячеек уже входят в A и F; второй множитель ширины в скалярном произведении не добавляется. Нормировка пары — `ψᵀ F φ = 1`. По умолчанию прямая функция также нормирована условием `sum(F φ)=1`.

Дифференцирование обобщённой собственной задачи даёт:

`dk = ψᵀ (k dF − k² dA) φ / (ψᵀ F φ)`.

Метод сопряжения многогрупповых переносов и малых возмущений описан в первоисточнике: Bell, Glasstone, *Nuclear Reactor Theory*, [разделы 6.2–6.3](https://digital.library.unt.edu/ark:/67531/metadc870144/m1/291/ocr/). Формулы локальных производных здесь выведены для конкретных матриц существующей FV-сборки.

Поддержаны производные по `nu_fission_per_m`, `absorption_per_m`, `scatter_per_m` и `diffusion_m`. При изменении межгруппового рассеяния учитываются одновременно поступление в целевую группу и удаление из исходной. Индексация — `[to, from, cell]`; диагональное рассеяние не является параметром модели, нули в этих позициях — заполнители.

Для диффузии дифференцируется гармоническая проводимость каждой внутренней грани, включая вклад обоих соседних коэффициентов. На границах с нулевым потоком учтена производная граничной утечки; отражающие границы её не добавляют. Поэтому отклик применим и к неравномерной сетке с разрывными коэффициентами.

Геометрия, тип границ, спектры, доли и постоянные распада предшественников и скорости нейтронов при этих производных фиксированы. Это локальный первый порядок по коэффициентам статического оператора, а не полная нелинейная оценка неопределённости или сопряжённая задача переходного процесса.

## Нормировка мощности

`power_weights_w` и `power_w` можно передать только совместно. Веса задают явную проекцию `sum(weights × φ)` в ватты. Прямой вектор масштабируется к целевой мощности, сопряжённый — обратно, сохраняя единичное спаривание и те же производные k.

Из `nu_fission_per_m` не выводятся неизвестные энергия одного деления или число нейтронов на деление. Физический смысл пользовательских весов должен быть обоснован отдельно.

`station_core_response` использует уже существующую проекцию мощности `DiffusionCore`, а не вводит новую модель тепловыделения. Проверяется суммарная мощность и отсутствие изменения checkpoint станционной сессии. Область адаптера — статический эталон при нулевых объёмной реактивности и осевом смещении. Ненулевое заданное осевое смещение отклоняется; отклик не является диагностикой текущего состояния работающей зоны. Локальная температурная обратная связь и связь отдельных каналов требуют следующих задач NPP-12.02/03.

## Использование

```python
from atomic_model_spatial import Model
from atomic_model_spatial.cases import slab
from atomic_model_spatial_response import sensitivities

model = Model(slab(7, heterogeneous=True))
result = sensitivities(model, tolerance=1e-12)
print(result["k"], result["gradients"]["diffusion_m"])
```

Анализ существующего пространственного владельца станции:

```python
from atomic_model_station import PWRCoreSession, CoreConfig
from atomic_model_spatial_response import station_core_response

session = PWRCoreSession(core=CoreConfig(kind="diffusion", cells=4))
result = station_core_response(session.neutron_core)
```

Требуется неразложимый связанный нейтронный оператор и положительная фундаментальная пара. Несвязанные подзадачи отклоняются; произвольная производная на вырожденной ветви не выбирается. Исчерпание итерационного бюджета, недопустимая нормировка или изменение исходников не дают принятого ответа.

## Воспроизведение проверки

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. .venv-layout/bin/python -m scripts.qualify_spatial_response --output artifacts/my-spatial-response
```

Фиксированы четыре синтетические постановки: однородная, разрывная на неравномерной сетке, отражающая и одноячеечная многогрупповая. Производные проверяются центральными разностями независимой плотной сборки. Дополнительно проверяются масштабные тождества рождения/потерь, независимая обобщённая сопряжённая задача и квадратичное уменьшение остатка линейного предсказания при малом возмущении.

Это вычислительная проверка на объявленных синтетических коэффициентах. Принятие численного отклика не является валидацией реальных сечений, стержневых банков или всей R2-конфигурации.

## Приёмка v109

Приняты четыре фиксированных постановки и статический адаптер существующей станции. Проверены 128 локальных производных; минимальный наблюдаемый порядок остатка линейного предсказания — 1.99804. Прямая и сопряжённая задачи, масштабные тождества и нормировка мощности прошли объявленные критерии. Checkpoint станции не изменился.

Общий прогон двух новых модулей и зависимостей — 153 теста. Из установленного wheel вне репозитория повторены 44 новых теста (29 для отклика, 15 для реестра данных), шесть расчётных JSON отклика и JSON реестра без исключения полей. Полный набор тестов библиотеки не запускался.

NPP-12.01 принят для статического дискретного отклика на объявленных синтетических коэффициентах. Пространственные обратные связи, банки, канальная динамика, реальные ядерные данные и R2 этим не принимаются. [Машинный протокол](benchmarks/spatial_response_v109.json).
