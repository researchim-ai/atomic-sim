# Паспорт: сосредоточенная установка ВВЭР

| Поле | Значение |
| --- | --- |
| model_id | `vver-lumped-loop` |
| версия | 2.0.0 |
| статус | verified |
| plant_referenced | нет |
| validated по измерениям блока | нет |

## Явление

Динамика одной эквивалентной петли водо-водяной установки: точечная кинетика, сосредоточенное топливо, четыре первичных объёма, компенсатор, парогенератор, турбина и конденсатор.

## Приближения

- Четыре петли заменены одной.
- Отметки первичных узлов совпадают, плавучесть контура в этот паспорт не входит.
- UA парогенератора согласован с номинальной точкой модели.
- Турбина имеет постоянный изоэнтропийный КПД.
- Обратные связи — редуцированные коэффициенты, нулевые в опорном состоянии.
- Групповые параметры запаздывающих нейтронов — учебный тепловой набор, не расчёт конкретного топлива.

## Область

Первичный контур без объёмного кипения. Вторичный контур в равновесной двухфазной области при давлении ниже границы области 3 IF97. Полный сброс пара до осушения конденсатора — `out_of_domain`.

## Эталоны

- Контрольные точки IF97.
- Матричная экспонента кинетики и inhour.
- Нулевая невязка правой части в номинале и удержание 0.5 с.
- Рост давления парогенератора и падение электрической мощности при частичном прикрытии турбины.
- Конечная скорость стержня после команды SCRAM.

## Данные

Ориентиры класса ВВЭР-1000 (около 15.7 МПа, 290/320 °C, 6.4 МПа на вторичной стороне) задают масштаб. Они не являются паспортом блока и не дают права на статус `plant_referenced`.
