# Полная двойственная геометрия жидкостного канала — v135

[English](FLUID_GEOMETRY_EN.md) · [Тепловая сетка](THERMAL_MESH_RU.md)

`FluidGrid(momentum_geometry="complete_dual")` включает граничные половины
ячеек в инерцию, потери давления и кинетическую энергию добавленного канала.
Режим доступен в `ChannelPWRSession` и наследующих стационарной и локальной
модераторной сессиях. Прежний режим называется `legacy` и остаётся выбором
по умолчанию. Команды приводов, владельцы расходов и ограничения модели
сохраняются.

```python
import numpy as np
from atomic_model_station import CoreConfig
from coupling.pwr_channel import FluidGrid
from coupling.pwr_fuel import FuelGrid
from coupling.pwr_moderator import LocalModeratorPWRSession

session = LocalModeratorPWRSession(
    core=CoreConfig(kind="diffusion", cells=4),
    fuel_grid=FuelGrid(tuple(np.linspace(0., 4., 9))),
    fluid_grid=FluidGrid(
        faces_m=tuple(np.linspace(0., 4., 5)),
        internal_loss_coefficient=1.,
        momentum_geometry="complete_dual",
    ),
)
geometry = session.snapshot()["momentum_geometry"]
```

В новом режиме историческое имя `internal_loss_coefficient` задаёт
суммарный дополнительный K **всего пролёта канала**, включая граничные
половины. В `legacy` оно по-прежнему относится только к внутренним связям.
Одноячейковый `complete_dual` допускает ненулевой K: потери распределяются
между двумя граничными половинами. Бюджет жидкости остаётся 1–8 ячеек.

## Что исправляет геометрия

Ранее добавленная инерция внутренних соединений покрывала расстояние от
центра первой ячейки до центра последней. При равномерном дроблении N ячеек
это `L*(1-1/N)`. Поэтому при смене N менялась не только дискретизация,
но и полная инерция добавленного канала. Для одной ячейки внутренних связей
вообще нет.

Новый оператор `coupling.hydraulic_geometry.dual_geometry` строит расстояния
от входной границы до первого центра, между центрами и от последнего центра
до выходной границы. Их сумма равна L на равномерных и неравномерных сетках.
Для постоянной площади A:

```text
I_face = dual_length / A
sum(I_face) = L / A
K_face = K_total * dual_length / L
sum(K_face) = K_total
```

Прежние граничные соединения здесь трактуются как внешние участки
эквивалентной схемы. Если конкретные исходные длины уже включают части зоны,
для такой установки нужна отдельная разбивка геометрии. Оператор не выводит
реальные размеры ВВЭР/PWR из чертежей и не подтверждает их экспериментально.

## Одна граничная переменная и согласованная энергия

Новые половины объединяются с существующими насосной и выходной связями.
Дополнительных состояний расхода и повторного владельца энергии нет.
Для старого соединения и присоединённой половины:

```text
I_old = L_old / A_old
I_half = half_length / A_channel
I_effective = I_old + I_half
L_effective = A_old * I_effective

I_effective / rho_reference_effective
    = I_old / rho_reference_old + I_half / rho_reference_channel

K_effective = K_old + K_half * (A_old / A_channel)**2
```

Эффективная опорная плотность служит существующему замыканию кинетической
энергии. Она **не подменяет плотность воды в EOS**. Последняя используется
для термодинамики и донорского переноса, включая трение. Масштабирование K
согласует давление потерь при разных площадях старого соединения и канала.

При одинаковом расходе через все грани добавленная кинетическая энергия
равна `0.5 * L/A * q**2 / rho_reference_channel` независимо от N.
Для неравномерных расходов сохраняются индивидуальные вклады граней;
их энергия и компенсирующее тепловое действие согласуются с уравнениями.
Замыкание остаётся моделью с **фиксированными опорными плотностями**.
Полная механика переменной плотности этим изменением не заявляется.

Снимки жидкости дополнены `face_acceleration_kg_s2` и
`face_driving_pressure_pa`. Они позволяют проверить `I*q_dot = driving_pressure`
на всех гранях. Геометрический паспорт содержит исходные и объединённые
коэффициенты границ. Это диагностические данные, не новые запасы.

## Условная проверка жидкостной сетки

Нативная матрица использует 2/4/8 равномерных жидкостных ячеек на 4 м,
фиксированные четыре нейтронные и восемь тепловых ячеек, K канала = 1.
На каждой сетке отдельно строится горячее равновесие с одинаковой заданной
мощностью и исходными ограничениями запасов. Найденные положения стержня
записываются; далее подаётся `+0.01` доли ввода относительно каждой опоры.

Каждая сетка рассчитана с `max_step_s=0.1, rtol=2e-8` и
`max_step_s=0.05, rtol=2e-9`. Наблюдения: `0`, `0.1`, `0.5`, `1`, `2 с`.
Fine-расчёт на восьми жидкостных ячейках воспроизводится из JSON-checkpoint
на `0.5 с`, во время движения стержня. Всего шесть траекторий и один restart.

По точным перекрытиям сравниваются температура, давление, плотность и
интегральные запасы массы, внутренней энергии и бора. Максимум L2 для 4/8
должен быть не больше 0.9 максимума для 2/4 по каждому полю и превышать
чувствительность к настройкам времени не менее чем в 20 раз.
Нормировки и отдельные ошибки каждого времени сохраняются в протоколе.

Порог нормированной L2 для массы/энергии/бора и плотности — 0.02,
температуры — 0.01 при масштабе 600 К, давления — 0.001 при 15.5 МПа.
Дополнительно требуются: временное расхождение полного состояния ≤ `1e-4`,
расхождение полной мощности 4/8 ≤ `1e-3` начальной мощности, прежние балансы,
полный ранг/невязки равновесия, неизменность опоры, прибытие стержня и rollback.
Это численные критерии данной постановки, а не физическая неопределённость.

Фактические коэффициенты рабочих соединений проверяются отдельно:
добавленные полная инерция, коэффициент опорной кинетической энергии и
потери должны сохраняться с относительным дефектом ≤ `1e-12`.
Невязка импульса ограничена `1e-5 Па`, нормированная невязка кинетической
работы — `1e-10`. Проверяются также произвольные неравномерные сетки,
одна ячейка, разные площади и опорные плотности граничных соединений.

Принятая поставка: **114 целевых тестов и 67 тестов из wheel**, восемь успешных фаз и полное совпадение научного JSON. Нормированная L2 температуры для пар 2/4 → 4/8: `0.00859940 → 0.00439547`. Максимальный дефект геометрических инвариантов — `5.15572e-15`, невязка импульса — `2.14236e-10 Па`, временное расхождение полного состояния — `1.73856e-07`. Девять отрицательных контролей отклонили искажения инерции, кинетического запаса, потерь, ускорения, кинетической работы, энергии, опоры, restart и состава матрицы.

## Локальное воспроизведение и статус

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  python -m scripts.verify_component_delivery --component fluid-geometry \
  --output artifacts/fluid-geometry-local --phase-timeout-s 1200
```

Каталог вывода должен быть новым. Профиль включает целевые тесты, научные
расчёты, sdist → wheel, свежую установку и повтор вне checkout с полным
совпадением научного JSON. CI и сеть не используются; зависимости локальные.
[Протокол v135](benchmarks/fluid_geometry_v135.json) содержит результаты и хеши.

Для `legacy` отдельно сравниваются пять сохранённых физических состояний
сценария v134: они должны совпасть побитно. Это проверка численной регрессии
в одном сценарии, не миграция checkpoint. Исходники адаптера изменились;
старые source-bound checkpoint локальных PWR-сессий не принимаются автоматически.

Проверка остаётся условной: однофазная жидкость, прямой поток, горизонтальная
эквивалентная схема, постоянные UA и синтетическая нейтроника. Ошибка до
непрерывного предела, совместная пространственная приёмка всех сеток,
экспериментальная валидация, StationEnv и длительные режимы ещё открыты.
Новый час и полный библиотечный профиль здесь не выполняются.
Корневой план — **58/76, открыто 18 задач**.
