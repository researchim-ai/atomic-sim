# Совместное уточнение сеток PWR — v136

[English](COUPLED_MESH_EN.md) · [Гидравлическая геометрия](FLUID_GEOMETRY_RU.md)

`coupling.refinement.coupled_pwr_mesh` создаёт согласованный набор
конфигураций для `LocalModeratorPWRSession`. Одновременно меняются сетки
нейтроники, жидкости, топлива и оболочки:

- разрешение 2: 2 нейтронные, 2 жидкостные и 4 тепловые ячейки;
- разрешение 4: 4 нейтронные, 4 жидкостные и 8 тепловых ячеек;
- разрешение 8: 8 нейтронных, 8 жидкостных и 16 тепловых ячеек.

Длина по умолчанию — 4 м, дополнительный K канала — 1. Жидкость использует
полную двойственную геометрию; тепловая сетка содержит все границы источника
и жидкости и по две дочерние ячейки внутри каждого интервала. Существующие
бюджеты 8/8/16 ячеек сохраняются. Рецепт создаёт конфигурации нового расчёта,
а не переносит состояния работающей модели.

```python
from coupling.refinement import coupled_pwr_mesh
from coupling.pwr_moderator import LocalModeratorPWRSession

session = LocalModeratorPWRSession(**coupled_pwr_mesh(4))
initial = session.snapshot()
rod = initial["actuator_status"]["rod_position"]
result = session.advance(0.1, {"rod_target": rod + 0.01})
```

Можно явно задать `length_m` и `loss_coefficient`; их изменение меняет
физическую постановку, поэтому не считается одним лишь уточнением сетки.
Матрица этого пакета относится к 4 м и K = 1.

## Одинаковая постановка на разных сетках

Для каждого разрешения отдельно решается горячее равновесие при одинаковой
заданной мощности и исходных ограничениях запасов. Найденные положения
стержня сохраняются. Затем подаётся одинаковое приращение ввода `+0.01`
от каждой опоры. Абсолютные команды и пространственные начальные состояния
могут отличаться.

При сравнении допускается менять число ячеек. Коэффициенты нейтроники,
длина, площадь, K, механическое замыкание, исходные параметры внешних
граничных соединений и опорная плотность канала должны совпадать.
Теплоёмкости и обе UA сохраняют одинаковые погонные плотности.
Каждая гидравлическая грань проверяется по своему коэффициенту, включая
обе граничные половины; проверка не ограничивается общей суммой.

Это контролируемое сравнение дискретизаций одной синтетической модели.
Финальная сетка не является независимым кодом или экспериментальным эталоном.

## Что сравнивается

Всего сохраняются 22 отдельных пространственных профиля:

- жидкость: масса, внутренняя энергия, бор, температура, давление и плотность;
- топливо/оболочка: две температуры, три запаса остаточного тепла, мощность
  деления, тепловой источник и два потока межкомпонентной теплопередачи;
- нейтроника: мощность деления и каждое из шести семейств предшественников.

Величины ячейки не сравниваются как одинаковые векторы при разных размерах
сеток. Оператор перекрытий различает средние поля и интегральные запасы/
мощности. Нормы вычисляются до усреднения ошибок: разнонаправленные
локальные дефекты не исчезают за одинаковой полной мощностью.

Нормировки общие для всех сеток: начальная мощность деления на длину,
начальный запас соответствующего семейства на длину, среднее начальное
поле предшественников подробной сетки. Температуры нормируются на 1000 К
для топлива и 600 К для оболочки/жидкости; давление — на 15.5 МПа,
плотность — на 1000 кг/м³. Эти масштабы не являются оценкой неопределённости.

## Критерии приёмки

Наблюдения записываются в `0`, `0.1`, `0.5`, `1`, `2 с`.
Все три разрешения выполняются с двумя настройками времени:
`max_step_s=0.1, rtol=2e-8` и `max_step_s=0.05, rtol=2e-9`.
На подробной fine-сетке проверяется точный JSON-restart из `0.5 с`,
когда стержень ещё движется. Всего шесть траекторий и одно продолжение.

Для каждого из 22 полей максимум нормированной L2 по всем временам,
включая начало, должен удовлетворять трём требованиям:

- расхождение пары 4/8 не больше 0.9 расхождения 2/4;
- пространственное различие не меньше двадцатикратного максимального
  coarse/fine-различия времени на всех трёх сетках;
- расхождение 4/8 укладывается в заранее заданный бюджет: 0.01 для температур,
  0.001 для давления, 0.02 для остальных жидкостных полей и 0.05 для
  остальных тепловых и нейтронных профилей.

Дополнительно проверяются временное расхождение полного связанного состояния
≤ `1e-4`, разность полной мощности 4/8 ≤ `1e-3` начальной мощности,
согласованность коэффициентов ≤ `1e-12`, сохранение перенесённых массы/бора
≤ `1e-12`, локальные энергетические и энтропийные тождества теплопередачи,
геометрия/импульс/кинетическая работа, прежние глобальные балансы и
нейтроны/предшественники. Требуются ранг и невязки равновесия, замороженная
опора, полный журнал прибытия стержня и rollback неправильной команды.

Максимумы по времени не заменяют сами траектории: все профили каждого
наблюдения остаются в научном JSON. Численный порядок и ошибка до
непрерывного предела из трёх сеток не выводятся. Этот пакет не выбирает
дешёвую замену модели для произвольного управления агентом.

Принятая поставка: **136 целевых тестов и 92 теста из wheel**, восемь успешных фаз и полное совпадение научного JSON. Максимальная L2 нейтронной мощности для 2/4 → 4/8: `0.01063574 → 0.00520071`. Временное расхождение полного состояния — `1.63116e-07`, дефект локального распределения гидравлических коэффициентов — `2.79796e-16`. Все 13 отрицательных контролей отклонили искажения балансов, отдельных семейств, коэффициентов, площади, опоры, карт запасов, restart и полноты матрицы.

## Локальное воспроизведение

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  python -m scripts.verify_component_delivery --component coupled-mesh \
  --output artifacts/coupled-mesh-local --phase-timeout-s 1200
```

Нужен новый каталог вывода. Восемь фаз включают целевые тесты, матрицу
расчётов, sdist → wheel, свежую установку и полный научный replay вне checkout.
Научные JSON должны совпасть целиком. CI и сеть не используются; зависимости
локальные. Результаты и хеши — в [протоколе v136](benchmarks/coupled_mesh_v136.json).

## Границы результата

Совместное уточнение относится к этому двухсекундному однофазному сценарию.
Сохраняются постоянные UA, синтетические одногрупповые данные и замыкание
кинетической энергии с фиксированными опорными плотностями. Подтверждение
одного сценария не распространяется на остальные режимы станции.
Борные переходные процессы, применимые физические замыкания, реальные
ядерные данные, StationEnv и длительные режимы требуют дальнейшей работы.
Новый час и полный библиотечный профиль здесь не выполняются.
NPP-12.02/03/04 остаются открытыми; корневой план — **58/76, открыто 18**.
