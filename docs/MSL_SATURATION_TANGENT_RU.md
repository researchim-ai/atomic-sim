# Производные насыщения: причина остаточных 135 нс и проверка исправления

## Результат

Остаточное расхождение времени парового перехода локализовано в двухфазных
производных MSL. После предыдущего исправления коэффициентов `g2` прямые
значения EOS согласовывались, но MSL использовала наклон Клапейрона для
`dp/dT` и изохорной теплоёмкости смеси. Atomic дифференцирует ту кривую
насыщения региона 4 IF97, по которой действительно вычисляет состояния.

Это различие двух близких касательных, а не ошибка выбора единиц или CSV.
IF97 состоит из отдельных приближённых уравнений; их согласованность на
линии насыщения рассматривается отдельно в разделе 10.2
[первичного документа IAPWS](https://iapws.org/technical-guidance/release/IF97-Rev.download).
Строгая численная проверка производной реализованной функции требует
дифференцировать именно эту функцию. Само наличие небольшого различия не
доказывает общую непригодность чужого симулятора.

При 1 МПа наклоны составляют примерно **23012,1052** и **23012,6781 Па/К**.
Около парового конца разность изохорной теплоёмкости достигает
**1,1075 Дж/(кг·К)**. Независимая модель с касательной Клапейрона, построенная
из прямых свойств IF97, предсказывает задержку **135,516 нс** без подбора
параметров. Наблюдавшаяся задержка MSL — около **135,44 нс**.

## Прямой аудит производных

Новый `scripts.audit_msl_saturation` вызывает настоящую
`waterBaseProp_dT` через `omc`, без динамики и интерполяции результатов.
Матрица: четыре давления 0,5/1/8/15,5 МПа и три качества
`1e-6`, `0,5`, `1−1e-6` — **12 состояний на вариант библиотеки**.

На стороне Atomic выполняются два независимых вычисления:

- Центральные разности прямой смеси при фиксированной плотности с шагами
  температуры 2e-4 и 1e-4 К. Производственный inverse EOS не вызывается.
- Аналитическая производная через Jacobian Atomic, использующая фактическую
  касательную кривой IF97 региона 4.

Пробы производной могут слегка продолжать вычислительную карту за конец
смеси; это только дифференцирование выражения. Такие состояния не принимаются
физическим интегратором, качество не обрезается и запасы не проецируются.

Бюджеты объявлены до расчёта: **0,01 Дж/(кг·К)** для производной энергии и
**0,1 Па/К** для производной давления. После одного лишь исправления `g2`
MSL не проходит эту проверку: максимум разности теплоёмкости с аналитическим
Atomic около **3,2266 Дж/(кг·К)**. Независимая реализация касательной
Клапейрона воспроизводит прямые MSL-значения с остатком до **2,83e-8 Дж/(кг·К)**.
Все 12 аналитических Atomic-производных проходят сравнение с прямыми разностями.

Отчёт: `artifacts/msl-tangent-coefficients-only-v2/report.json`.
Его `diagnostic_executed=true` означает выполненное измерение;
**`tangent_passed=false`** сохраняет отрицательный результат MSL.

## Отдельная копия с согласованными производными

`--counterfactual-copy` создаёт новую копию уже исправленной по таблице 10 MSL.
В `waterBaseProp_dT` меняются только двухфазные `dpT` и `cv`:
используется штатная производная `Basic.dptofT(T)`, а производная энергии
смеси вычисляется вдоль этой же кривой при постоянной плотности.
Прямые `p`, `h`, плотности концов и формула качества не меняются.
Общая функция `Common.cv2Phase` и остальные среды не переписываются.

Для удельного объёма `v`, качества `x` и концов `f/g` используются

```text
v_i' = (pt_i − p_sat') / (pd_i · rho_i²)
x'   = −((1−x) · v_f' + x · v_g') / (v_g − v_f)
u_i' = cv_i + (T · pt_i − p) · v_i'
u'   = (1−x) · u_f' + x · u_g' + x' · (u_g − u_f)
```

Здесь штрих означает производную по температуре вдоль насыщения.
Это аналитическая производная прямой карты, без корректирующего коэффициента
по измеренному времени события. Все изменения находятся в одном
`IF97_Utilities.mo`; исходная MSL и коэффициентная копия сохранены.
Manifest содержит `counterfactual=true`, `tangent_counterfactual=true`,
SHA исходной, родительской и новой версий. Это диагностическая библиотека,
а не неизменённый независимый peer.

Вторая матрица прямых вызовов приняла **12/12** состояний.
Максимальное отличие MSL-теплоёмкости от аналитической Atomic —
**2,81e-8 Дж/(кг·К)**. От центральных разностей — до **5,88e-5 Дж/(кг·К)**,
в пределах исходного бюджета. Отчёт:
`artifacts/msl-forward-tangent-audit-v2/report.json`.

## Динамика и строгие корни события

Полная динамическая матрица на новой копии приняла **40/40**:
32 заданных тепловых цикла и восемь wall-сравнений, DASSL/IDA,
tolerance1e-12. Исходные бюджеты P/T/u/m/U, стенки, балансов и фаз не менялись.
Максимальная ошибка удельной энергии в wall-сравнениях уменьшилась
примерно с **1,35e-3 до 1,24e-5 Дж/кг**.
Отчёт: `artifacts/modelica-forward-tangent-v1/report.json`.

Новый `scripts.compare_phase_event_campaign` строго допускает сохранённые
native-корни по исходникам, полноте матрицы, конечности значений, ширине
интервала, независимым решениям и restart. Повторный допуск не объявляется
новым вычислением native-сети. Сравниваются настоящие левые/правые строки
внешнего события; готовый успешный CSV другого источника не подставляется.

При неизменённом допуске **2e-8 с** результаты времени:

- Исходная MSL: **4/8**; её исходный отрицательный вердикт сохранён.
- Копия с исправлением только коэффициентов: **6/8**.
- Копия с коэффициентами и согласованной касательной: **8/8**,
  максимальная ошибка **1,3062e-9 с**.

Общий отчёт всех трёх вариантов отрицателен, поскольку включает исходные
отказы: `artifacts/msl-tangent-events-v1/report.json`.
Отдельная приёмка нового диагностического варианта положительна:
`artifacts/msl-forward-tangent-events-v2/report.json`.
Исходная MSL не объявлена прошедшей benchmark. Альтернативные неудачные
опыты выбора состояний из предыдущего этапа также не пересматриваются.

## Команды

```bash
python -m scripts.audit_msl_saturation \
  --omc /path/to/omc --library artifacts/my-table10-copy \
  --output artifacts/my-tangent-audit \
  --counterfactual-copy artifacts/my-forward-tangent-copy

python -m scripts.benchmark_modelica_cycles \
  --omc /path/to/omc --library artifacts/my-forward-tangent-copy \
  --include-wall --tolerance 1e-12 --output artifacts/my-forward-cycles

python -m scripts.compare_phase_event_campaign \
  --reference-from artifacts/phase-event-roots-v1 \
  --campaigns artifacts/my-forward-cycles \
  --output artifacts/my-forward-events
```

Native reference должен быть получен на тех же физических исходниках и
неизменённых драйверах. Отсутствие, изменение или неполнота свидетельств
приводят к отказу; при несовпадении источников нужно заново выполнить
`scripts.verify_phase_event`, а не переносить старый SHA в новый отчёт.

Этот блок закрывает локализацию остаточного сдвига в объявленном равномерном
wall-сценарии. Экспериментальная валидация, неоднородный проточный канал и
сравнение всей установки остаются отдельными задачами.
`validated=false`, `plant_referenced=false`.
