# API станции для агентов и проверяемое планирование

Пакет `atomic_model_station_env` предоставляет один станционный контракт
для Python, Gymnasium и JSONL. Он использует существующую физику,
регуляторы, приборы и неисправности; отдельной упрощённой «физики для API» нет.

## Жизненный цикл Python

```python
from atomic_model_station_env import EnvConfig, StationEnv

env = StationEnv(EnvConfig(max_steps=4))
observation, info = env.reset(seed=7)
observation, reward, terminated, truncated, info = env.step({})
actions = env.available_actions()
```

`reset` создаёт новую сессию с объявленным seed. Пустой запрос `step({})`
сохраняет выбранное управление; при `automatic=True` первый успешный шаг
включает все шесть штатных контуров. Некорректный запрос не включает их
задним числом и не продвигает время.

Наблюдение содержит только операторские отсчёты: значения, единицы,
время выборки/доставки, возраст и качество. `info` добавляет публичные
квитанции команд, обнаруженные тревоги и реакцию. Истинный вектор,
предшественники, геометрические запасы, расписание и имена неисправностей
не выдаются в этих объектах.

Действие разделено на `operator`, `modes`, `targets` и `reset`.
`available_actions()` описывает разрешённые поля, фиксированные диапазоны,
текущие объявленные задания и оставшийся горизонт. Это контракт запросов,
не раскрытие скрытой фактической мощности неисправного привода.
Изменение внешней доступности сети и прямое редактирование запасов
не являются действиями агента.

Например, режим/задание контроллера и ручной запрос привода различаются:

```python
env.step({"targets": {"rod_target": 3.15e9}})  # задание мощности делений, Вт
env.step({"modes": {"rod_target": "manual"},
          "operator": {"rod_target": 0.3}})   # запрос положения стержней
```

Действуют прежние насыщения, конечные скорости и приоритет защиты.
Намерение оператора может быть перекрыто; квитанция показывает причину.

## Завершение и отклонение запроса

`terminated` и `truncated` имеют разный смысл. Объявленный предел шагов
даёт `truncated=True`. Параметр `terminal_on_trip=True` дополнительно
завершает эпизод при фиксируемом trip. По умолчанию после останова можно
продолжать моделировать остаточное тепло до заявленного горизонта.
Это не позволяет сбросить физическую защёлку внутри прежней сессии.

`info` содержит отдельные `termination_reason` и `truncation_reason`.
Повторный шаг после завершения отклоняется без изменения состояния.
`ActionError` разделяет `invalid_action`, `model_domain_rejected`,
`episode_finished` и ошибки планирования. Физический отказ расчёта не
превращается в успешный переход с неисполненным хвостом.

Шаг атомарен во всех слоях: время, физика, PI, измерительные очереди,
шум, монитор и история сохраняются при ошибке. Возвращаемые словари —
отдельные копии; изменение наблюдения клиентом не изменяет станцию.

Вознаграждение — отрицательная сумма нормированных абсолютных ошибок
измеренной мощности, давления и скорости, со штрафами за недоступный
канал и публичный trip. Оно использует только доступные отсчёты и
объявленные задания. Это исходный исследовательский tracking reward,
не принятая промышленная функция безопасности, экономичности или диагноза.
Полный набор задач и train/dev/test NPP-14.03/04 остаётся отдельной работой.

## Gymnasium

```python
import numpy as np
from atomic_model_station_env import EnvConfig, StationGymEnv

env = StationGymEnv(EnvConfig(max_steps=4))
observation, info = env.reset(seed=7)
transition = env.step({"setpoints": np.zeros(3, dtype=np.float64), "scram": 0})
```

Три нормированных координаты задают мощность делений ±2%, скорость ±0,5%
и механическую нагрузку ±2% относительно объявленного номинала.
Это задания существующим контурам и нагрузке, а не назначение реальной
мощности или скорости. Отдельное дискретное действие запрашивает SCRAM;
нулевое значение не сбрасывает ранее сработавшую защиту.

Наблюдение включает десять нормированных измерений, маску пригодности,
возраст отсчётов и время. Непригодный канал представлен нулём с маской 0;
он не подменяется истинным состоянием. Пространства имеют конечные границы.
`info.raw_observation` сохраняет исходный измерительный кадр с единицами.

## JSONL и граница доступа

```bash
PYTHONPATH="$PWD/src" python -m atomic_model_station_env
```

По одной JSON-команде на строку:

```json
{"method":"reset","seed":7}
{"method":"actions"}
{"method":"step","action":{}}
{"method":"observe"}
```

Ответ — `ok/result` либо `ok/error` со структурированным кодом и причиной.
Неизвестные методы и поля отклоняются. Строки ограничены 65536 символами;
слишком длинная строка полностью пропускается, не превращаясь в несколько
действий. Ошибка JSON не продвигает сессию и не ломает следующий запрос.

Транспорт не предоставляет `checkpoint`, `restore`, `preview`, `apply`
или изменение сценария. Приватный сценарий задаёт исследователь при
создании серверной среды, а не агент в `reset`.

Python/Gym — доверенные библиотечные интерфейсы, не sandbox для произвольного
кода, который получил объект среды. Для отделённого агента информационной
границей служит JSONL-процесс. Политика должна получать наблюдение,
а не доступ к привилегированному объекту симулятора.

## Checkpoint и ветви действий

Checkpoint является привилегированным материалом исследователя. Он
сохраняет сценарий, полное состояние и историю. `StationEnv.restore`
воспроизводит префикс и сверяет весь результат, включая последний кадр,
вознаграждение, завершение и RNG. Изменённый или чужой checkpoint отклоняется.

Для явно модельно-привилегированного исследования доступен одношаговый
планировщик с максимум восемью альтернативами:

```python
comparison = env.preview([{}, {"operator": {"scram": True}}])
transition = env.apply(comparison, 0)
```

Планирование не продвигает исходную физику. Публичное сравнение содержит
запрошенные действия, прогнозируемые измерительные переходы и ошибки.
Полный checkpoint ветви, его скрытый отпечаток, исходный private-state hash
и расписание неисправностей в сравнение не входят. До проявления скрытой
будущей неисправности одинаковые начальные кадры не получают разные
идентификаторы из-за скрытого сценария.

Внутри backend остаются исходный отпечаток и ожидаемые отпечатки ветвей.
`apply` проверяет локальный живой план, повторно исполняет выбранное
действие и сравнивает весь переход и конечный checkpoint. Только затем
коммитится один шаг. Подмена результата, устаревший план или отвергнутая
ветвь не изменяют станцию. Продвижение, reset, restore и новое сравнение
делают прежние планы недоступными. Сами планы не входят в checkpoint.

Планировщик явно помечен `privileged_model_assisted`: прогноз использует
модель, включая её скрытое состояние и будущие события. Такой baseline
нельзя выдавать за обычного агента с одними измерениями. Поэтому обычный
JSONL-клиент не получает этот инструмент; эта граница также проверяется.

## Локальная квалификация

`python -m scripts.qualify_station_env --output artifacts/env-source-new`
проверяет связанные эпизоды по 4 с, измерительный отказ и реакцию,
совпадение Python/JSONL/Gym, новый интерпретатор, сортированный файловый
restart, выбор ветви, её непрозрачность и атомарное отклонение.

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
export PYTHONPATH="$PWD/src"
python -m scripts.qualify_station_env --output artifacts/env-source-new
python -m scripts.verify_local_library --output artifacts/env-library-new
python -m scripts.verify_station_primary_delivery --study env \
  --output artifacts/env-installed-new \
  --source-evidence artifacts/env-source-new \
  --library-evidence artifacts/env-library-new
```

Каталоги должны быть новыми. Установленный пакет повторяет всю научную
программу вне проекта. Эта проверка интерфейсов не заменяет полную
матрицу физики NPP-11 или R1.
