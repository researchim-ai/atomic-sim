# Изменения нагрузки всей станции

`atomic_model_station_load` задаёт воспроизводимый цикл нагрузки и
проверяет его переходные процессы. Это следующий шаг после согласованного
номинала; сам факт наличия программы не закрывает NPP-11.02.

## Задание и причинность

Стандартный цикл длится 1800 с при такте 5 с. Станция начинается из
согласованного состояния 3,15 ГВт, 6,3 МПа и 157 рад/с. На 450 с
нагрузка и задание мощности переходят на 98%, на 900 с — на 102%,
на 1350 с возвращаются к номиналу. Это ступенчатый цикл; он не выдаётся
за реализацию ограниченного по скорости диспетчерского графика.

Команда принадлежит началу такта. Например, команда на 450 с действует
на переходе 450–455 с, а измерение 455 с проверяется относительно этого
задания. Граница задаётся целым номером такта. Нет повторной инициализации,
сброса времени или PI между площадками; источники и баки остаются конечными.
Шесть контуров работают автоматически, нейтральная полоса запасов — 0,2 мм.

```python
from atomic_model_station_load import LoadCycle

cycle = LoadCycle()
episode = cycle.episode()
assert cycle.reference(89) == 1.
assert cycle.reference(90) == .98
```

Можно объявлять другие выровненные по тактам площадки в пределах 95–105%,
с ограниченным горизонтом и явным окном проверки. Это область допустимых
заданий, а не гарантия физической выполнимости всех комбинаций.

## Критерии

Проверяются все завершённые переходы: непрерывность времени, применение
согласованных заданий нагрузки/мощности, автоматический режим каждого
из шести конкретных контуров, отсутствие trip, качество всех шести основных
измерений и глобальные невязки энергии, массы и бора. Пропущенный шаг,
NaN, устаревший датчик или неверное задание не исчезают из статистики.

В последних 60 с **каждой** стандартной площадки проверяются:

- мощность и давление — относительная ошибка не больше 2%;
- скорость турбины — не больше 1%;
- уровень ПГ — ошибка не больше 0,02 м;
- уровни конденсатосборника и питательного бака — не больше 0,005 м;
- валовая электрическая мощность больше неотрицательных собственных нужд.

Это проверки заданий и запасов. Они не требуют нулевого изменения всей
станции во время перехода, когда энергия физически накапливается.
Допуски бюджетов: энергия 10⁻⁶, масса и бор 10⁻¹⁰.

При уточнении сравнивается каждая физическая координата на каждом общем
такте, с нормировкой `max(abs(reference), 1 SI unit)` и порогом 10⁻³.
Исключаются только накопительные учётные счётчики из штатной схемы.
Совпадение конечного вектора не компенсирует расхождение в середине пути.
Само это сравнение не заменяет отдельную проверку времён дискретных событий.

## Восстановление и происхождение данных

Программа сохраняет исходное состояние, весь путь, checkpoint в середине
и конечный checkpoint. При native restart реально повторяется весь префикс
через `FaultSession.restore`, а затем выполняется оставшийся путь. Для
проверки точности сравниваются все записи пути и конечный checkpoint.
Другая конфигурация цикла, устаревшие исходники или иные настройки
интегратора при запросе точного native replay отклоняются до расчёта.

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
export PYTHONPATH="$PWD/src"
python -m scripts.qualify_station_load_cycle --output artifacts/load-coarse-new
python -m scripts.qualify_station_load_cycle --output artifacts/load-fine-new \
  --max-step-s .5 --rtol 2e-8 --reference artifacts/load-coarse-new
python -m scripts.qualify_station_load_cycle --output artifacts/load-native-new \
  --reference artifacts/load-coarse-new --restart
```

Отказ физики и неполный горизонт сохраняются в отчёте с причиной;
они не объявляются полным пройденным циклом. Короткий путь на 0,12 с
существует отдельно для проверки транзакций, трёх численных настроек,
restart и установленного wheel. Он не доказывает регулирование за 1800 с.

```bash
python -m scripts.qualify_station_load_short --output artifacts/load-short-new
python -m scripts.verify_local_library --output artifacts/load-library-new
python -m scripts.verify_station_load_delivery \
  --output artifacts/load-installed-new \
  --source-evidence artifacts/load-short-new \
  --library-evidence artifacts/load-library-new
```

Все проверки выполняются локально и офлайн. Для принятия NPP-11.02
нужна совокупность длительных физических испытаний, уточнения, событий,
restart и установленного повтора. Успешный короткий тест и один длительный
расчёт по отдельности этого не доказывают.

## Результат v60

Пройдены 18 новых тестов и локальная поставка: 1889 тестов, восемь фаз.
Короткий путь 0,12 с прошёл три настройки, полный native replay и
точный установленный повтор всех 26 научных JSON. Расхождение
по физической траектории — 4,673·10⁻⁹.

Полный исходный цикл 1800 с прошёл критерии одного исходного расчёта.
Причины отказа: нет. Результаты всех площадок и бюджеты сохранены
в [машинном отчёте](benchmarks/station_load_cycle_v60.json).
Это единственный длительный исходный расчёт, а не полная квалификация
NPP-11.02. Счётчик остаётся 47/76, открыто 29.

Полная последующая квалификация этого цикла: [v61](STATION_LOAD_QUALIFICATION_RU.md).
Приведённая выше оценка v60 сохраняется как исторический результат одиночного расчёта.
