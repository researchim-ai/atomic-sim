# Пространственное уточнение и сильный нелинейный баланс v77

Дата: 17 ноября 2026.

После [нелинейного интегратора v76](STATION_NONLINEAR_MIDPOINT_RU.md)
добавлен компонент `atomic_model_station_resolution`: сравнение физических
скоростей при разных полосах Fourier-мод и радиальных базисах, а также
сильный баланс импульса с нелинейной адвекцией.

**Условная Fourier-проверка на выбранном фоне пройдена. Радиальная,
временная и граничная проверки не пройдены.** Выполнение исследования
и правильность инструментария подтверждены; полная пространственная
приёмка динамики не заявлена. Станционный счётчик сохраняется.

## Одна физическая начальная задача

Все расчёты начинают с одного поля: фиксированных регулярных мод полосы 1
и порядка 3 с общей амплитудой. При увеличении полосы новые моды начинают
с нулевых коэффициентов; при изменении радиального базиса исходное
полиномиальное поле представляется в новом вложенном пространстве.

Перед интегрированием сравниваются физические начальные скорости,
а не их разные координатные векторы. Максимальное расхождение на независимой
квадратуре — **4,088·10⁻¹⁶** при допуске 10⁻¹⁰. Рабочее начальное поле
не подгоняется после запуска.

Все расчёты используют безразмерную вязкость 0,05, alpha=0,628319,
64-точечную интеграционную квадратуру и неизменённый интегратор v76.
Порядок радиального базиса означает число полиномов в каждой спиновой
группе, а не число узлов квадратуры.

## Сравнение с учётом отсутствующих мод

При разных базисах сравниваются скорости, вычисленные на общей независимой
96-точечной квадратуре. При разных полосах берётся объединение полных
знаковых спектров. Отсутствующая в одном расчёте мода имеет в нём нулевую
скорость; её вклад в разность сохраняется.

Используется радиальная L2-норма:

```text
norm² = sum_signed_modes integral_0^1 |u_first-u_second|² r dr
norm² = common_modes² + only_first_modes² + only_second_modes²
```

В API/JSON эти нормы называются `total_rms`, `common_rms`, `only_first_rms`
и `only_second_rms`. Их точное определение — формула выше, без нормировки
на площадь сечения. Для среднеквадратичной нормы, усреднённой по сечению,
нужно умножить значение на sqrt(2). Все допуски v77 относятся к указанной
L2-норме.

Сравнение требует совпадающих периода и эпохи. Допускается округление
времени, но не произвольное расхождение моментов; для больших времён
используется ограничение по нескольким ULP. Прямое сравнение координат
разных базисов не выполняется.

На первом Fourier-уточнении разница только общих мод — 1,655·10⁻⁶,
а полная разница — **3,57535·10⁻⁴**. Пропуск новых мод занизил бы показатель
примерно в 216 раз. Независимые тесты проверяют норму отсутствующих мод
на аналитических полиномиальных полях.

## Девять расчётов и раздельные семейства

Выполнены:

- Четыре Fourier-полосы 1/2/3/4 при порядке базиса 3,
  t=0,05 и dt=0,005.
- Четыре порядка базиса 3/5/7/9 при полосе 2,
  t=0,1 и dt=0,0025.
- Дополнительный расчёт полосы 2, порядка 9 до того же t=0,1
  с dt=0,00125.

Это условные семейства с разными фиксированными фонами. Их нельзя
объединять в доказательство общей совместной сходимости всей системы.
Все временные сравнения физических скоростей выполняются на одинаковой
конечной эпохе.

### Fourier-полоса при фиксированном радиальном базисе

Последовательные полные разницы скоростей:

```text
полосы1→2: 3,57535e-4
полосы2→3: 1,33194e-6
полосы3→4: 7,97410e-9
```

Последний показатель ниже объявленного допуска 10⁻⁷; наблюдаемое
последовательное уменьшение также проходит критерий. Это приёмка
выбранного Fourier-уточнения **при порядке базиса 3**, а не непрерывной
задачи Навье–Стокса.

### Радиальный базис и шаг времени

При полосе 2 последовательные разницы:

```text
порядки3→5: 7,63252e-3
порядки5→7: 3,13950e-4
порядки7→9: 6,20473e-5
```

Последняя разница выше допуска 10⁻⁷. Радиальная проверка не принята.
Эти значения — разницы конечных решений, не доказанные оценки ошибки
относительно неизвестного точного решения.

Уменьшение шага на подробном радиальном базисе с 0,0025 до 0,00125
даёт разницу **5,83192·10⁻⁷**, также выше допуска 10⁻⁷.
Это новый более жёсткий фон проверки, чем отдельная временная программа v76.
Её прежний второй порядок не отменяется, но не считается автоматическим
допуском любого более подробного пространства.

## Сильный импульс с адвекцией

На 101 положительной радиальной точке до r=1 вычисляется:

```text
R_mode = (u_new-u_old)/dt + N_mode(u_mid)
         + grad(p_mid)_mode - nu*Lap(u_mid)_mode - f_mode
```

Адвекция вычисляется прямой свёрткой по физическим полям средней точки.
В отличие от линейного аудита v74, нелинейный член включён явно.
Тест центробежного равновесия подтверждает необходимость этого члена:
линейный остаток там велик, а нелинейный баланс выполнен.

Сила задаётся явными значениями в точках контроля; в выполненной программе
внешняя сила везде нулевая. Произвольные обобщённые нагрузки нельзя
подставлять вместо поточечной силы.

В самом подробном расчёте с половинным шагом максимальный граничный
остаток — **0,00622484**, выше допуска 10⁻⁸. Граничная проверка не принята.
Квитанции сохраняют абсолютный остаток и нормировку на максимум 1 и
модулей составляющих импульса на выбранной сетке.

Давление v76 восстанавливается только в сохранённых модах. Продукты
адвекции вне полосы также вычисляются и показываются как индикатор
неразрешённого содержания. Они **не называются полным остатком импульса**:
давление вне полосы неизвестно и может компенсировать потенциальную
часть нелинейного члена.

Диагностика последнего шага относится к его средней точке давления;
конечное время и средняя точка отдельно записаны. Остатки на разных
временных шагах не используются как сопоставленные в одну эпоху
давления для вывода порядка сходимости.

## Машинная приёмка

В отчёте разделены:

```text
passed = true                         # выполнение и начальная согласованность
fourier_conditional_gate_passed = true
basis_gate_passed = false
temporal_gate_passed = false
finest_wall_gate_passed = false
full_spatial_convergence_qualified = false
station_usable = false
```

Отказы сохранены; допуски не ослаблены. Дальнейшее исправление должно
обеспечить требуемую пространственно-временную точность и сильный
граничный баланс, а не только успешное завершение solve.

## Локальное воспроизведение

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH="$PWD/src:$PWD" \
  .venv-layout/bin/python -m scripts.qualify_station_resolution \
  --output artifacts/my-nonlinear-resolution

OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  .venv-layout/bin/python -m pytest -q tests/test_station_resolution.py \
  tests/test_station_resolution_qualification.py
```

Директория вывода новая. Нужны только Python и научные зависимости.
Пройдены **307 целевых тестов, включая 20 новых**. Два файла включены
в общий локальный профиль. Полный прогон 2261 теста остаётся исторической
проверкой v69; он не объявляется полным повторным прогоном v77.

[Машинная квитанция v77](benchmarks/station_resolution_v77.json) содержит
все девять расчётов, сравнения с отсутствующими модами, начальные проверки,
сильные остатки, отрицательные вердикты и подтверждение поставки.

Следующий этап — устранение радиального и граничного остатка с отдельным
контролем временной ошибки. Затем нужны общая динамическая приёмка,
тепловая/плавучая связка, длительная статистика и станционная применимость.

Станционный статус: **48/76 приняты, 28 открыты**.
