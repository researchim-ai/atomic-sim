# Регенеративный теплообмен борного обмена — v139

Новая опциональная политика: [IF97-проверка жидкостных портов v140](BORON_PORTS_RU.md). Прежние результаты не являются фазовой приёмкой выходов; строгий режим отклоняет неподдержанную двухфазность с полным rollback.

[English](BORON_REGENERATOR_EN.md) · [Конечный борный обмен](PWR_BORON_RU.md)

Горячая вода, отводимая из первичного контура, может отдавать часть тепла
холодной подпитке. Регенератор уменьшает тепловой удар подпитки и нагрузку
на принимающую воду. В этом пакете добавлен **отключаемый квазистационарный
противоточный теплообменник** внутри исследовательского компонента борного
обмена. Это математическая модель переноса тепла, а не описание оборудования
конкретной АЭС.

## Что моделируется

Параметр `BoronExchangeConfig.regenerator_ua_w_k` задаёт полную тепловую
проводимость UA в Вт/К; диапазон конфигурации — от 0 до 10⁷ Вт/К.
Значение по умолчанию **0** отключает перенос тепла. Новых динамических
состояний или запасов энергии не добавляется: у теплообменника нет собственной
воды и теплоёмкости стенки. Модель предназначена для исследования режимов,
в которых такое приближение уместно; его временной диапазон физически
не подтверждён измерениями.

У двух потоков одинаковый массовый расход, но могут различаться теплоёмкости.
Горячая теплоёмкость берётся из состояния IF97 на входе отвода и фиксируется
при решении текущей квазистационарной задачи. Холодная — 4180 Дж/(кг·К),
согласно существующему линейному замыканию баков. При изменении состояния
установки входные значения пересчитываются.

Используется метод эффективности ε–NTU из
[EnergyPlus Engineering Reference, Heat Exchangers](https://energyplus.readthedocs.io/en/stable/guides/engineering-reference/16.8-heat-exchangers.html).
Для Cmin/Cmax = r и NTU = UA/Cmin:

```text
epsilon = (1 - exp(-NTU*(1-r))) / (1 - r*exp(-NTU*(1-r)))
Q = epsilon * Cmin * (T_hot_in - T_cold_in)
```

При равных теплоёмкостных расходах предел вычисляется напрямую:
`epsilon = UA / (UA + Cmin)`. Для близких значений используется `expm1`,
чтобы избежать вычитания почти одинаковых чисел. При нулевых расходе или UA
тепловой поток равен нулю. Обратная разность температур даёт обратный поток
тепла. Выходные температуры и энтропия в диагностике относятся к этой
модели теплоёмкостей: **они не являются обращением IF97 на выходах**.

## Насос и энергетические порты

Подпитка нагревается в регенераторе после насоса. Удельная работа насоса —
`w = head / (rho_ref * eta)`. В линейном несжимаемом замыкании идеальная
работа повышает член p/rho в энтальпии, поэтому температура перед
регенератором повышается только на `(w - head/rho_ref) / 4180`.
Вся электрическая работа по-прежнему учитывается в собственных нуждах
и энергетическом счётчике установки ровно один раз.

Вклад обмена в энергию первичного контура и бака-приёмника:

```text
primary_rate = q*(h_supply - h_primary_donor) + pump_electric + Q
receiver_water_rate = q*h_primary_donor - Q - p_receiver*q/rho_ref
supply_water_rate = -q*h_supply + p_supply*q/rho_ref
```

Работа газовых подушек сохраняется отдельно. Q возвращает энергию внутрь
системы и не считается внешним источником или генерацией электричества.
Перенос бора, равенство расходов подпитки/отвода и конечные запасы баков
сохраняются. Параметр UA имеет статус иллюстративного: измерения,
калибровка и физическая неопределённость отсутствуют.

## Как проверяется

Восемь нативных траекторий на сетке 2 нейтронные / 2 жидкостные / 4 тепловые
ячейки: подачи 0 и 2000 ppm × UA 0 и 200000 Вт/К × две настройки времени.
Команды и наблюдения те же, что в v137–138: 0.1, 0.5, 1, 2 и 2.5 с;
расход открывается на 50 кг/с, в 2 с начинается закрытие с экспоненциальным
хвостом. Для включённого регенератора оба подробных расчёта проходят restart
с 0.5 с и точное продолжение до конца.

Тепловой поток на каждом наблюдении проверяется отдельной краевой задачей
для двух температур вдоль противоточного аппарата. Её решает `solve_bvp`;
формула эффективности в эталоне не используется. Отдельные тесты покрывают
равные, различные и почти равные теплоёмкости, нулевые пределы и обратный
теплоперенос. Проверяются глобальные балансы, энергия каждого порта,
расходование баков, бор, неизменность начальной опоры, чувствительность
к настройкам времени, работа насоса и энтропия модели теплоёмкостей.
Семь отрицательных контролей меняют копии результатов; они не подменяют
физические эксперименты.

Принятая поставка: **75 целевых тестов, 66 тестов из wheel**, восемь успешных фаз и точное совпадение полного научного JSON. Все семь отрицательных контролей сработали. Пик возврата тепла — `22.792407 МВт`; конечный бак-приёмник холоднее на `2.2606245 К` / `2.2606193 К` для разбавления/борирования. Максимальное временное расхождение полного состояния — `5.55075e-06`. Физические состояния двух отключённых случаев совпали с v138 побитно в шести наблюдениях каждый.

## Локальное воспроизведение

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  python -m scripts.verify_component_delivery --component boron-regenerator \
  --output artifacts/boron-regenerator-local --phase-timeout-s 1200
```

Нужен новый каталог. Проверяются исходники, сборка sdist → wheel,
установка вне checkout, тесты и полный научный replay из пакета;
сравнивается весь научный JSON. Научные зависимости используются
из локальной среды. CI и сеть для этого прогона не требуются.
[Протокол приёмки v139](benchmarks/boron_regenerator_v139.json).

## Граница результата

Этот пакет не квалифицирует длительные режимы или пространственную
сходимость нового активного теплообменника. Матрица v138 относится к
предыдущему исходнику и отключённому тепловому возврату. Новая подпись
адаптера не разрешает автоматическую перепривязку старых checkpoint.
Стандартный StationEnv не подключается к новому компоненту.

Остаются собственные запасы воды и стенки аппарата, гидравлическое
сопротивление и размеры, переменная теплоёмкость вдоль аппарата,
EOS/фазовая проверка выходов и дросселирования, вспомогательное охлаждение,
химия и данные реальной CVCS. Энтропия замыкания теплоёмкостей не заменяет
полный энтропийный баланс IF97. Корневой план остаётся **58/76: открыто 18**.
