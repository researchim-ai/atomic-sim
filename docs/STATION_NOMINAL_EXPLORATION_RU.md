# Часовой исследовательский номинал с шестью контурами

Выполнен непрерывный проход **3600 с**, 720 управляющих тактов по 5 с,
из исходного горячего состояния. Все шесть контуров включены на первом
шаге и продолжают работать без переинициализации, очистки PI, сброса
энергетических ledgers или переназначения жидких запасов. Seed — 0,
tracking — 10 с, физический `max_step_s=1`, `rtol=1e-7`, бюджет 8192 шага.
Дополнительных отказов и смены заданий нет.

Модель кампаний и физический источник совпадают с принятой версией v52;
разработка API v53 их не меняла. Это связанный часовой опыт с управлением,
не повтор прежнего ручного компонентного номинала.

## Наблюдаемый результат

За все 720 записанных шагов trip не срабатывал. На последнем участке
3000…3600 с максимальные ошибки геометрических уровней составили:
ПГ — 0.00187576 мм,
колодец — 0.00185684 мм,
питательный бак — 0.0983184 мм.
Это слежение за объявленными заданиями внутри данной модели.

Максимальные относительные ошибки **измеренных** мощности/давления/скорости
на том же участке: 0.000378775, 0.00034269,
2.93067e-05. Окончательный привилегированный физический снимок:
мощность делений 3.14935463 ГВт, давление коллектора
6.30063008 МПа, скорость
157.001455 рад/с. Эти числа не являются
погрешностью относительно реального энергоблока.

Максимумы относительных невязок по **шести сохранённым точкам через 600 с**:
энергия 3.9886e-15, масса
7.61554e-15, бор 1.62079e-15.
Допустимость и глобальные балансы каждого принятого шага дополнительно
проверял прежний backend. Максимумы по всем внутренним dense-пробам
здесь отдельно не извлекались.

Реальное время этого прохода — 2933.096 с. Это отдельный замер
при текущей нагрузке компьютера, не обещание скорости для других сценариев.

## Почему NPP-11 ещё открыт

Этот запуск исследовательский: для него не выполнены полный часовой
расчёт с уточнением, полный restart и независимый установленный повтор.
Поэтому результат не закрывает NPP-11.01–04 и не присваивает R1.
Также не выполнены остальные обязательные семейства длительной матрицы.

[Машинный отчёт и подписи](benchmarks/station_nominal_exploration_v54.json)
содержат фактическую длительность, число шагов, хвостовые метрики,
контрольные точки и явные отрицательные признаки отсутствующих проверок.
Счётчик плана остаётся **46/76**, открыто 30 задач.

Следующая проверка — те же начальные условия и контроллер при более
строгом физическом интеграторе, затем полный restart и установленный
повтор. До этого нельзя повышать статус на основании одного красивого
конечного снимка.
