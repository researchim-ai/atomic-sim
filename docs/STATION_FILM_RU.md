# Зависящая от расхода теплоотдача и контроль фазовых запасов

Дата: 13 ноября 2026. Backend: `PWRFilmSession`. Это следующий этап NPP-04.04;
весь пункт остаётся открытым, поскольку кипение и CHF в связанную станцию
ещё не подключены. Базовая `PWRPrimarySession` сохраняет прежнюю модель.

## Физическое изменение

В прежнем станционном backend теплообмен оболочки с водой определялся
постоянной проводимостью UA. Теперь коэффициент плёнки вычисляется из
текущего расхода выходного ребра `core_out` и свойств IF97 в объёме зоны.
Это сосредоточенная оценка; локальный профиль скорости и тепловой поток
в отдельном горячем канале не восстанавливаются. Используется существующий
проверенный численный kernel Диттуса—Бойлтера для нагрева однофазной жидкости:

`Re = m_dot D / (A_flow mu)`, `Pr = cp mu / k`,
`Nu = 0.023 Re^0.8 Pr^0.4`, `h = Nu k / D`,
`Q_clad = h A_heat (T_clad - T_bulk)`.

Этот же Q один раз уходит из энергии оболочки и один раз поступает
в существующий запас воды. Тепло топлива, энергия оболочки и водяной
запас сохраняют прежних владельцев; дополнительные дублирующие запасы
не вводятся. Снижение расхода меняет теплоотдачу через Re, а не через
назначенный извне множитель мощности.

## Эквивалентная геометрия и происхождение

Для явного замыкания геометрии объявлена эквивалентная система круглых труб:

- фактический сосредоточенный объём зоны V сохраняется;
- длина L задаётся `FilmConfig.heated_length_m`, по умолчанию 4 м;
- `A_flow = V/L`, `A_heat = 4V/D`;
- один диаметр D определяется из совпадения нового и прежнего номинального UA.

Это конструктивное согласование начальной исследовательской конфигурации.
Номинальное совпадение не служит независимым подтверждением точности корреляции.
Массы, внутренние энергии, начальные температуры топлива/оболочки и давление
не корректируются. При V=18 м³ получаются A_flow=4,5 м², D≈6,70 мм,
A_heat≈10742,5 м². Эквивалентное число труб непрерывное; оно не является
числом твэлов или элементов реальной установки.

Диаметр должен остаться в объявленных 5…30 мм, L/D > 10. Параметры
помечены как `illustrative`, геометрия не обмерена и не подогнана к
экспериментам. Корреляция круглой трубы не объявлена квалифицированной
для пучка твэлов, дистанционирующих решёток или локального горячего канала.
Неопределённость прогноза для реальной установки не назначена.

## Явная область расчёта

Поддерживаются положительный расход, Re ≥ 10000 и 0,7 ≤ Pr ≤ 160.
Ламинарное течение и переходная область не заменяются продолжением
турбулентной формулы. Оболочка должна нагревать жидкость и оставаться
ниже насыщения с объявленным запасом. Все четыре первичных объёма
должны находиться в жидкой области IF97 с запасом по недогреву.
Неподдержанный режим приводит к отказу всего запрошенного интервала;
состояние исходной сессии не изменяется. Фазовые ограничения проверяются
в принятых узлах решателя и на дополнительной сетке плотного вывода
не реже 0,05 с; это не математическое доказательство непрерывной безопасности.

Для всех существующих водяных объёмов диагностируются:

- область IF97, давление, температура насыщения и недогрев;
- качество и существующие массы жидкой/паровой фаз;
- для равновесной смеси — остатки восстановления плотности и удельной энергии.

В парогенераторе требуются обе фазы. Нижний порт компенсатора требует
жидкого запаса; полностью жидкое состояние компенсатора допускается,
отдельная паровая подушка тогда не заявляется. Минимальная относительная
масса требуемой фазы задаётся `minimum_phase_fraction`, по умолчанию 1e-8.
Контроль не обрезает качество, не добавляет воду и не переносит энергию
между владельцами. Он не моделирует динамику поверхности раздела,
сепарацию капель или пространственное осушение.

`chf_w_m2` и `dnbr` возвращаются как `None`, `boiling_supported=False`.
Это означает отсутствие применимой оценки, а не бесконечный запас до кризиса.
Существующая ограниченная таблица проточного CHF из другого backend
не переносится автоматически: её область давления/массового потока,
геометрия и двухфазное состояние должны совпасть со станционными условиями.
В текущем номинале давление зоны около 16,08 МПа и эквивалентный массовый
поток около 4015 кг/(м²·с), что выходит за прежнюю коробку 15…16 МПа,
300…2000 кг/(м²·с). Расширение числовых границ без новой квалификации запрещено.

## Программа локальной квалификации

```bash
python -m pytest -q tests/test_station_film.py
python -m scripts.qualify_station_film --output artifacts/my-station-film
python -m scripts.verify_station_primary_delivery --study film --output artifacts/my-film-delivery
```

Последняя команда выполняет исходный расчёт, профиль библиотеки, сборку,
офлайн-установку wheel в отдельное окружение и точный повтор вне checkout.
Можно явно переиспользовать уже принятые исходные результаты через
`--source-evidence` и `--library-evidence`. Численные настройки потоков
наследуются; версии библиотек и настройки BLAS сохраняются в отчёте.
CI, сеть и независимый runner не требуются.

До расчёта сохраняются критерии и контрольные суммы физического backend,
корреляционного kernel, драйвера и сериализатора. Программа включает:

- номинальный режим 3600 с, дрейф последних 120 с;
- 60 с выбега после SCRAM и отключения турбины;
- три настройки интегратора на переходе 10 с;
- независимую матричную экспоненту для изолированных запасов топлива,
  оболочки и воды при замороженных свойствах;
- короткий JSON-restart и атомарный отказ некорректной команды.

Изолированный эталон проверяет численный теплообмен и сохранение энергии,
а не физическую точность свойств или корреляции. Длительные расчёты
относятся к точечной зоне; отдельный короткий тест проверяет совместимость
с двухъячеечным пространственным владельцем нейтронного состояния.
Естественная циркуляция из приёмки `PWRPrimarySession` не считается
автоматически принятой для новой плёнки: при малом расходе Re может
выйти из её турбулентной области. Длительная история из checkpoint
отдельно не переинтегрируется; проверяется короткий restart.

## Что остаётся в NPP-04.04

Необходимо подключить применимую кипящую теплоотдачу к этим же запасам,
согласовать диапазоны давления и массового потока, задать геометрию
выбранного уровня модели и применимость CHF, затем квалифицировать
достижение насыщения, появление/исчезновение фаз, ограничения и restart.
Неподдержанные post-CHF режимы должны оставаться явным отказом.
Этот этап добавляет динамическую плёнку и фазовый контроль, но не закрывает
весь NPP-04.04 и не означает экспериментальную валидацию станции.

## Пример Python API

```python
from atomic_model_station import PWRFilmSession

station = PWRFilmSession(max_step_s=0.5)
initial = station.snapshot()
result = station.advance(10.0, {
    "scram": True,
    "turbine_trip": True,
    "primary_pump_on": False,
})
print(initial["film"]["conductance_w_k"])
print(result["film"]["conductance_w_k"])
print(result["film"]["reynolds"])
print(result["phase_inventory"]["sg_secondary"]["liquid_mass_kg"])
print(result["phase_inventory"]["sg_secondary"]["vapor_mass_kg"])
```

`checkpoint()` и `PWRFilmSession.restore(...)` сохраняют конфигурацию
плёнки и связывают историю с контрольными суммами физического кода
и корреляции. Checkpoint другого backend не принимается как совместимый.

## Фактическая квалификация

Номинал 3600 с пройден; дрейф последних 120 с — 1.42e-06. После 60 с выбега UA составляет 0.536535 начального значения. Ошибки уточнения по времени: [1.9754082842586166e-07, 2.0838170537952183e-07, 0.0]. Ошибка независимого замороженного матричного эталона — 2.53e-16, относительная невязка его энергии — 2.33e-16.

Максимальные относительные невязки станции: энергия 3.94e-15, масса 3.04e-15, бор 2.95e-15. Короткий restart и откат команды точные.

Пройдено 1525 тестов и восемь фаз локальной поставки. Все JSON-результаты точно повторены из установленного wheel вне checkout. [Машинный результат](benchmarks/station_film_v43.json). NPP-04.04 остаётся открытым; общий счётчик — 32/76.
