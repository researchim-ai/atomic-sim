# Радиальные проверки каталога и точный переходный эталон — v85

## Задача и область проверки

Предыдущий протокол v84 подтвердил временные и Fourier-сравнения пяти случаев
на пяти контрольных эпохах до безразмерного t=0,5. Новый протокол отдельно
проверяет чувствительность **конечного состояния при t=0,5** к радиальным
порядкам скорости и температуры. Результат не переносится автоматически
на промежуточные эпохи или на другие начальные поля.

Для каждого случая выполняются четыре независимых несегментированных
BDF-расчёта с одинаковыми физическими начальными полями:

- основной: порядки скорости/температуры 32/40;
- уточнение оси скорости через сравнение с 28/40;
- более грубая температура: 32/32;
- более подробная температура: 32/48.

Меняется одна ось за раз. В прежней короткой матрице вариант 28/32 менял обе
оси одновременно; теперь их влияние можно различить. Fourier band=4,
128 узлов квадратуры решения, rtol=1e-10 и atol=1e-13 одинаковы во всех
вариантах. На внешней Fourier-оболочке 4 сохраняются порядки 24/24: её
радиальное уточнение **не проверено** этим экспериментом.

Начальные физические поля сравниваются независимо от размерности вектора
коэффициентов. Их L2-разница должна быть меньше 1e-10; конечная L2-разница
скорости и температуры — меньше 1e-7. Сравнение использует 160 узлов
квадратуры и сохраняет различия обоих полей отдельно.

Основной вариант и вариант температуры 48 должны пройти строгие проверки
теплового баланса (1e-10) и стеночных остатков (1e-8). Грубые варианты
сохраняются вместе с их отказами: малая L2-разница не превращает их в
принятые решения. Для всех четырёх проверяются энергетические дефекты
(1e-9), слабая невязка давления (1e-9) и мощность дискретного переноса
(1e-11). Незавершённый расчёт не может дать успешную общую приёмку.

## Независимый переходный эталон

Пусть λ — положительный нуль функции Бесселя J₀, а Eκ(t)=exp(−κλ²t).
Осесимметричное, не зависящее от осевой координаты решение имеет вид:

θ(r,t) = Q(1−r²)/(4κ) + A Eκ(t) J₀(λr),

u_z(r,t) = bQ(3−4r²+r⁴)/(64νκ) + U(t) J₀(λr),

u_r = u_φ = 0.

При ν≠κ:

U(t) = bA [exp(−κλ²t) − exp(−νλ²t)] / [(ν−κ)λ²].

При ν=κ используется точный предел:

U(t) = bAt exp(−νλ²t).

Начальная добавка к скорости равна нулю. Температурная мода затухает и
через плавучесть возбуждает течение. Перенос исчезает из-за отсутствия
радиальной скорости и осевой зависимости. Равенство
∆J₀(λr)=−λ²J₀(λr) сводит проверку формул к двум скалярным ОДУ.
Поэтому эталон не вычисляется через правую часть или матрицы решателя.

Дополнительно независимо проверяются физическое тепло в мере r dr:

H(t) = Q/(16κ) + A Eκ(t) J₁(λ)/λ,

и интеграл наружного стеночного потока от 0 до t:

F(t) = Qt/2 + A J₁(λ)[1−Eκ(t)]/λ.

Восемь тестов используют первый и второй радиальные собственные режимы,
нагрев и охлаждение, оба знака плавучести, равные и различные ν/κ,
а также эпохи t=0,5 и t=2. Точность физических полей проверяется с
абсолютным допуском 2e-10, тепла и интеграла потока — 2e-11.
Это аналитическая верификация связанной переходной задачи; измерения
реальной установки она не заменяет.

## Воспроизведение

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  .venv-layout/bin/python -m scripts.qualify_station_thermal_radial_catalog \
  --output artifacts/my-thermal-radial-catalog

OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  .venv-layout/bin/python -m pytest -q \
  tests/test_station_thermal_radial_catalog.py \
  tests/test_station_thermal_transient_reference.py
```

Каталог вывода должен быть новым. Для каждого случая сохраняется отдельная
квитанция с исходными спецификациями, отчётами решателя, проверками качества,
сравнениями и отказами. Общий отчёт содержит хеши этих квитанций.
Изменение научных исходников во время эксперимента запрещает выпуск
итоговой квитанции. Все проверки локальные, без CI.

## Что остаётся

Радиальные сравнения на промежуточных эпохах и радиальное разрешение внешней
Fourier-оболочки остаются отдельными задачами. Сравнение конечного числа
порядков не является строгой оценкой ошибки относительно точного общего
трёхмерного решения. Непрерывная область параметров, длительные статистики,
экспериментальная валидация и станционная применимость не заявляются.
Станционная приёмка остаётся 48/76; открыто 28 задач.

## Результат v85

Приняты 5/5 конечных радиальных сравнений; завершено 20/20 расчётов. Максимальные L2-разницы: скорость 28/32 — 1.88901e-12; температура 32/40 — 2.84714e-12; температура 40/48 — 9.48249e-13. Сохранено 3 отказов качества грубых вариантов. [Машинный отчёт](benchmarks/station_thermal_radial_catalog_v85.json).

Прошли 53 целевых теста, включая 16 новых; 16 новых тестов повторены из установленного wheel вне проекта. Полная научная матрица из wheel не повторялась; полный прогон библиотеки не заявляется.
