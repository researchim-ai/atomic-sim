# AI-08.03: многогрупповая 1D-диффузия и локальная кинетика

Численный модуль `atomic_model_spatial` отделён от прежних `reactor/neutronics_1d.py`, `physics/neutronics/` и замороженных HEM-семейств. Он решает неоднородную плоскую диффузию на неподвижной сетке с заданными макросечениями. Статус — numerical verification, `validated=false`, `plant_referenced=false`. Это не собранная пространственная модель ВВЭР и не квалифицированная библиотека ядерных данных.

AI-08.03 принят только для описанного ниже численного контракта. AI-08.01/02/04/05/06/07/08, экспериментальная валидация и связанная установка не закрываются автоматически. Примерные коэффициенты и скорости явно синтетические. Расчёт с физическими скоростями 10⁷ и 2200 м/с отдельно проверяет сохранение критического равновесия; время синтетического переходного примера не является паспортным горизонтом реактора.

## Уравнения и данные

В каждой ячейке задано `G` энергетических групп и `J` неподвижных семейств предшественников:

- `(1/v_g) dφ_g/dt = div(D_g grad φ_g) − (Σa,g + Σout,g) φ_g + Σh≠g Σs,g←h φ_h + χp,g (1−Σβj) Σh νΣf,h φ_h + χd,g Σj λj Cj + qg`;
- `dCj/dt = βj Σh νΣf,h φ_h − λj Cj`.

`scatter_per_m[to,from,cell]` допускает downscatter и upscatter. Диагональное рассеяние должно быть нулевым: внутри группы оно не создаёт поглощения. `absorption_per_m` содержит именно поглощение; уход в другие группы добавляется при сборке. `nu_fission_per_m` — уже произведение νΣf, а не Σf. Скорость не изменяется интегратором.

Геометрия: плоский слой, площадь 1 м², `faces_m` в метрах. `diffusion_m` в м, макросечения в м⁻¹, скорости в м/с, λ в с⁻¹; χ и β безразмерны. φ — нейтрон/(м²·с), C — м⁻³, q — нейтрон/(м³·с), ток J — нейтрон/(м²·с). Для собственных функций абсолютная амплитуда условна: интегральный источник деления нормируется к единице. Энергия на деление и тепловая мощность не выводятся из νΣf.

Формы массивов строгие, без broadcasting: групповые поля `[G,N]`, scatter `[G,G,N]`, β `[J,N]`, λ `[J]`. В каждом узле спектры χp и χd нормированы, `0 ≤ Σβ < 1`; D, v, λ положительны. Явная строка `provenance` обязательна, но её наличие не удостоверяет происхождение сечений. Для evaluated/MGXS нужны отдельные библиотека, лицензия, оси, нормировки и статистические ошибки AI-08.01/02.

Пределы реализации: 1–512 ячеек, 1–8 групп, 1–8 семейств, не более 4096 компонент состояния. Допуски не являются гарантией точности любой допустимой конфигурации. Выход за бюджет, некорректные данные, сингулярная система или непройденный численный критерий приводят к отказу.

## Дискретизация и решатели

Конечно-объёмный поток через внутреннюю грань использует сумму двух полусопротивлений `h_left/(2D_left) + h_right/(2D_right)`. Это сохраняет общий межъячеечный ток при скачке D и работает на неравномерной сетке. Ток положителен в направлении увеличения x.

Границы задаются отдельно: `reflecting` (нулевой ток) либо `zero_flux` (φ=0 на физической грани, проводимость 2D/h). `zero_flux` не выдаётся за транспортную vacuum/Marshak-границу; экстраполяционная длина не подставляется скрыто.

Собственная задача `Lφ = Fφ/k` решается степенными итерациями с разреженной факторизацией L, нормировкой источника и двумя критериями: изменение формы и нормированная невязка. В равновесной F учтены разные prompt/delayed спектры. При исчерпании итераций результат не принимается.

Задача источника решает `(L−F)φ=qV`. При наличии деления сначала требуется `k < 1−10⁻⁸`; критический или надкритический стационарный источник отклоняется. Помимо линейной невязки проверяется интегральный нейтронный баланс. Это равновесный, а не prompt-only источник.

Переходная задача использует полностью связанный backward Euler для всех φ и локальных C. Перед шагом проверяется достаточный сертификат M-матрицы: для положительного весового вектора w требуется `dt·max_i(Bw/w)_i < 0,95`. Выбирается лучший из двух проверенных весов; их размерность — численная диагональная подобность, не физическая нормировка. Отказ сертификата не доказывает неустойчивость истинного решения; он означает, что данная реализация этот шаг не принимает. Пользователь может уменьшить dt. Автоматической подмены dt, clipping отрицательных запасов, проекции к критичности или скрытой перенормировки φ нет.

После шага проверяются невязка, конечность, неотрицательность и локальный/глобальный баланс запаса `Σg φg/vg + Σj Cj`. Рассеяние и переход нейтрон→предшественник→нейтрон сокращаются; остаются νΣf, поглощение, внешнее поступление и утечка. Этот журнал — нейтронный, не тепловой энергетический баланс.

## Запуск и рестарт

```bash
python -m atomic_model_spatial example slab_eigen_v1 --output artifacts/spatial_eigen_input.json
python -m atomic_model_spatial run artifacts/spatial_eigen_input.json --output artifacts/spatial_eigen.json
python -m atomic_model_spatial example slab_transient_v1 --output artifacts/spatial_transient_input.json
python -m atomic_model_spatial run artifacts/spatial_transient_input.json --output artifacts/spatial_transient.json
python -m atomic_model_spatial qualify --output artifacts/spatial_qualification.json
python -m atomic_model_spatial audit artifacts/spatial_qualification.json
```

Установленный пакет предоставляет эквивалентный `atomic-spatial`. Оба примера включены в wheel. `run` принимает строгий JSON версии 1; режимы `eigen`, `fixed_source`, `transient`. Для источника нужно поле `source[G,N]`; для transient — начальные φ/C и последовательность `{dt_s,source}` (не более 10 000 шагов суммарной истории). Источник постоянен внутри каждого шага; изменение материалов, движение стержней, автоматический календарь событий и обратная связь не поддерживаются этим контрактом.

Для продолжения transient создайте вход с той же моделью, `initial_flux=null`, `initial_precursors=null` и следующими шагами. Передайте `--checkpoint artifacts/spatial_transient.json`: CLI принимает результат предыдущего запуска либо отдельный checkpoint. Перед продолжением воспроизводятся все шаги, сверяются конфигурация, исходники, версии Python/NumPy/SciPy, журнал и конечные популяции. Даже корректно перехешированная подмена истории отвергается. Это полный replay при постоянных материалах, не дешёвый долгосрочный checkpoint большого производства.

Результаты содержат схему, запрос, единицы через контракт полей, текущие хеши исходников/примеров, версии зависимостей, токи на гранях и невязки. Файлы публикуются атомарно без перезаписи. API возвращает новое состояние; отказ шага сохраняет исходное. API/JSON не являются песочницей для недоверенного кода; AI-12.07 остаётся открытым. Побитовая воспроизводимость проверена на том же хосте; другая BLAS/ОС требует отдельной квалификации.

## Независимые проверки и ограничения результата

Критерии закреплены в `workflow.CRITERIA`. Плотный эталон собирается независимо через матрицу инцидентности и блочные диагонали, не считывает sparse-матрицы продукта. Проверяются стационарные задачи на однородных и неоднородных данных. Дополнительно используются аналитические одногрупповые решения, интегральное сокращение рассеяния, трёх-/восьмигрупповая отражающая среда и независимая 4×4 локальная кинетика.

Пространственная квалификация на 8/16/32/64 ячейках включает непрерывный многогрупповой фундаментальный k и точный источник в двухслойной среде со скачком D в четыре раза. Получены порядки около 2,00. Для неравномерной сетки проверены операторы и k против плотного эталона; универсальный второй порядок на произвольной неравномерной сетке не заявлен.

Временная квалификация включает два переходных случая, три шага 0,002/0,001/0,0005 с до 0,04 с и матричную экспоненту независимого оператора. Получены порядки 0,988–0,994; максимальная относительная ошибка на мелком шаге около 0,0844%. Все шесть restart повторяют полную историю. Это проверка линейного интегратора, не экспериментальный transient benchmark.

Методические первоисточники: [уравнения многогрупповой диффузии и предшественников GeN-Foam](https://foam-for-nuclear.gitlab.io/GeN-Foam/doxygen/classFoam_1_1diffusionNeutronics.html), [документация SciPy по вычислению действия матричной экспоненты](https://docs.scipy.org/doc/scipy/reference/generated/scipy.sparse.linalg.expm_multiply.html). Эталон здесь использует `scipy.linalg.expm` на небольшом плотном расширенном операторе. Это не выполненное межкодовое сравнение с GeN-Foam.

Физическая экспериментальная оценка HEM также остаётся открытой, её прежний отказ не изменён этим модулем.
