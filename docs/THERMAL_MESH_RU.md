# Согласованная сетка топлива и оболочки — v134

[English](THERMAL_MESH_EN.md) · [Уточнение нейтроники](NEUTRON_MESH_RU.md)

`coupling.thermal_grid.aligned_fuel_grid` строит тепловую сетку,
содержащую все границы нейтронных источников и жидкостных ячеек. Затем каждый
полученный интервал можно разделить на одинаковое число частей.
Построитель возвращает обычный `FuelGrid`, пригодный для
`LocalModeratorPWRSession`. Он не переносит состояния и не меняет уравнения.

Концы двух исходных сеток должны точно совпадать. Близкие границы не
сливаются по допуску. Целое число подразделений должно быть от 1 до 16;
итоговая сетка по-прежнему ограничена 16 тепловыми ячейками. Неразрешимые
в float64 интервалы и превышение бюджета отклоняются.

```python
import numpy as np
from atomic_model_station import CoreConfig
from coupling.pwr_channel import FluidGrid
from coupling.pwr_moderator import LocalModeratorPWRSession
from coupling.thermal_grid import aligned_fuel_grid

core = CoreConfig(kind="diffusion", cells=4)
fluid = FluidGrid()
fuel = aligned_fuel_grid(
    np.linspace(0., core.length_m, core.cells + 1),
    fluid.faces_m,
    subdivisions=2,
)
session = LocalModeratorPWRSession(core=core, fluid_grid=fluid, fuel_grid=fuel)
```

## Что показало обычное дробление

Сначала рассчитаны вложенные сетки 3/6/12 ячеек, полученные дроблением
прежней сетки `(0, 0.7, 2.2, 4)`. При фиксированных четырёх нейтронных
ячейках и жидкости `(0, 1, 2, 4)` некоторые тепловые ячейки пересекают
границы обеих постановок. Дробление меняет усреднение источника и контакта.

Максимум нормированной L2 температуры оболочки для пар 3/6 и 6/12 равен
примерно `0.003331` и `0.003541`. Для распределённой мощности — `0.005900`
и `0.006161`. Ошибки этих сравнений не уменьшились. Из этого опыта
**нельзя принять монотонную сеточную сходимость**. Все три нативные траектории
и отрицательный диагностический результат сохранены в протоколе.
Два численных режима и restart для этой серии не квалифицировались.
Прежняя трёхъячеечная сетка не получает статус сеточно-независимой.
Эта диагностическая серия не входит в научный JSON повторной проверки wheel.
Её можно воспроизвести отдельно при установленной библиотеке:

```python
import json
from pathlib import Path
import numpy as np
from atomic_model_station import CoreConfig
from coupling.pwr_fuel import FuelGrid
from coupling.pwr_moderator import LocalModeratorPWRSession
from scripts.qualify_moderator_transients import protocol

out = Path("artifacts/thermal-nonconforming-local")
out.mkdir(parents=True, exist_ok=False)
original = (0., .7, 2.2, 4.)
for split in (1, 2, 4):
    faces = [float(x) for a, b in zip(original[:-1], original[1:])
             for x in np.linspace(a, b, split + 1)[:-1]] + [4.]
    sim = LocalModeratorPWRSession(
        core=CoreConfig(kind="diffusion", cells=4),
        fuel_grid=FuelGrid(tuple(faces)), max_step_s=.05, rtol=2e-9,
    )
    initial = sim.snapshot()
    rows = [sim.advance(**step) for step in protocol("insertion", float(sim.state[12]))]
    (out / f"{len(faces)-1}.json").write_text(
        json.dumps(dict(initial=initial, snapshots=rows)), encoding="utf-8",
    )
```

## Проверяемый предел воспроизведения

В текущей модели теплоёмкости и UA постоянны на единицу длины. Осевой
теплопроводности нет; внутри одной нейтронной и одной жидкостной ячейки
источник и контактные условия одинаковы. Если тепловая ячейка уже согласована
с этими границами, её одинаковые дочерние ячейки должны воспроизводить ту же
температуру, а их интегральные запасы и мощности — складываться в родительские.
Это проверяемое свойство конкретного локального замыкания.

Пакет использует согласованные тепловые сетки **4/8/16** ячеек на длине 4 м,
при неизменных нейтронной сетке из четырёх ячеек и жидкостной сетке из трёх.
На каждой сетке отдельно строится горячее равновесие с одной заданной
мощностью и одинаковыми исходными ограничениями запасов. Найденные положения
стержня записываются; далее подаётся приращение ввода `+0.01` от каждой опоры.
Абсолютные команды и пространственные начальные состояния могут отличаться.

Времена наблюдений: `0`, `0.1`, `0.5`, `1`, `2 с`. Все три сетки запускаются
с `max_step_s=0.1, rtol=2e-8` и `max_step_s=0.05, rtol=2e-9`.
На шестнадцатиячеечной fine-сетке выполняется точный JSON-restart с `0.5 с`,
когда стержень ещё движется. Всего шесть траекторий и одно restart-продолжение.

## Девять профилей и локальные балансы

Сравниваются температуры топлива/оболочки, три отдельных запаса остаточного
тепла, мощность деления, полный тепловой источник, передача топливо–оболочка
и оболочка–жидкость. Нормы вычисляются по точным перекрытиям ячеек.
Температуры — средние поля, энергии и мощности — интегральные величины ячеек.
Нормировки температур — `1000 К` и `600 К`, мощностей — начальная мощность
деления на длину, запасов — соответствующий начальный запас на длину.

Для каждой пары 4/8, 8/16 и 4/16 максимум нормированной L2 по всем временам
должен быть не больше `1e-6` для каждого из девяти полей. Это численный
контракт воспроизведения, а не физическая неопределённость. Дополнительно
проверяются:

- неизменность сумм и погонных плотностей обеих теплоёмкостей и обеих UA
  с относительной невязкой не более `1e-12`;
- отдельные уравнения энергии каждой ячейки топлива и оболочки, согласие
  потоков обоих владельцев и сумм строк/столбцов матрицы контакта;
- энергия оболочки как сумма `C[i]*T[i]`, положительность производства
  энтропии и её согласие с тепловыми потоками;
- прежние глобальные балансы, ранг/невязки равновесия, замороженная опора,
  перенос массы/бора, прибытие стержня и rollback неправильной команды;
- разность полной мощности не больше `1e-6` начальной мощности и
  coarse/fine-расхождение полного состояния не больше `1e-4`.

Энергетические тождества вычисляются заново, с нормированным допуском `1e-10`.
Совпадение общих сумм не позволяет скрыть изменение локальной теплоёмкости
или ошибку отдельной ячейки. Размах температуры топлива должен превышать 1 К:
равномерное поле не заменяет проверку пространственного отклика.

Принятая поставка: **134 целевых теста и 75 тестов из wheel**, восемь успешных фаз и полное совпадение научного JSON. Максимальная нормированная L2 девяти профилей по трём парам сеток — `4.11075e-11`; расхождение полного состояния по времени — `1.75162e-07`. Восемь отрицательных контролей отклонили испорченные локальные балансы, пары тепла, распределение теплоёмкости, третий запас остаточного тепла, опору, матрицу, restart и энтропию.

## Локальный запуск

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  python -m scripts.verify_component_delivery --component thermal-mesh \
  --output artifacts/thermal-mesh-local --phase-timeout-s 1200
```

Нужен новый каталог вывода. Восемь фаз включают целевые тесты, расчёты,
sdist → wheel, свежую установку вне checkout и повтор расчётов с полным
совпадением научных JSON. Зависимости локальные, CI и сеть не используются.
[Протокол v134](benchmarks/thermal_mesh_v134.json) сохраняет результаты и хеши.

Принятие предела воспроизведения не означает общей сходимости тепловой сетки
или всей установки. Жидкостная дискретизация и её геометрия/инерция,
применимые замыкания, борные процессы, StationEnv и длительные режимы ещё
требуют работы. Синтетические сечения и иллюстративные обратные связи
сохраняются. Экспериментальная валидация, новый часовой режим и полный
библиотечный профиль здесь не выполняются. Корневой план — **58/76, открыто 18**.
