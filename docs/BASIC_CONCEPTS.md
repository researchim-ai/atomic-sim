# 🎯 Основные понятия ядерного реактора

> **Для кого:** Если вы новичок в ядерной физике, начните с этой страницы. Она объясняет основные понятия простыми словами.

## Что такое ядерный реактор?

**Простыми словами:** Ядерный реактор - это "печь", которая нагревает воду, используя энергию деления атомных ядер.

**Как это работает:**
1. **Топливо** (уран) делится под действием нейтронов
2. При делении выделяется **тепло**
3. Тепло нагревает **воду**
4. Пар вращает **турбину** и вырабатывает электричество

## Ключевые понятия

### 1. Деление ядра

**Что это:** Процесс расщепления тяжелого ядра (урана) на два более легких под действием нейтрона.

**Аналогия:** Как разбить большой камень молотком - получается много мелких осколков + искры (нейтроны).

**Результат:**
- Выделяется энергия (тепло)
- Испускается 2-3 нейтрона
- Образуются новые ядра (осколки деления)

### 2. Цепная реакция

**Что это:** Самоподдерживающийся процесс, где нейтроны от одного деления вызывают новые деления.

**Условие:** Каждое деление должно вызывать в среднем ровно одно новое деление.

**Аналогия:** Как лесной пожар - одна искра зажигает сухую ветку, которая зажигает дерево, которое зажигает весь лес.

### 3. Критичность

**Критическое состояние (ρ = 0):**
- Количество нейтронов постоянно
- Мощность реактора стабильна
- Цепная реакция самоподдерживается

**Надкритическое состояние (ρ > 0):**
- Количество нейтронов растет
- Мощность реактора увеличивается
- Нужно управление для безопасности

**Подкритическое состояние (ρ < 0):**
- Количество нейтронов уменьшается
- Мощность реактора падает
- Реактор останавливается

### 4. Нейтроны

**Мгновенные нейтроны:**
- Испускаются сразу при делении
- Время жизни: ~0.00005 секунды
- Составляют 99.35% всех нейтронов

**Запаздывающие нейтроны:**
- Испускаются с задержкой (от 0.2 до 60 секунд)
- Составляют 0.65% всех нейтронов
- **Критически важны** для управления реактором

**Почему запаздывающие нейтроны важны:**
- Без них реактор неуправляем (слишком быстрые изменения)
- С ними можно управлять мощностью за секунды/минуты
- Как тормоз в автомобиле - замедляет процесс

### 5. Реактивность

**Что это:** Мера отклонения реактора от критического состояния.

**Формула:** ρ = (k_eff - 1) / k_eff

**Где k_eff - эффективный коэффициент размножения:**
- k_eff = 1.0 → критический (ρ = 0)
- k_eff > 1.0 → надкритический (ρ > 0)
- k_eff < 1.0 → подкритический (ρ < 0)

**Единицы измерения:**
- **Абсолютная реактивность:** безразмерная (0.001 = 0.1%)
- **Доллары:** ρ / β (где β = 0.0065)
- **Центы:** (ρ / β) × 100

### 6. Управляющие стержни

**Что это:** Устройства для управления мощностью реактора.

**Как работают:**
- **Введение стержня** → поглощение нейтронов → снижение мощности
- **Извлечение стержня** → меньше поглощения → увеличение мощности

**Материалы:** Бор, кадмий, гафний (хорошо поглощают нейтроны)

**Типы стержней:**
- **Управляющие** - для точного управления мощностью
- **Стержни безопасности** - для аварийной остановки (SCRAM)

### 7. Температурные эффекты

**Доплер-эффект:**
- При повышении температуры ядра движутся быстрее
- Увеличивается поглощение нейтронов
- Реактивность снижается (отрицательная обратная связь)

**Эффект плотности:**
- При повышении температуры вода расширяется
- Плотность замедлителя снижается
- Меньше замедления нейтронов → снижение реактивности

**Важность:** Обеспечивают естественную стабильность реактора.

### 8. Отравление реактора

**Что это:** Накопление веществ, поглощающих нейтроны и снижающих реактивность.

**Основные "яды":**
- **Ксенон-135 (Xe-135)** - самый важный
- **Самарий-149 (Sm-149)**
- **Европий-151 (Eu-151)**

**Проблема ксенона:**
- Образуется при делении
- Поглощает нейтроны
- Затрудняет управление реактором
- Особенно проблематично после остановки

### 9. Мощность реактора

**Что это:** Количество энергии, выделяемой в единицу времени.

**Единицы измерения:**
- **МВт** (мегаватт) - электрическая мощность
- **МВтт** (мегаватт тепловой) - тепловая мощность
- **Относительная мощность** - доля от номинальной (1.0 = 100%)

**Типичные значения:**
- **Номинальная мощность:** 1000-1500 МВт электрических
- **Тепловой КПД:** ~33% (остальное тепло в охлаждающую воду)

### 10. Безопасность

**Принципы безопасности:**
1. **Отрицательная обратная связь** - при повышении температуры реактивность снижается
2. **Запаздывающие нейтроны** - позволяют управлять реактором
3. **Системы аварийной защиты** - автоматическая остановка при авариях
4. **Множественные барьеры** - защита от выхода радиоактивности

**Аварийная остановка (SCRAM):**
- Быстрое введение всех стержней безопасности
- Остановка цепной реакции за секунды
- Срабатывает автоматически при авариях

## Как использовать эти понятия в симуляторе

### В коде симулятора:

```python
# Реактивность реактора
rho = 0.001  # 0.1% надкритичности

# Плотность нейтронов (относительная мощность)
n = 1.2  # 120% от номинальной мощности

# Позиция стержней (0 = полностью введен, 1 = полностью извлечен)
rod_position = 0.3  # 30% извлечен

# Температура топлива
fuel_temp = 600  # °C
```

### Типичные сценарии:

1. **Запуск реактора:** Постепенное извлечение стержней до критичности
2. **Изменение мощности:** Точное управление стержнями
3. **Остановка:** Быстрое введение всех стержней
4. **Отравление ксеноном:** Компенсация снижения реактивности
