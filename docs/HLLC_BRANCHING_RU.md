# Разветвлённая жидкостная сеть HLLC

Срез: 10 ноября 2026. Стенд расширяет проверку после
[прямого RHS](HLLC_DIRECT_RHS_RU.md) на четыре неподвижных узла давления,
пять неоднородных труб и два независимых цикла графа.

## Постановка

Соединения: a→j, j→b, c→j, b→a, c→a. Длины труб соответственно
1,2 / 0,9 / 1,4 / 2,0 / 1,7 м; диаметры 0,05 / 0,04 / 0,03 / 0,025 / 0,02 м.
Начальные давления узлов a/j/b/c: 4,04 / 4,00 / 3,98 / 4,01 МПа;
температуры: 441 / 440 / 439 / 442 К. В трубах начальные профили линейные.
Жидкостный режим адиабатический, без трения и внешнего нагрева.

Матрица включает покой с двумя ячейками на трубу и противоток в j→b
с двумя и четырьмя ячейками. Начальная скорость противотока −0,005 м/с.
Массово-взвешенная средняя скорость этой ветви естественно становится
положительной и к 2 мс достигает примерно +0,006 м/с.

Для каждой конфигурации выполнены два нативных расчёта с ограничением шага
5 и 2,5 мкс и независимые временные решения Radau/BDF. Сравниваются
состояния и интегралы потоков в 0; 0,1; 0,25; 0,5; 1; 2 мс.
Точное восстановление checkpoint проверяется в 1 мс.
Всего — шесть основных нативных траекторий и шесть независимых временных
решений; ещё одна нативная траектория меняет ориентацию трубы j→b.
Из двенадцати сравнений абсолютная приёмка обязательна для шести
на меньшем шаге. Результаты грубого шага сохранены отдельно. В завершённом прогоне прошли
все 12 сравнений, включая шесть обязательных на меньшем шаге.
Radau/BDF используют общий EOS и ту же пространственную постановку:
это независимая временная проверка, а не экспериментальный эталон.

## Балансы и ориентация

Контролируются масса, энергия, энтропийный учёт, положительность запасов,
нулевой импульс неподвижных узлов и точный restart. Узловые реакции
восстанавливаются из интегралов тензора потока импульса на портах;
допуск их невязки и общего осевого баланса — 10⁻⁹ кг·м/с.

При смене ориентации трубы переставляются её ячейки и привязка стенки,
меняются знаки скорости, импульса, потоков массы и энергии. Знак тензора
потока импульса сохраняется. Состояния остальных труб и узлов должны
совпадать в закреплённых допусках. Чужой checkpoint отклоняется без
изменения состояния модели.

Узловые реакции здесь скалярные и привязаны к локальным осям портов.
Их сырые значения не обязаны сохраняться при смене оси. Это не модель
трёхмерной силы в тройнике и не квалификация местных гидравлических потерь.
Нагрев, кипение, двухфазное трение и экспериментальная валидация этим
стендом не принимаются. Производственные уравнения в данном блоке не менялись.

## Надёжность самой проверки

Добавлены 18 тестов постановки, изменения оси и повреждения входных данных.
Искусственные NaN, сдвинутые времена, нулевые запасы, неполные ledger-массивы
и подмена геометрии должны приводить к отказу проверки. До исправления
валидатора восемь таких тестов выявляли недостаточную строгость; это
не было наблюдаемым отказом физического расчёта. Исходный положительный
физический прогон сохранён, матрица повторена со строгим валидатором.

## Итог поставки

Пройдено 1057 тестов, все восемь фаз локальной поставки. Проверены
1451 файл wheel и 788 ресурсов. Две выбранные нативные траектории
(исходная и с обратной осью) точно повторены из свежего установленного
wheel вне checkout, с изолированным запуском Python. Полная матрица
независимых решений из wheel повторно не запускалась.
Максимальная невязка портовых реакций основных траекторий —
7,3·10⁻¹⁴ кг·м/с; общего осевого баланса — 2,9·10⁻¹⁴ кг·м/с.
Подпись производственного ядра совпадает с предыдущим срезом v16.

## Воспроизведение

```bash
python -m pytest -q tests/test_hllc_branching.py
python -m scripts.verify_hllc_branching --output artifacts/my-branching
python -m scripts.verify_local_library --suite library --output artifacts/my-delivery
```

Полные локальные результаты: `artifacts/hllc-branching-v2/`.
Публичный протокол и результаты: [benchmark v17](benchmarks/hllc_branching_benchmark_v17.json).
Остальные исторические испытания не считаются автоматически повторёнными
этим стендом. Следующий физический шаг — отдельная квалификация потерь
и нагрева разветвлённой сети, затем более длительные переходные процессы.
