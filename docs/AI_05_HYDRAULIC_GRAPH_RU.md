# Стационарная гидравлика разветвлённых сетей

Инженерный решатель `scripts/solve_hydraulic_graph.py` расширяет AI-05.03
на связные графы до 128 узлов и 512 рёбер: ветвления, параллельные линии,
несколько границ давления, заданные подачи/отборы, обратный и нулевой поток,
заданный напор и гидростатика. Это отдельный препроцессор, а не новый
динамический backend существующего компилятора `core/network.py`.

## Физический контракт

Плотность постоянна и едина для всей сети. В каждом ребре расход m
положителен от `from` к `to`; давление — абсолютное, в Па:

```text
p_from - p_to + prescribed_gain - rho*g*(z_to-z_from)
    = L*m + R*m*abs(m)
sum(outgoing m) - sum(incoming m) = injection
```

L > 0, R >= 0. Единицы L — Па·с/кг, R — Па·с²/кг².
Заданная подача положительна внутрь узла из внешнего источника.
В узле задаётся ровно одно: давление или подача. У границы давления
подача вычисляется из баланса; скрытой границы или опорного давления нет.
Параллельные рёбра допускаются, самопетли и несвязные острова отклоняются.

`pressure_gain_pa` — фиксированный ориентированный источник перепада,
который может отдавать либо поглощать механическую мощность при реверсе.
Он не моделирует характеристику насоса, КПД или вал. Сопротивления —
входные коэффициенты, а не квалифицированная корреляция конкретной трубы.

Обязательное L > 0 обеспечивает конечную положительную проводимость
даже при m=0. Чисто квадратичные сопротивления, идеальные открытые линии,
обратные клапаны и переключения активных ограничений здесь не поддержаны.
Они не заменяются незаявленной регуляризацией.

## Численный метод и балансы

Монотонный закон ребра обращается устойчивой формулой без вычитания
близких чисел. Для свободных давлений решается массовая невязка; её
якобиан — взвешенный лапласиан графа с закреплёнными границами давления.
Диагональное масштабирование и проверка обусловленности выполняются
также для уже согласованной начальной догадки. Используется демпфированный
Ньютон с контролем уменьшения массовой невязки, без разгона во времени.

Строгая монотонность законов и хотя бы одна закреплённая граница в связном
графе дают единственность решения **этой постановки**. Это не доказательство
единственности общей теплогидравлической сети или произвольной EOS.
Промежуточные давления — математические итерации; физические ограничения
проверяются у конечного решения. Итерации не являются допустимой траекторией.

Проверяются исходные размерные уравнения каждого ребра и свободного узла,
общий массовый баланс всех внешних подач и механическая мощность:

```text
sum(p_node*injection_node/rho)
  + sum(gain_edge*m_edge/rho)
  + g*sum(z_node*outgoing_balance_node)
  = sum((L*m² + R*abs(m)³)/rho)
```

Последний член справа — диссипация. В тепловые запасы она здесь
не переносится: тепловых состояний в этой постановке нет.
Гидростатика при одинаковой плотности консервативна; замкнутый перепад
высот не создаёт циркуляцию без другого источника энергии.
Следовательно, AI-05.07 о совместно нагреваемой естественной циркуляции
этим блоком не закрывается.

Бюджет `validation/ai05_hydraulic_graph_budget_v1.json` требует невязки
массы в узлах и всей сети <= 1e-9 кг/с, давления <= 1e-6 Па,
механической мощности <= 1e-5 Вт. Плохая обусловленность или выход
давления из открытого пользовательского интервала дают отказ;
ограничения не удовлетворяются обрезкой состояния.

## Формат и запуск

Отдельный формат `atomic-hydraulic-steady`, schema 1, отклоняет неизвестные
поля. Пример: `examples/hydraulic_graph_steady.json`.

```bash
python -m scripts.solve_hydraulic_graph examples/hydraulic_graph_steady.json \
  --output artifacts/NEW_GRAPH_POINT
python -m scripts.qualify_hydraulic_graph --output artifacts/NEW_GRAPH_MATRIX
python -m scripts.qualify_hydraulic_graph --audit artifacts/NEW_GRAPH_MATRIX \
  --output artifacts/NEW_GRAPH_AUDIT.json
```

CLI сохраняет запрос, результат и manifest с SHA256 файлов, решателя
и бюджета. При отказе exit code 2, `diagnostics.json` вместо `solution.json`.
Существующий каталог не перезаписывается. Неизвестные поля и ошибочные
физические параметры также отклоняются. Передача результата в существующую
динамическую модель автоматически не реализована.

## Проверки и область доказательств

Матрица содержит 18 графов размером 3/8/16/32/64/128 узлов: линейные,
смешанные и с нулевыми/почти нулевыми расходами. Точные решения заданы
производством граничных данных из выбранных давлений и расходов.
Независимый эталон решает **полную смешанную систему давлений и расходов**
через MINPACK с последующим уточнением исходных невязок, не используя
обращение ребра или компилятор рабочего решателя.

Дополнительно аналитические тесты проверяют последовательные и параллельные
сопротивления, гидростатический столб, ориентацию, цикл с заданным напором,
механическую мощность и вырожденный якобиан. Аудитор пересчитывает решения,
проверяет полную матрицу, замороженные скрипты, бюджет и целостность файлов.
Подмена результата с пересчитанным хешем также отклоняется.

Первый прогон не принят из-за преждевременного завершения независимого
эталона на 64-узловом случае с почти нулевым потоком. Эталон дополнен
уточнением полной смешанной системы; допуски сравнения и физические
критерии не ослаблялись. Исторический лог сохранён в artifacts.

Это numerical verification редуцированной стационарной постановки.
Нет сжимаемости, теплового смешения, переменной плотности, фазовых переходов,
гидроудара, турбомашинной динамики или экспериментальной валидации.
`validated=false`, `plant_referenced=false`; общий AI-05.03 остаётся открытым.
