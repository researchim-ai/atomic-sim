# Переносимая поставка численных доказательств

Пакет включает wheel/sdist, точные инженерные скрипты, бюджеты, исходные
сценарии, траектории, checkpoints, фактические сетки решателя и отчёты.
Проверка целостности отделена от повторного численного аудита.
Старый расчёт не получает допуск для нового runtime из факта упаковки.

## Сборка одной командой

```bash
python -m scripts.primary_steam_release \
  --release artifacts/ai05_primary_steam_final_release_v2 \
  --steady artifacts/ai05_primary_steam_design_qualification_v3 \
  --steady-audit validation/ai05_primary_steam_design_audit_v1.json \
  --output artifacts/NEW_PRIMARY_STEAM_RELEASE.tar.gz
```

Для переходной матрицы используются дополнительные `--transient` и
`--transient-audit`. Все выбранные профили должны иметь один source fingerprint,
совпадающие producer/audit signatures и точный SHA256 исходного qualification.
Смешение переходной матрицы `68fb…` и стационарной `985b…` отклоняется.
При наличии frozen scripts/budgets используются они; fallback к скриптам
checkout разрешается только при совпадении обязательных хешей аудиторов.
Совпадение исходников wheel/sdist проверяется по содержимому архивов.

Профиль `--fixed`/`--fixed-audit` добавляет
[инициализацию при фиксированных командах](AI_05_FIXED_BOUNDARY_STEADY_RU.md).
Его численность выводится из объявленного budget; отдельные отрицательные
проверки должны присутствовать в принятом аудите. В пакет дополнительно
попадают точные initializer/qualification scripts и оба бюджета нового метода.

Команда печатает JSON с `archive_sha256` и `manifest_sha256`. Эти значения
следует сохранять с отчётом поставки отдельно от передаваемого архива.
Сам архив не является подписью издателя.

Универсальный `scripts.evidence_bundle create selection.json --output …`
принимает явный список `source/path` и может архивировать также непройденные
задачи. Наличие архива не превращает их в принятые. Формат selection:

```json
{
  "schema_version": 1,
  "bundle_id": "example-evidence-v1",
  "scope": "Declared numerical scope",
  "entries": [{"source": "validation/report.json", "path": "validation/report.json"}]
}
```

## Проверка и перенос

```bash
python -m scripts.evidence_bundle verify candidate.tar.gz \
  --manifest-sha256 TRUSTED_MANIFEST_SHA256
python -m scripts.evidence_bundle extract candidate.tar.gz \
  --manifest-sha256 TRUSTED_MANIFEST_SHA256 --output NEW_PAYLOAD
```

Эти операции не исполняют Python из payload и не устанавливают зависимости.
Сверяются точный набор файлов, размеры, SHA256 и, при наличии runtime,
единый fingerprint wheel/sdist. Без внешнего доверенного checksum проверяется
внутренняя согласованность; аутентичность издателя не доказывается.

Пути нормализованы, запрещены выход из каталога, ссылки, специальные файлы,
дубликаты, конфликты регистра и файлов/каталогов. Размеры ограничены:
10000 членов, 128 MiB на файл, 2 GiB суммарно, manifest до 8 MiB.
Вложенные runtime-архивы также ограничены. Существующие выходы не
перезаписываются; ошибка распаковки удаляет только созданный ею каталог.
Изменение входа между проверкой и извлечением обнаруживается повторным
подсчётом контрольных сумм. Создание архива публикует результат только после
проверки собранных байтов.

При одинаковых файлах, selection и наблюдаемом окружении архив имеет
одинаковые байты: порядок и JSON канонизированы, tar metadata и gzip mtime
фиксированы. Это не атомарный snapshot изменяемой рабочей папки: для
поставки выбираются завершённые неизменяемые расчёты.

## Повторный численный аудит

```bash
python -m scripts.replay_primary_steam_bundle candidate.tar.gz \
  --manifest-sha256 TRUSTED_MANIFEST_SHA256 --profile steady \
  --output NEW_REPLAY
```

В отличие от verify/extract, эта команда **исполняет замороженные аудиторы**
доверенной поставки. Для обеих матриц можно повторить `--profile` с `transient`.
Для фиксированных команд используется `--profile fixed`.
Это не sandbox для произвольного недоверенного Python.

Создаётся отдельная исходная рабочая папка из sdist; туда копируются
архивные бюджеты, скрипты и raw packets с исходными относительными путями.
`PYTHONPATH` внешнего checkout удаляется. Численный аудитор повторно
проверяет source, Python/numpy/scipy, входы, траектории, балансы, сетки,
рестарт и критерии. Полученный JSON должен полностью совпасть с архивным
принятым аудитом. Переписывание путей в исходном qualification не требуется.

Окружение зависимостей наследуется; пакеты не скачиваются. Внешние библиотеки
и их версии должны уже соответствовать исходному расчёту. `--wall-limit-s`
задаёт общий срок подготовки/запуска аудиторов; вычислительная часть
останавливается через subprocess timeout. Это не полноценная изоляция CPU,
памяти и пользовательской политики из AI-12.07.

Ошибка до запуска аудитора откатывает подготовку. Ошибка после запуска
сохраняет логи и `replay.json` с `passed=false`; она не даёт численного допуска.

## Состав inventory и границы приёмки

`INVENTORY.json` содержит метаданные проекта, Requires-Dist, наблюдаемые
версии/лицензионные поля distributions и окружение упаковки. Условные
requirements сохраняются как объявлены; это не разрешённый транзитивный
lockfile и не заявление соответствия SPDX/CycloneDX. Лицензионные поля
являются данными metadata, а не юридическим заключением. Собственный LICENSE
включается в пакет поставки.

Полные SBOM/constraints, проверка поддерживаемой OS/Python matrix, подпись
реального канала поставки и исполнение недоверенных политик остаются
отдельными задачами. AI-12.06 продвинут, но весь AI-12 не объявляется закрытым.
Численное воспроизведение не заменяет экспериментальную или объектную
валидацию: `validated=false`, `plant_referenced=false`.
