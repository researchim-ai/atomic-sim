# Пространственное уточнение нейтроники в связанной PWR — v133

[English](NEUTRON_MESH_EN.md) · [Предыдущие переходные процессы](MODERATOR_TRANSIENTS_RU.md)

Этот пакет проверяет чувствительность пространственного распределения
мощности и всех шести семейств предшественников к числу нейтронных ячеек.
Используется связанная `LocalModeratorPWRSession`: локальные температуры
топлива и плотность/бор теплоносителя участвуют в нейтронной производной,
а мощность деления возвращается в тепловую модель консервативно.

## Что именно уточняется

Расчёты используют 2, 4 и 8 равномерных нейтронных ячеек на длине 4 м.
Тепловая сетка топлива/оболочки `(0, 0.7, 2.2, 4)` и жидкостная сетка
`(0, 1, 2, 4)` остаются неизменными. Коэффициенты диффузии, рождения,
обратных связей, данные предшественников, граничные условия и оборудование
не меняются. Это **условное уточнение нейтронной сетки** при фиксированной
теплогидравлической дискретизации, а не сходимость всей установки по пространству.

На каждой сетке отдельно решается стационарная задача при одной заданной
мощности и одинаковых исходных ограничениях запасов. Пространственные
состояния и найденная исходная позиция стержня могут отличаться; позиции
сохраняются в протоколе. Подгонки коэффициентов нет. Затем на каждой сетке
задаётся одинаковое приращение доли ввода `+0.01` от её стационарной позиции.
Абсолютные команды поэтому не объявляются тождественными.

Наблюдения: `0`, `0.1`, `0.5`, `1`, `2 с`. Все три сетки рассчитываются
с двумя настройками времени: `max_step_s=0.1, rtol=2e-8` и
`max_step_s=0.05, rtol=2e-9`. Восемь узлов — максимально разрешённая
нейтронная сетка этого адаптера. Она служит численным ориентиром,
а не доказанным решением непрерывной задачи.

## Как сравниваются разные сетки

`coupling.mesh_comparison.profile_error` вычисляет точные нормы разности
кусочно-постоянных реконструкций на перекрытиях ячеек:

```text
L1 = sum(overlap[j,i] * abs(a[i]-b[j])) / length
L2 = sqrt(sum(overlap[j,i] * (a[i]-b[j])**2) / length)
Linf = max(abs(a[i]-b[j])) на непустых перекрытиях
```

Интегральная мощность ячейки сначала делится на её длину. Сравниваются
линейные плотности мощности в Вт/м с общей нормировкой `P_initial / length`.
Для каждого семейства предшественников сравниваются средние поля отдельно;
общая для всех сеток нормировка — начальное среднее этого семейства на
восьмиузловой fine-сетке. Поля разных семейств не складываются.

Оператор не усредняет мелкую сетку на грубую перед вычислением ошибки.
Это существенно: поле `[+1, -1]` и нулевое поле имеют одинаковый интеграл,
но ненулевые пространственные нормы. Такая ошибка не должна исчезнуть
из-за компенсации знаков. Отдельно сохраняется знаковая разность интегралов.
Несовпадающие границы, нечисловые значения, неверная семантика данных,
неположительная нормировка и непредставимый результат отклоняются.

Для представимых очень больших величин промежуточное возведение в квадрат
не должно переполняться: вычисление норм масштабируется до суммирования.
Масштаб вычисления зависит от разности полей, а не от пользовательской
нормировки: ошибка `1e-100` остаётся представимой даже при нормировке `1e300`.
Вычитание выполняется до масштабирования, поэтому одинаковый большой фон
также не скрывает малую локальную ошибку.
Тесты включают ручные интегралы на несовпадающих сетках, сохранение формы,
различие мощности и плотности, знакопеременную ошибку и все шесть семейств.

## Критерии приёмки

Сохраняются полные снимки, checkpoint и ошибки каждого времени наблюдения.
Итоговые критерии применяются к максимальной ошибке по всем этим временам,
включая начальное состояние:

- нормированная L2-ошибка 4/8 не больше `0.05` для мощности и каждого семейства;
- максимум L2 для 4/8 не больше `0.9` максимума для 2/4;
- пространственное различие 4/8 не менее чем в 20 раз больше coarse/fine
  L2-различия времени, проверенного на всех трёх сетках;
- разность полной мощности 4/8 не больше `1e-3` начальной мощности;
- coarse/fine-расхождение полного связанного состояния не больше `1e-4`;
- одинаковая начальная мощность, неизменные тепловые сетки и ненулевой
  пространственный отклик: размах относительного потока не меньше `0.01`;
- стационарные невязки и ранг, прежние балансы массы/энергии/бора и
  нейтронов/предшественников, замороженная опора и перенос запасов;
- точный JSON-restart восьмиузлового fine-расчёта на `0.5 с`, полный журнал
  прибытия стержня и rollback недопустимой команды.

Балансовые проверки заново вычисляются из снимков. Численный порядок
сходимости и ошибка до непрерывного предела не выводятся из трёх сеток.
Шесть дополнительных отрицательных контролей изменяют только копии
сохранённых данных: нарушают энергобаланс, шестое семейство, полноту матрицы,
коэффициент диффузии, результат restart или замороженную опору.
Каждое нарушение должно отклоняться; исходные траектории не перезаписываются.
Контракт также не подтверждает любой другой сценарий или дешёвую замену
всей модели: NPP-12.04 этим пакетом не закрывается.

Принятая поставка: **111 целевых тестов и 66 тестов из wheel**, восемь успешных фаз, научный JSON совпал целиком. Максимальная нормированная L2 мощности: **0.00949610 → 0.00468011** для 2/4 → 4/8. Максимальное расхождение полного состояния по времени — `1.55566e-07`; исходные значения для каждого времени и семейства сохранены в протоколе.

## Воспроизведение и границы

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  python -m scripts.verify_component_delivery --component neutron-mesh \
  --output artifacts/neutron-mesh-local --phase-timeout-s 1200
```

Каталог вывода должен быть новым. Профиль выполняет целевые тесты и шесть
траекторий, строит sdist → wheel, устанавливает пакет в свежую среду
с локальными научными зависимостями и повторяет тесты и расчёты вне checkout.
Полный научный JSON должен совпасть. CI и сеть не используются.
[Протокол v133](benchmarks/neutron_mesh_v133.json) содержит метрики и хеши.

Модель по-прежнему использует синтетические одногрупповые данные и
иллюстративные обратные связи. Это не независимая кодовая или экспериментальная
валидация. Замыкания, уточнение тепловой/жидкостной сетки, борный переходный
процесс, StationEnv и длительные режимы остаются отдельными работами.
Полный библиотечный профиль и новый часовой режим здесь не выполняются.
Статус корневого плана — **58/76, открыто 18 задач**.
