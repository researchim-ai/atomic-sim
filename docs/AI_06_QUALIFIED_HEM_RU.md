# AI-06: активные термодинамические области и pre-CHF HEM

Новый движок `atomic_model_hem_qualified` расширяет численно проверяемую область HEM. Старые source-bound семейства и их checkpoints сохраняются. Это численная верификация открытого моделёра, а не экспериментальная валидация установки.

## Термодинамика: AI-06.02/04

Прямые области IF97 1/2/4 и обратное преобразование `(rho,u)` используют одинаковые коэффициенты. Диапазон адаптера: **0,1–16 МПа, 300–900 К**, без области 3, критической точки, метастабильных состояний и сверхкритики. Для динамики нужен дополнительный запас давления 100 Па с каждой стороны; локальная скорость ограничена Mach 0,2 и заявленной границей характеристик. Точка 15,5 МПа / 600 К включена как проверка повышенного давления; соответствие конкретной установке этим не доказано.

Обратная EOS решает уравнения в активных координатах `(p,T)` или `(p,x)` damped Newton с аналитическим Якобианом. Нелинейные пробные точки могут пересекать насыщение; принимаются только физические состояния, прошедшие прямую проверку **обоих** запасов: относительная невязка плотности ≤2e-12 и энергии ≤2e-6 Дж/кг. Запасы, давление и качество не обрезаются. Кандидаты на границе области также обязаны удовлетворять обоим уравнениям.

Производные однородных фаз получены из потенциала Гиббса, двухфазные — из обратного Якобиана смеси и производной фактической кривой IF97 region 4. На `x=0/1` пользователь явно выбирает сторону производной. Точная формула Клапейрона не подменяет производную приближённой согласованной аппроксимации IF97. Проверка энтропии на траекториях не является доказательством глобальной энтропийной устойчивости.

Источники: [официальный IF97](https://iapws.org/relguide/IF97-Rev.html), неизменённые коэффициенты `physics/materials/iapws.py`. Нормативные однофазные контрольные точки и разностные производные проверяются отдельно от динамики.

## Замыкания: AI-06.05

Версия новых замыканий: `qualified-hem-closures/1.0.0`.

- Трение: гомогенная no-slip смесь с McAdams либо Cicchitti для вязкости; отдельный явный выбор Churchill или Colebrook. Все предположения о прямой круглой трубе, развитом квазистационарном течении и равновесии задаются строгими булевыми attestations. Colebrook сохраняет отказ в переходном диапазоне; Churchill является другой выбранной моделью. Трение снимает импульс, сохраняет полную энергию и учитывается в энтропийном журнале.
- Кипящая теплоотдача: **`chen-inl-documented-hfg025`**, конкретный вариант [документации INL BISON](https://mooseframework.inl.gov/bison/source/materials/CoolantChannelMaterial.html), с показателем теплоты парообразования 0,25. Это не выдаётся за буквальную исходную формулу Chen с другим показателем. Поверхностное натяжение — [IAPWS R1-76(2014)](https://iapws.org/documents/release/Surf-H2O.download).
- CHF: существующий низкодавленческий куб 1995 сохранён; добавлены 18 углов при **15–16 МПа, G=1000–2000 кг/(м²·с), x=0–0,1, D=8 мм**. Кусочно-трилинейная интерполяция не соединяет разрыв между низким и высоким давлениями. Источник — [IAEA-TECDOC-1203](https://www-pub.iaea.org/MTCD/Publications/PDF/te_1203_prn.pdf), Table II.I; координаты, единицы, хеш и протокол чтения — в `validation/ai06_hem_qualified_chf_curation_v1.json`. Это ограниченный фрагмент, не полная таблица.
- Дополнительный CHF `biasi_inl` следует опубликованному варианту INL в пересечении диапазонов: p=0,27–14 МПа, G=100–600 кг/(м²·с), x=0–0,1, D=5–37,5 мм, L=0,2–6 м. Верхняя граница G следует буквальному значению документации; более широкая область не предполагается.

Кипящая стенка допускается только для насыщенной влажной смеси, вертикального восходящего потока, равномерного нагрева и пренебрежимо малого гидростатического перепада (`rho*g*L/p<0,01`). Гравитация в уравнения графа не добавлена. Дополнительно: перегрев стенки 0–10 К, Re жидкой фазы 1e4–5e6, Pr=0,7–100. Требуется явный выбор CHF; при выходе из области или достижении заданной доли CHF (не более 0,8) расчёт отклоняется транзакционно. Post-CHF, dryout-теплоотдача и конденсационная корреляция не подставляются автоматически. Ограничение доли CHF — вычислительный envelope, не калиброванный запас безопасности/DNBR.

Учитывается как коэффициент теплоотдачи, так и дифференциальная проводимость `dQ/dTw` при проверке заявленной границы шага. Обмен стенка/жидкость консервативен.

**Неопределённость всех двухфазных замыканий не откалибрована:** доверительный интервал не назначен. Разброс McAdams/Cicchitti на 21 фиксированном состоянии — чувствительность к выбору модели, не экспериментальная погрешность. Происхождение и ограничения прежних законов трения сохранены в `AI_06_HOMOGENEOUS_FRICTION_RU.md`.

## Численная квалификация: AI-06.07

Проверено 123 новых теста и 296 связанных прежних тестов; общая portable-регрессия проекта этой итерацией не заменяется.

Воспроизводимый протокол находится в `atomic_model_hem_qualified/qualification.py`, критерии — константа `CRITERIA`:

- движущиеся точные `x=0/1`, выход смеси в жидкость/пар, вход пара в смесь, повышенное давление, два кипящих сценария и онлайн-нагрев;
- независимая сборка абсолютных запасов и потоков с DOP853/Radau; общая EOS явно остаётся общей, это не независимая термодинамическая модель;
- уменьшение временного ограничения вдвое и сравнение с IVP; оценка отношения ошибок только выше явно заданного численного шума;
- пространственная самосходимость гладких однофазной и двухфазной задач на 4/8/16/32/64 ячейках на ветвь, консервативное приведение к общей сетке; 64 ячейки — конечный численный ориентир, не точное решение PDE;
- положительность массы на каждой стадии, невязки массы/энергии, энтропийное неравенство с опубликованным абсолютным допуском, восстановление checkpoints полным повторением истории.

Сеть допускает 2–32 конечных узла, 1–32 ветви, 2–64 ячейки на ветвь, до 256 жидкостных объёмов и 16 стенок. Узлы остаются неподвижными объёмами смешения, не безынерционными тройниками и не многомерной моделью импульса. Увеличение лимитов не доказывает точность произвольной топологии.

Команды из корня проекта:

```bash
python -m atomic_model_hem_qualified demo --output artifacts/qualified_demo.json
python -m atomic_model_hem_qualified replay artifacts/qualified_demo.json
python -m atomic_model_hem_qualified qualify --output artifacts/qualified_campaign.json
python -m atomic_model_hem_qualified audit artifacts/qualified_campaign.json
pytest -q tests/test_hem_qualified.py
```

CLI не перезаписывает существующий результат; digest и хеши исходников проверяются до повторного расчёта. Любое изменение исходников семейства требует новой квалификации. Файл примера `examples/qualified_hem.json` содержит запрос и последовательность вызовов Python API `QualifiedHEMNetwork`.

## Что остаётся внешним доказательством

Экспериментальные динамические двухфазные данные с исходными условиями, измерительной неопределённостью и правами на распространение; калибровка диапазона/ошибки Chen и CHF; проверка представительности для целевой установки; независимая предметная экспертиза. Это отдельные открытые работы AI-06.06/AI-09, их нельзя закрыть совпадением двух интеграторов.

## Переносимое свидетельство

`validation/ai06_hem_qualified_summary_v1.json` содержит границы и сводку;
`validation/ai06_hem_qualified_installed_v1.json` — точные команды и результаты
проверки установленного wheel вне checkout. Сборщик
`python -m scripts.build_hem_qualified_evidence --output artifacts/qualified_evidence.tar.gz`
проверяет источники и установленную квалификацию, включает wheel/sdist,
численные результаты, исходники для ревью и прежние checkpoints, затем
проверяет целостность и побайтовую детерминированность повторной сборки.

В распакованном архиве можно установить `runtime/*.whl` в отдельный venv с
зависимостями и запустить его Python:
`verification/verify.py verification_inputs receipt.json`.
Проверка повторяет численную квалификацию, 123 теста и оба прежних replay.
Одна машина с общими зависимостями не считается независимой аппаратной/OS-матрицей.
