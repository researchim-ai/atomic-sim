# Переиспользование оператора теплообменника — v144

Продолжение: [разреженная стационарная инициализация и LU-кэш v145](SPARSE_STEADY_RU.md).

[English](EXCHANGER_CACHE_EN.md)

Добавлен опциональный `CachedTwoStreamExchanger`. Он ускоряет повторные шаги
существующего теплообменника с двумя потоками и тепловой инерцией стенки.
Исходный `TwoStreamExchanger` остаётся реализацией по умолчанию. Уравнения,
массы, теплоёмкости, проводимости, направления потоков и независимые
энергетические интегралы сохраняются.

```python
from physics.thermal.cached_exchanger import CachedTwoStreamExchanger

model = CachedTwoStreamExchanger(configuration, boundary_controls,
                                initialization, cache_entries=8)
row = model.advance(0.1)
info = model.cache_info()
model.clear_cache()  # Не меняет физическое состояние.
```

## Что переиспользуется

При постоянных свойствах `T'=A*T+b`. За шаг интегрируются приращение
температуры `dT` и отдельные клеточные интегралы энергии `I`. Начальная
производная `v=A*T0+b` включается в расширенную линейную систему:

```text
dT' = A*dT + v
I'  = C*A*dT + C*v
v'  = 0
```

Кэш хранит только отклик `dT,I` на начальное `v` для данного шага. Он не
хранит физические состояния или готовые ответы для округлённого режима.
Ключ включает точный `dt`, байты матрицы `A` и теплоёмкостей `C`.
Изменение расхода, направления или коэффициентов требует другого оператора.
Входные температуры меняют `b` и текущую производную; при неизменной
матрице отклик можно переиспользовать, но производная пересчитывается.

Интеграл энергии не заменяется разностью сохранённых состояний. Повреждение
его блока приводит к отказу проверки баланса. Температура и интегралы
фиксируются только после нативных допусков; при отказе физический snapshot
не меняется. Рассчитанный оператор и счётчики могут остаться в кэше.

## Память и restart

Кэш принадлежит одному экземпляру, имеет LRU-вытеснение и предел 1–32 записи
при 1–32 клетках. Максимальный удерживаемый полезный объём массивов и
байтов ключей — 7102464 байта. `cache_info()['bytes']` не включает накладные
расходы Python и временные массивы при вычислении экспоненты. Массивы
операторов помечены только для чтения; наружу статистика возвращается копией.

Кэш не сериализуется и не принимается из snapshot. JSON-restart строит
пустой кэш и точно повторяет суффикс. Поддержано чтение snapshot исходного
теплообменника. Очистка кэша не меняет состояние. Один экземпляр, как и
исходная модель, предполагает последовательное продвижение; независимые
экземпляры не разделяют кэш.

## Проверка и стоимость

Шесть пар траекторий сравнивают исходную и кэшированную реализации на
1/4/8 клетках. В каждом расчёте 20 шагов; проверяются противоток, смена
входных температур, реверс, возврат расхода, остановка и два значения шага.
Есть шесть точных restart. Тесты дополнительно охватывают 16/32 клетки,
изолированный аналитический режим, точность ключа, вытеснение, разные
теплоёмкости и повреждённые операторы. Шесть отрицательных контролей
изменяют копии научных результатов.

Стоимость измеряется отдельно от детерминированного научного JSON:
64 шага по 0.1 с, три повтора на 4/16 клетках. Сравниваются исходный solver,
кэш с одним заполнением и очистка кэша перед каждым шагом. Конструирование
модели не входит во время, первое заполнение входит. Полезность зависит
от повторения ключей: расчёт расширенного оператора без повторного
использования может быть дороже исходного шага. Это локальный короткий
benchmark, а не универсальная гарантия ускорения.

Принятая поставка: **57 тестов исходников и 27 тестов из wheel**, восемь фаз и полный научный JSON без расхождений. Максимальное отличие температуры — `5.6843419e-14 К`, клеточного интеграла энергии — `3.4924597e-10 Дж`. В шести траекториях получено 105 попаданий и 15 заполнений кэша; все шесть restart точные. Медианные локальные ускорения повторных шагов относительно исходного solver — **1.77× / 6.30×** на 4/16 клетках. [Машинный протокол с обоими измерениями](benchmarks/exchanger_cache_v144.json).

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  python -m scripts.verify_component_delivery --component exchanger-cache \
  --output artifacts/exchanger-cache-local --phase-timeout-s 1200
```

Нужен новый каталог. Профиль проверяет исходники, sdist → wheel, установку
вне checkout, тесты и полный научный replay. `performance.json` сохраняется
отдельно в source/installed: измеренные времена не обязаны совпадать.
Сеть и CI не используются, научные зависимости переиспользуются локально.

## Область применимости

Только существующий теплообменник с постоянными свойствами, фиксированными
массами, предписанным расходом и кусочно-постоянными граничными условиями.
Новых корреляций, фазовых переходов или гидравлического решения нет.
Ускорение не подключено к PWR/StationEnv и не закрывает разреженные
якобианы, переиспользование факторизаций или весь NPP-15.02. Экспериментальная
валидация и полный библиотечный прогон не заявляются. **58/76, открыто 18**.
