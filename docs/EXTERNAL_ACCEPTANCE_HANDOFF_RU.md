# Проверка пользователем на своём компьютере

Для open-source библиотеки достаточно воспроизводимого локального пути проверки.
Удалённый CI и отдельная физическая машина не являются условиями software-поставки.

Из корня исходников:

```bash
python -m scripts.verify_local_library
```

[Описание этапов и дополнительных наборов тестов](LOCAL_VERIFICATION_RU.md).

## Отдельные научные свидетельства

Для утверждений об экспериментальной точности нужны подходящие измерения,
конфигурация установки, единицы, native clocks, права на данные и описание
неопределённостей. Их нельзя получить из факта прохождения unit tests.

`atomic-uncertainty input.json --output report.json` считает интервалы по явно
заданной совместной covariance. Доступный manufactured пример проверяет метод,
а не точность относительно реального реактора. Неподтверждённые компоненты
неопределённости не заменяются нулями по умолчанию.

Независимый технический разбор остаётся отдельной необязательной для локального
запуска оценкой; отдельный ИИ-рецензент не запускался по решению пользователя.
