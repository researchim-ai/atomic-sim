# Атомарная последовательность действий агента — v102

`advance_hybrid_actions` выполняет от одного до шестнадцати действий `StationEnv` как одну проверяемую операцию. Все шаги сначала проходят на отдельной копии среды. Исходная среда обновляется только после приёмки каждого шага, общего энергетического бюджета и проверки неизменности исходников.

Это продолжение аудита отдельных агентных шагов и физического расписания. Здесь сохраняются именно штатные такты агента: наблюдения, работа регуляторов, награда, история команд и признаки завершения совпадают с обычными вызовами `StationEnv.step`. Проверочное уточнение работает на диагностических копиях и не увеличивает частоту работы регуляторов.

## Контракт выполнения

Перед расчётом проверяются формат действий и оставшийся горизонт эпизода. При позднем отказе возвращается `HeatEventError.receipt` с индексом действия, причиной и принятым диагностическим префиксом. Ни один шаг этого префикса не записывается в исходную среду. Вложенные квитанции шагов описывают принятие на временной копии; поле `prefix_committed_to_caller=False` явно отличает его от изменения среды вызывающего кода.

Штатное завершение или усечение эпизода разрешено на последнем запрошенном действии. Если эпизод заканчивается раньше, вся последовательность отклоняется: оставшиеся команды не исчезают из результата незаметно.

Общий бюджет суммирует абсолютные энергетические невязки всех шагов, поэтому ошибки разных знаков не компенсируются. Нормированный допуск сохранён равным 10⁻⁶. Дополнительно отклоняются нечисловые, бесконечные и отрицательные суммы дефектов. Доказательство с физическими внутренними состояниями помечено как `privileged_evaluator`; оно не добавляется к наблюдениям агента или публичному транспорту среды.

## Использование

```python
from atomic_model_station_env import StationEnv, EnvConfig
from atomic_model_station_hybrid_heat import advance_hybrid_actions

env = StationEnv(EnvConfig(max_steps=3, tick_s=.02,
                          automatic=False, rtol=1e-10))
env.reset()
transitions, proof = advance_hybrid_actions(env, [
    {"operator": {"feed_pump_on": False}},
    {"operator": {"feed_pump_on": True}},
    {},
])
```

Локальный воспроизводимый протокол, из корня репозитория:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. .venv-layout/bin/python -m scripts.qualify_station_hybrid_actions --output artifacts/my-hybrid-actions
```

Нужна новая выходная директория. Протокол проверяет закрытие питательного обратного клапана внутри первого шага, последующее включение насоса и завершение трёхшагового эпизода на 0,06 с. Открытие при повторном включении здесь относится к командной границе, а не к отдельно квалифицированному внутреннему корню. Продолжение из checkpoint после первого шага сравнивается с хвостом исходной последовательности.

## Ограничения

Запланированные неисправности пока не поддержаны. Приёмка короткой последовательности не распространяется на произвольные действия, циклы предохранительного байпаса в `StationEnv` или длительные режимы. Автоматическое регулирование сохраняет штатный механизм среды, но данный приёмочный сценарий использует ручные команды. Физический backend не изменён. Станционная приёмка остаётся 48/76; NPP-11.03/04 и полные задания NPP-14.03/04 этим этапом не закрываются.

## Результаты поставки

Прошли 62 целевых теста, включая 14 новых. Установленный вне репозитория wheel повторил 14 новых тестов и четыре JSON протокола целиком, без исключения полей. Подтверждены точное совпадение штатных переходов и checkpoint, внутреннее закрытие клапана, конец горизонта и продолжение из checkpoint. Полный набор тестов библиотеки не запускался.
