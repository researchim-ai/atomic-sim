# Независимая квалификация связанной первичной петли и парового цикла

Протокол реализован четырьмя инженерными скриптами:
`primary_steam_references.py`, `verify_primary_steam.py`,
`qualify_primary_steam.py`, `audit_primary_steam.py`.

Полная переходная матрица 53/17 прошла независимый повторный аудит
на замороженных исходниках из sdist: см.
[аудит](../validation/ai05_primary_steam_audit_v1.json) и
[поставку v2](../validation/ai05_primary_steam_delivery_v2.json).
Это историческое доказательство относится к fingerprint `68fb24c8…`,
с которым выполнены 1217 программных тестов.
Исправленная версия `985bb203…` отдельно прошла новую матрицу 53/17 и
[холодный frozen-аудит](../validation/ai05_primary_steam_audit_v2.json),
а также 14 стационарных прогонов и 1315 программных тестов.
[Поставка v3](../validation/ai05_primary_steam_delivery_v3.json) закрывает
AI-05.06 в объявленном редуцированном scope. Старые матрицы не переназначались
новому runtime автоматически.

Независимый reference интегрирует абсолютные температуры первичной жидкости
и стенок, расход/скорость насоса, абсолютные M/U паровых запасов и роторную
энергию. Уравнения насоса, адвекции, давления, теплообмена и турбины
выписаны отдельно. Производные, якобианы и интеграторы рабочей сборки
не вызываются; общая библиотека — IF97. Паровое равновесие решается
двумерным корнем по log(p)/качеству вместо рабочего скалярного обращения.

## Объявленная матрица

17 семейств дают 53 пакета: три уровня Radau для каждого и два
дополнительных BDF. Включены нагрев, отключение/реверс мотора, обратный
теплообмен, нагрузка, питание, охлаждение, паровой клапан, четыре
предельных семейства, изоляция и длительные совместные задачи 120/60/120 с.
Операционные задачи должны завершить весь заявленный горизонт; ранний
физический останов допустим только для явно перечисленных предельных задач.

Ограничение шага уменьшается в четыре раза, а допуски Radau сохраняются.
Фактическое отношение максимальных возвращённых шагов должно быть не менее
двух. Порядок по адаптивным сеткам не объявляется. Проверка выполняется
сразу после каждого семейства, чтобы непройденное уточнение останавливало
кампанию до дорогих длительных расчётов.

Аудитор проверяет полноту/уникальность матрицы, точные входы, версии,
SHA256, сетку, историю команд и физические остановы. Состояния
восстанавливаются из записанных величин; проверяются запасы и счётчики,
общий/подсистемные балансы, давления и полные энтальпийные потоки граней.
Контрольный checkpoint продолжается и сопоставляется с независимой задачей.
Подмена одного отчёта либо одновременно ошибочное рабочее наблюдение не
служат самостоятельным доказательством корректности.

Кэш reference ограничен восемью идентичными физическими начальными задачами.
Ключ включает все параметры, команды, горизонт, точность эталона и
абсолютное начальное состояние. Он исключает только имя и настройки
рабочего решателя/выходной сетки. Метрики каждого пакета вычисляются заново.

## Сохранённые отказы и исправления

Исходная развивающая траектория не прошла бюджет полного энтальпийного
потока 0.001 Вт. Усиление рабочего решателя снизило ошибку; сам бюджет
не изменён. Это сохранено в
[регрессии точности](../validation/ai05_primary_steam_precision_regression_v1.json).

Контроль временного уточнения отверг отношение шагов 1.791 для короткого
выхода по скорости. Предел шага этого семейства уменьшен; минимальное
требование 2 сохранено. См.
[регрессию сетки](../validation/ai05_primary_steam_mesh_regression_v1.json).

Затем первая полная матрица не прошла проверку реверса: почти одинаковая
ошибка на трёх рабочих сетках потребовала уточнения самого reference.
Четыре уровня независимой точности сравниваются на плотной временной сетке.
Выбранный эталон подтверждён ещё более строгим расчётом в пределах четверти
бюджета допуска; это отдельный критерий качества эталона, а не изменение
критерия рабочей сборки. См.
[сходимость эталона](../validation/ai05_primary_steam_reference_convergence_v1.json)
и [прослеживаемость исправления](../validation/ai05_primary_steam_reference_correction_v1.json).
Рабочая физика и сохранённые траектории при этом не менялись.

## Воспроизведение

```bash
python -m scripts.qualify_primary_steam --output artifacts/NEW_PRIMARY_QUALIFICATION
python -m scripts.audit_primary_steam artifacts/NEW_PRIMARY_QUALIFICATION \
  --output artifacts/NEW_PRIMARY_AUDIT.json
python -m scripts.verify_primary_steam_reference \
  artifacts/NEW_PRIMARY_QUALIFICATION/motor_reverse_fine \
  --output artifacts/NEW_REFERENCE_CONVERGENCE.json
```

Перенос завершённых raw-пакетов допускается через `--reuse-from` только
при совпадении исходников, Python/NumPy/SciPy, входа и SHA256 артефактов.
Незавершённые пакеты не переносятся; старый вердикт не используется.
Raw-пакеты и замороженные drivers/бюджеты необходимы для повторного аудита.
Они локальные и исключены из Git; одних JSON-сводок недостаточно.

Стационарная инициализация проверяется
[отдельной процедурой](AI_05_PRIMARY_STEAM_STEADY_RU.md).
Удалённая CI/platform matrix и измерения реального оборудования не
следуют из локальных проверок. `validated=false`, `plant_referenced=false`.
