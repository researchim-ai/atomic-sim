# Внутреннее открытие конденсатного клапана — v97

Добавлен воспроизводимый сценарий `prepare_condensate_reopening()` в существующий пакет `atomic_model_station_hybrid_heat`. Он проверяет открытие конденсатного обратного клапана **внутри физического интервала**, после изменения давлений. Это отдельный случай от открытия на границе команды насосу.

## Подготовка и переход

Используется исследовательская конфигурация `FeedConfig(condensate_inertance_m_inv=1.0)`, `rtol=10⁻¹⁰`, `max_step_s=0,01`. Все состояния получены штатным интегрированием: конденсатный насос отключается, сессия развивается до t=0,006 с, клапан закрывается, расход становится нулевым. Состояния и флаги не присваиваются вручную.

Затем насос включается с управляющим коэффициентом, рассчитанным из текущего противодавления: его предельный напор на 100 Па ниже этого противодавления. Непосредственно после команды клапан остаётся закрытым. По мере изменения давления в питательном баке движущий перепад достигает штатного порога открытия. В проверенном случае корень находится около t=0,012138903 с, внутри окна t=0,006…0,026 с.

Функция возвращает подготовленную физическую сессию, команду и рецепт с параметрами и исходными контрольными суммами. Это фиксированный исследовательский сценарий, не политика для агента и не калибровка оборудования конкретной станции. Подбор напора использует внутренние физические величины исключительно для подготовки проверочного случая.

## Проверки

На 8/16/32 подшагах проверяются обе стороны корня, баланс каждого участка, конечные запасы и полный вектор состояния относительно обычного расчёта, время события и сходимость интегралов. Все прежние допуски сохранены. Проверены точное совпадение инструментированного решателя с обычным, воспроизведение после checkpoint и отсутствие изменения исходной сессии диагностикой.

В контрольном расчёте доля напора насоса задаётся нулевой. Баланс проходит, но событие открытия отсутствует: сам факт подачи команды не засчитывается как физическое открытие.

Основной алгоритм гибридного адаптера и сборщик групп событий v96 не изменены. Добавление модуля сценария меняет отпечаток пакета; отчёт v97 содержит актуальные контрольные суммы. Старые отчёты сохраняются как свидетельства своих ревизий.

## Результаты поставки

Прошли **28 целевых тестов**, включая четыре новых. Установленный wheel вне репозитория повторил четыре новых теста и все шесть расчётных JSON. Полный набор тестов библиотеки в этом этапе не запускался. Проверены неизменность алгоритма адаптера и сборщика v96; добавлен отдельный воспроизводимый сценарий.

## Использование

```python
from atomic_model_station_hybrid_heat.scenarios import prepare_condensate_reopening
from atomic_model_station_hybrid_heat import record_hybrid_window

session, command, recipe = prepare_condensate_reopening()
report = record_hybrid_window(
    session, recipe["duration_s"], command, subdivisions=16,
)
assert report["passed"]
```

Локальный протокол:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. .venv-layout/bin/python scripts/qualify_station_condensate_reopening.py --output artifacts/condensate-reopening-local
```

Выходная директория должна быть новой. CI не требуется.

## Что не закрыто

Этот результат относится к короткому окну физической сессии. Он не квалифицирует внутреннее открытие питательного клапана, физический сценарий одновременных корней, предохранительные клапаны, длительные режимы или применение к реальной установке. Станционная приёмка остаётся **48/76**; новых закрытых станционных пунктов нет.
