# Исходный эталон производительности HLLC

`hem_contact_v13/` — неизменённые четыре файла контактного пакета до оптимизации
звуковых характеристик. Это проверочный fixture, а не второй поддерживаемый
runtime. Не редактировать и не использовать вместо текущего пакета из `src/`.

`hem_contact_v13_source.json` фиксирует SHA исходников и квалифицированного
основания. `scripts.benchmark_hllc_speed` проверяет их перед отдельным импортом.
Fixture сохранён в репозитории, чтобы воспроизведение не зависело от наличия
старого незакоммиченного checkout или локальной директории artifacts.
Численное окружение должно соответствовать зафиксированной подписи; другое
окружение требует собственной переквалификации основания.

`hem_contact_v14/` и `hem_contact_v14_source.json` фиксируют следующий baseline:
версия со звуковым кэшем, до быстрого жидкостного Newton-пути. Этот fixture
также используется только для измерений и проверки точного равенства.

`hem_contact_v15/` и `hem_contact_v15_source.json` сохраняют версию с быстрым
жидкостным EOS, до удаления неиспользуемого родительского транспорта HLLC.
В source-тестах сравниваются оба RHS на одном текущем основании; benchmark
дополнительно требует совпадения полной зафиксированной подписи окружения.
