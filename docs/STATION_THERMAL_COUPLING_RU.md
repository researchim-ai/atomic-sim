# Связанная тепловая динамика и плавучесть v80

Дата: 18 ноября 2026.

После [пространственного исследования v79](STATION_REFINED_DYNAMICS_RU.md)
добавлен `atomic_model_station_thermal`: совместная эволюция скорости,
температурного отклонения и давления в вертикальном периодическом канале.
Прежние гидродинамические компоненты и станционный backend сохранены.

**Приняты выбранные связанные конечномерные траектории и независимые
аналитические тепловые примеры. Общая нагреваемая трёхмерная постановка
ещё не прошла пространственную и сильную граничную квалификацию.**

## Уравнения и область применения

Используется безразмерная постановка Буссинеска с постоянными свойствами:

```text
div(u) = 0
u_t + (u·grad)u = -grad(p) + nu*lap(u) + b*theta*e_z
theta_t + u·grad(theta) = kappa*lap(theta) + Q
```

`theta` — отклонение от постоянной температуры стенки; `b` — подписанный
коэффициент плавучести. Положительное отклонение при b>0 ускоряет поток
вдоль +z. На стенке заданы отсутствие скольжения и theta=0; ось регулярна,
осевые условия периодические. Источник Q задан неподвижным полиномиальным
Fourier-полем. Режимы с заданным тепловым потоком на стенке этим API не
поддерживаются.

Это однофазная исследовательская модель. Она не вычисляет плотность
из EOS, не описывает кипение, CHF или изменение свойств с температурой.
Достаточность приближения Буссинеска для реальной установки отдельно
не установлена. Положительность абсолютной температуры не заявляется:
API оперирует подписанным температурным отклонением.

Регулярный скалярный базис имеет вид r^m(1-r²)L_j(r²), с нормировкой
по матрице массы. Температурный порядок ограничен 2..16, порядок скорости —
2..12; |k|≤2, m=0..2, не более 13 канонических мод и 1024 комплексных
коэффициентов. Общая радиальная квадратура содержит не менее 64 точек.
Проверяются обусловленность, положительность диффузии, реальные средние
моды и сопряжённость знакового спектра.

Температурная адвекция вычисляется через FFT с достаточным дополнением;
независимая прямая свёртка используется в тестах, эталонном интеграторе
и сильной диагностике. Направление связи двустороннее: температура
создаёт объёмную силу, изменившаяся скорость переносит температуру.

## Три отдельных баланса

Интегратор ведёт шесть интегралов: вязкую диссипацию, работу плавучести,
тепловую диссипацию, корреляцию температуры с источником, поступление
тепла и выходящий поток через стенку.

```text
E = 1/2 * sum_signed integral |u|² r dr
V = 1/2 * sum_signed integral |theta|² r dr
H = integral mean(theta) r dr

E(t)-E(0) + integral D_nu dt - integral W_b dt = 0
V(t)-V(0) + integral D_kappa dt - integral <theta,Q> dt = 0
H(t)-H(0) - integral mean(Q) r dr dt + integral F_wall dt = 0
F_wall = -kappa * partial_r mean(theta)(1)
```

Квадратичная величина V — половина нормы температурного отклонения
без вычитания среднего, **не внутренняя энергия**.
Работа плавучести учитывается как отдельный вклад; сохранение суммы
кинетической и термодинамической энергий этим не утверждается.

Дефекты первых двух балансов проверяются на каждом принятом шаге;
при превышении допуска решение отклоняется. Физический поток через
стенку вычисляется аналитической производной базиса, независимо от H.
Его дефект сохраняется отдельно. Постоянная тестовая функция не входит
в базис с нулевой температурой на стенке, поэтому малый слабый остаток
сам по себе не обеспечивает точный физический тепловой баланс.

Движок **не объявляет произвольную траекторию принятой по тепловому
балансу**. Эта проверка выполняется явно для квалификационных случаев.
Грубый расчёт сохраняет дефект тепла 5,251·10⁻⁷, хотя слабый баланс
скалярной дисперсии уже проходит допуск.

## Независимые физические примеры

Проверены затухающая температура и порождённое ею осевое движение:

```text
theta(r,t) = A*J0(a*r)*exp(-kappa*a²*t),  J0(a)=0
u_z(r,t) = b*A*J0(a*r)
           * [exp(-kappa*a²*t)-exp(-nu*a²*t)] / [(nu-kappa)*a²]
```

Для nu=kappa используется независимое предельное решение
u_z=b*A*t*exp(-nu*a²*t)*J0(a*r). Начальная скорость равна нулю.
Проверены разные коэффициенты диффузии, совпадающие коэффициенты
и обратный знак плавучести. При порядке 10 и t=0,1 ошибки скорости
и температуры не превышают 1,760·10⁻¹² и 5,071·10⁻¹³.
Для базового подробного случая дефект тепла — 2,922·10⁻¹⁷.

В стационарном примере:

```text
theta = A*(1-r²)
Q = 4*kappa*A
u_z = b*A/(16*nu) * (3-4*r²+r⁴)
```

Источник тепла равен выходящему стеночному потоку, работа плавучести —
вязкой диссипации. Этот ненулевой режим сохраняется при интегрировании
без подгонки состояния или поправок к энергетическим журналам.

## Нелинейная связь и независимое интегрирование

Для общих ненулевых Fourier-мод приняты короткие траектории до t=0,05.
Основной метод — BDF с разделением действительных и мнимых коэффициентов.
Разреженная квазиньютоновская матрица включает точные линейные вязкий,
тепловой и плавучий блоки; нелинейные и журнальные производные опущены.

Независимый временной эталон — DOP853 с прямой свёрткой обоих переносов.
При одинаковой конечномерной постановке разница с BDF/FFT составляет:

- Скорость: 1,376·10⁻¹¹.
- Температура: 2,694·10⁻¹⁴.

Оба показателя ниже допуска 10⁻⁸. Дополнительное ужесточение BDF даёт
согласованный результат. Отключение плавучести меняет скорость на
4,182·10⁻⁴ и температуру на 2,010·10⁻⁷ в физических L2-нормах.
Это подтверждает действующую обратную связь, а не наличие неиспользуемого
параметра. Сравниваются поля на независимой 128-точечной квадратуре.

Начальные коэффициенты копируются, входное состояние не меняется.
Продолжение из промежуточного результата проверено в пределах допуска;
история BDF не сериализуется, побитовый restart не заявляется.

## Что ещё не принято

В согласованном нагреваемом трёхмерном исследовании порядка 6→10:

- Разница скоростей — 1,420·10⁻⁴, температуры — 4,094·10⁻⁶.
- Остаток импульса на стенке — 1,644·10⁻².
- Температурный остаток на стенке — 2,596·10⁻⁴.
- Максимальный интегральный дефект физического тепла — 1,220·10⁻⁷.

Эти результаты **не проходят** соответствующие пространственные,
граничные и тепловые допуски. Они сохранены в машинном отчёте;
прохождение слабых балансов и временного эталона их не отменяет.
Сильная диагностика относится к сохранённым модам; давление вне
сохранённого спектра не восстанавливается. Общая PDE-квалификация
и экспериментальная валидация не заявлены.

Следующий физический этап — улучшить разрешение нагреваемого случая
с тем же начальным полем и проверить начальную совместимость со стенкой,
затем совместно пройти радиальное/Fourier-уточнение, сильный баланс
и физический поток. После этого — длительные режимы и статистика,
возврат к станционной матрице. Счётчик остаётся **48/76, открыто 28**;
NPP-11.03/04 и R1 открыты.

## Локальное воспроизведение

Из корня проекта, с установленной библиотекой, без CI:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
python -m scripts.qualify_station_thermal --output artifacts/my-thermal-study
python -m pytest tests/test_station_thermal.py tests/test_station_thermal_qualification.py
```

Каталог результата должен быть новым. Получаются четыре JSON:
протокол, физические примеры, нелинейная динамика и итог с контрольными
суммами исходников. Для повторного сравнения предусмотрен
`--reference artifacts/my-thermal-study`. Побайтное повторение проверяется
в зафиксированном локальном Python/NumPy/SciPy-окружении; одинаковые
байты на всех платформах и BLAS не обещаются.

[Машинный отчёт и результаты проверки поставки](benchmarks/station_thermal_v80.json).
