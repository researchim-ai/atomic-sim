# Каталог вариантов короткого цикла давления — v101

`atomic_model_station_hybrid_heat.catalog` позволяет проверять несколько явно заданных конфигураций одним запуском. Каждый вариант создаёт собственную физическую сессию и проходит атомарный аудит всей последовательности. Неуспешный вариант сохраняется вместе с причиной отказа и диагностическим протоколом; последующие варианты продолжают выполняться. Доля успешных расчётов использует все заявленные варианты в знаменателе.

## Что проверяется

Для каждой конфигурации обычный решатель независимо выполняет то же расписание. Затем проверяются три уровня уточнения 8/16/32, энергетические балансы, порядок и времена событий, точное совпадение конечного checkpoint с обычным расчётом, открытие и закрытие по давлению, остатки давления до 0,05 Па, возврат байпасного привода в ноль и два достижения позиции парового клапана. Все окна вместе должны достигнуть 0,022 с.

Каталог ограничен восемью вариантами. Идентификаторы проверяются; повтор одной физической конфигурации под разными именами запрещён. Параметры проходят проверку области допустимости самого оборудования. Изменение исходников во время прогона делает результат недействительным.

## Объявленные варианты

- `smaller-area`: площадь байпаса 0,029 м², время полного хода 0,1 с.
- `slower-actuator`: площадь 0,03 м², время полного хода 0,101 с.

Остальные параметры и шесть окон взяты из [протокола v100](STATION_RELIEF_CYCLE_RU.md). Это исследовательские параметры, не характеристики конкретной установки. Две принятые точки не квалифицируют непрерывный диапазон между ними. Фактический ход привода в этом коротком цикле частичный.

## Локальный запуск

Из корня репозитория, с установленными зависимостями:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. .venv-layout/bin/python -m scripts.qualify_station_cycle_catalog --output artifacts/my-cycle-catalog
```

Выходная директория должна быть новой. `catalog.json` содержит все результаты и полные проверочные траектории; `report.json` — сводку с хешем каталога. Если хотя бы одна конфигурация отказана, команда завершится ошибкой после сохранения результатов всех попыток. Автоматический CI не требуется.

## Границы результата

Этот этап расширяет численную проверку короткого цикла. Он не является экспериментальной валидацией, сравнением с другим симулятором или квалификацией длительных промышленных режимов. Промышленные задачи автоматически не закрываются: статус остаётся 48/76. Исторические sealed-протоколы сохранены; добавление модуля каталога меняет идентичность пакета, поэтому результаты v100 не выдаются за повторный прогон новой версии.

## Результаты проверки

Оба объявленных варианта приняты: 2/2, без исключённых попыток. Прошли 48 целевых тестов, включая 12 новых. Wheel установлен вне репозитория; повторены 12 новых тестов и оба JSON протокола с точным совпадением целых документов, без исключения полей. Полный набор тестов библиотеки не запускался. Физическая база и алгоритмы аудита не изменены.

Компактный протокол: [station_cycle_catalog_v101.json](benchmarks/station_cycle_catalog_v101.json).
