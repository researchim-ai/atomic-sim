# Двухфазное трение: гомогенные замыкания и чувствительность

Блок 1.69.0. Новый пакет `atomic_model_hem_mixture` расширяет прежнюю сеть отдельным движком `MixtureHEMNetwork`. Исходники и сохранённые артефакты предыдущих семейств не изменяются. Это numerical verification ограниченной постановки, не экспериментальная валидация двухфазного сопротивления.

## Законы и источники

Для равновесной воды/пара с одной скоростью и массовым паросодержанием x:

```text
McAdams:   1/mu = (1-x)/mu_liquid + x/mu_vapor
Cicchitti:   mu = (1-x)*mu_liquid + x*mu_vapor
Re = rho * abs(v) * D / mu
pressure_gradient = f_D * rho * v * abs(v) / (2*D)
force_density = -pressure_gradient
```

Уравнения выбора вязкости приведены в таблице 3 [первичной исследовательской статьи Lee–Mudawar](https://engineering.purdue.edu/mudawar/files/articles-all/2005/2005_1.pdf), DOI 10.1016/j.ijheatmasstransfer.2004.09.018. Статья исследует R134a в микроканалах и обсуждает ограничения HEM: её экспериментальная точность не переносится на нашу воду/пар. Исследование [Effective property models for homogeneous two-phase flows](https://doi.org/10.1016/j.expthermflusci.2008.07.006) рассматривает такие модели как эмпирические определения эффективных свойств, а не универсальную материальную вязкость смеси.

Здесь эти два определения соединены с прежним законом Дарси: 64/Re при Re<2300, численное Colebrook при 4000<=Re<=1e8. Это собственная явно объявленная композиция моделей. Fanning/Blasius из статьи Lee–Mudawar не выдаются за наш Darcy/Colebrook. Для `darcy_law="colebrook"` переходная область отклоняется. Это прежнее строгое поведение по умолчанию.

Явный `darcy_law="churchill"` включает отдельную формулу всех режимов из [оригинальной статьи Churchill 1977, eq.18](https://files.engineering.com/files/85c0f3a6-a102-4a22-9d35-f15858c0dd2b/CEM_-_Friction-factor_equation_%281977%29.pdf). Коэффициент автора умножается на 8 для формы Дарси, а не на 2 для Fanning. Производственная функция вычисляет большие степени в логарифмах без обрезания Re. Смена закона никогда не происходит автоматически; эмпирическая переходная ветвь не становится экспериментально подтверждённой для смеси. `Result.source` указывает источник вязкостной модели, `darcy_source` — выбранного закона сопротивления.

Свойства фаз берутся из IF97 и существующего транспорта IAPWS. Плотность соответствует равновесной EOS, не арифметической средней плотностей. Массовое качество не подменяется пустотностью. На x=0/1 оба закона точно возвращают свойства соответствующей насыщенной фазы. За границей фазовой области используется однофазная вязкость текущего состояния, без продолжения x за [0,1]. Нет проекции состояния или искусственного сглаживания границы.

## Балансы и допуск

Торможение входит только в уравнение импульса. Полная энергия жидкости сохраняется; потеря кинетической энергии увеличивает внутреннюю. Вязкое производство энтропии равно `-force*v/T` и неотрицательно. Импульс трения и энтропия интегрируются теми же RK-стадиями, что и запасы и прежние журналы граней/стенок.

Ламинарная сила вычисляется непосредственно через `32*mu*v/D²`: это устойчивый точный предел при v→0, без умножения бесконечного коэффициента на нулевую скорость. При покое коэффициент f возвращается как null, сила и производство энтропии точно нулевые. Состояние и scope проверяются также при нулевой скорости.

На выбранном ребре прежнее `friction` должно быть `none`: двойное включение Дарси отклоняется. Каждая стадия проверяет EOS, транспорт, Re и явное время релаксации торможения. Ошибка откатывает всю команду с состоянием контроллера. Checkpoint восстанавливается полным повторным расчётом; смена закона входит в digest входной постановки.

Область вычисления: прежняя ограниченная графовая геометрия, IF97 1/2/4, 0.1–10 MPa и 300–623.15 K в выбранных ячейках трения, при работе графа — прежний запас давления 100 Pa. Эти границы являются вычислительным допуском, а не экспериментально подтверждённым диапазоном двухфазной корреляции. Обязательные явные предположения: homogeneous_equilibrium, no_slip, circular_straight, fully_developed, quasi_steady. Булевы признаки — заявления вызывающего кода, не автоматическая классификация физического режима.

## Запуск

```bash
atomic-hem-mixture run examples/hem_mixture.json --output artifacts/my-mixture
atomic-hem-mixture replay artifacts/my-mixture
atomic-hem-mixture qualify --output artifacts/my-mixture-qualification.json
atomic-hem-mixture audit artifacts/my-mixture-qualification.json
```

Класс принимает `{schema_version:1, model:<прежний граф>, mixture_friction:{edge_id:{viscosity_model:"mcadams"|"cicchitti", scope:<пять признаков>}}}`. Для файлового workflow эта постановка находится в стандартном поле `model`, рядом с `program`. API управления, единицы, ревизии и транзакции сохраняются. `contract()` публикует выбор закона по рёбрам.

## Численные свидетельства и чувствительность

Квалификационный код содержит десять программ: оба закона смеси, реверс в ветвлении, насыщенные неподвижные жидкий/паровой пределы, два турбулентных случая, нагрев через исчезновение жидкой фазы и онлайн-мощности, а также явное прохождение переходной области Churchill. Каждый сравнивается с отдельными абсолютными m/P/E IVP DOP853/Radau на трёх временных ограничениях с точным JSON-restart. Независимый RHS переиспользует прежнюю отдельную реализацию графового эталона, самостоятельно вычисляет вязкость, решает Colebrook через brentq и вычисляет первичную формулу Churchill через logsumexp; рабочий RHS и рабочая функция трения не вызываются. EOS и научные зависимости общие. Для строгого inverse используются общие детерминированные попытки начального T с фиксированным p seed: 0, ±0.01 и ±1 K. Это только смена начального приближения: target rho/u и прежние forward-допуски не меняются; все неуспешные попытки заканчиваются отказом без проекции. Кэш эталона живёт только внутри одного RHS и очищается в finally.

Полная переходная квалификация движущихся точных x=0/1 пока не принята: воспроизведённый отказ inverse на движущемся насыщенном паре устранён строгими seed retries; длительный запуск на движущейся насыщенной жидкости прерван из-за стоимости. Это не доказательство численного расхождения и не заявляется физическим отказом. Сохранены scope/источник попытки в `validation/ai06_hem_mixture_pending_boundaries_v1.json`; квалифицируются отдельно неподвижные пределы и нагрев исходно двухфазной смеси через исчезновение жидкости.

Отдельные 21 состояния при трёх давлениях и семи качествах сравнивают оба закона при одном и том же массовом потоке 50 kg/(m²*s). Публикуется отношение градиентов, а не доверительный интервал. Такой spread характеризует чувствительность к выбору модели; он не заменяет неопределённости измерений и калибровки.

## Открытые задачи

Нужны независимые данные двухфазного трения, выделение гравитационного и ускорительного перепадов, проверка зависимости от геометрии/режима и slip. Кипящая теплоотдача, полная CHF, post-CHF, неравновесное вскипание и динамическая экспериментальная валидация остаются открытыми. Однофазное сравнение NIST из предыдущего блока не становится валидацией смеси после добавления этого движка.

Результат блока: 279 passed (53 новых, 226 связанных), отдельный installed-wheel прогон 53 passed, полная повторная квалификация 30 траекторий/20 IVP и совместимость старого graph checkpoint. Максимальное расхождение с IVP по давлению 0.001880 Pa, энергии ячейки 6.450e-5 J, скорости 4.110e-7 m/s. Максимальное отношение двух предсказанных градиентов в 21 фиксированном состоянии — 1.342287; это spread выбора модели, не измерительная неопределённость. Прежний полный portable-baseline 3724 не пересчитывался и не подменяется суммой частичных прогонов.
