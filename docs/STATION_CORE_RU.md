# Заменяемая нейтронная зона в станционной динамике

Текст фиксирует приёмку v41. [Следующий этап](STATION_PRIMARY_RU.md) проверяет первичный выбег и естественную циркуляцию при нулевом насосном напоре.

Дата: 12 ноября 2026. Продолжение [станции с конечным электропитанием](STATION_POWER_RU.md).
Новая сессия `PWRCoreSession`, model_id `npp-pwr-train-replaceable-core`.
Она поддерживает два встроенных владельца нейтронного состояния через
один интерфейс: `PointCore` и `DiffusionCore`.

Это реализация NPP-03.04 — интерфейса замены зоны. Она не является
валидацией пространственной модели конкретного энергоблока.

## Контракт и владение состоянием

Протокол `NeutronCore` определяет размер состояния, начальное отображение
из точечного состояния, вычисление производных, интегральное отображение
и мощность делений по ячейкам. Нейтронный блок добавляется в станционный вектор;
его размер определяет выбранный адаптер:

- точечная зона: амплитуда и шесть групп предшественников, всего 7 величин;
- пространственная зона: одна группа потока и шесть локальных групп
  предшественников в каждой ячейке, всего `7*N` величин.

Старые семь координат нейтронной кинетики остаются вычисляемыми
представлениями для совместимости теплогидравлического backend.
Они исключены из интегрируемых неизвестных. Единственный владелец
нейтронных состояний — новый блок; две независимые копии кинетики
одновременно не интегрируются.

После реконструкции каждого пробного состояния старые координаты
вычисляются из нового владельца. Для принятых состояний проверяются
согласованность представлений, неотрицательность каждой локальной
популяции и каждого предшественника. Отрицательная ячейка не может
скрыться за положительной суммарной мощностью. Значения не обрезаются.
Проверяются принятые узлы и прежняя дополнительная сетка 0,05 с;
это не непрерывное доказательство положительности Radau. Самостоятельный
положительный backward-Euler из пространственного пакета здесь не используется.
Для нейтронного блока задан отдельный абсолютный допуск `1e-10`;
тепловые энергии и пассивные интегралы сохраняют свои прежние масштабы.

Произвольный внешний адаптер может реализовать тот же программный
контракт, но его подключение к replay-сессии потребует регистрации
конфигурации, источников и собственной квалификации. В этой версии
воспроизводимо зарегистрированы только два встроенных варианта.

## Точечный адаптер

`PointCore` использует прежний `PointKinetics` без изменения физических
коэффициентов и нормировки мощности. Сравнение с `PWRPowerSession`
проверяет, что перенос состояния в новый блок сохраняет поведение
станции при изменении нагрузки и движении стержня. Совпадение оценивается
с численным допуском, поскольку расположение неизвестных и допуски
нейтронного блока меняют работу адаптивного интегратора.

## Пространственный адаптер

`DiffusionCore` вызывает существующий конечно-объёмный оператор
`atomic_model_spatial.Model.kinetics`. Это динамическая одномерная
диффузия, а не заранее заданный профиль или статический пересчёт формы.
Интегрируются относительный поток и локальные предшественники.

Выбрана одна энергетическая группа, отражающие концы плоского слоя и
равномерная сетка 2…8 ячеек. Нулевой опорный режим сконструирован
критическим: поглощение равно `nu_fission_per_m`. Диффузионный коэффициент,
геометрия и коэффициент делений задаются явно. Скорость построена из
существующего времени генерации как `1/(Lambda*nu_fission)`.

Сечения **синтетические**. Они не извлечены из оценённой библиотеки,
не являются эффективными константами BEAVRS/ВВЭР и не подогнаны под
измеренные распределения мощности. Шесть долей запаздывающих нейтронов
и постоянных распада скопированы из прежнего учебного набора проекта;
это не оценённые пространственные эффективные параметры установки.
В реестре перечислены источник, единицы и семейство `illustrative`.

Плотность/температура/бор и положение агрегированного поглотителя
по-прежнему дают прежний скалярный вход реактивности. Он применяется
ко всем ячейкам как изменение поглощения. Дополнительно конфигурация
может задать фиксированное линейное смещение:

```text
bias(x) = axial_bias_reactivity * (2*x/L - 1)
Sigma_absorption(cell) = nu_Sigma_fission * (1 - bulk_reactivity - bias(cell))
```

Параметры берутся в центрах ячеек; при уточнении сетки сохраняется одна
и та же пространственная функция. Поглощение должно оставаться
положительным. `bulk_reactivity` — вход этого замыкания, а не вычисленная
эффективная реактивность всей неоднородной зоны.

При ненулевом смещении начальный поток сохраняет равномерную форму,
а последующее установление профиля рассчитывается динамически.
Начальный стационар всей неоднородной станции не навязывается.

`reference_eigenpair` относится только к опорному оператору без скалярного
воздействия и без осевого смещения. Это не текущее `k_eff` станции.

## Нормировка и точечный предел

Относительный поток нормирован через мощность прежней зоны. Его нельзя
интерпретировать как измеренный абсолютный нейтронный поток.
Интегральная амплитуда — среднее потока с весами объёмов ячеек.
Эффективные точечные предшественники — соответствующее среднее локальных
предшественников, умноженное на скорость группы. Такая размерность
согласует локальные уравнения диффузии с прежними уравнениями кинетики.

При нулевом осевом смещении и одинаковом скалярном воздействии
интегральные уравнения сводятся к точечным: внутренние диффузионные
переносы сокращаются, отражающие концы не дают утечки. Это проверено
для 2, 3, 4, 6 и 8 ячеек. Отдельно проверяется баланс нейтронов и
предшественников при произвольном неоднородном профиле.

## Передача мощности тепловой модели

`fission_by_cell_w` — источник энергии делений по ячейкам. Его сумма
должна совпадать с мощностью, вычисленной по интегральной амплитуде.
Суммарный источник проходит через существующий учёт мгновенной доли
и трёх групп остаточного тепла, затем поступает в общий запас топлива.
Он не добавляется повторно поверх прежнего теплового источника.

Тепловая модель **остаётся пространственно свёрнутой**: одна температура
топлива, один запас оболочки и прежние объёмы теплоносителя. Нейтронная
форма может меняться, но это ещё не ячеечная температурная обратная связь.
Мощность делений ячейки не равна локально поглощённому теплу с учётом
всех запаздываний. Локальные температуры твэлов, запас до CHF и пределы
линейной мощности из этого профиля не вычисляются.

Следующий уровень потребует отдельных тепловых запасов, геометрии,
пространственных данных и проверки их обратной связи; он не закрывается
одним нейтронным интерфейсом.

## Restart и происхождение кода

Checkpoint сохраняет конфигурацию зоны, полное состояние и историю
станционных команд. Его fingerprint дополнительно включает исходники
импортированного пространственного решателя и точечной кинетики.
Изменение этих источников не принимается как тот же restart.

Восстановление повторяет команды, включая короткую потерю электропитания,
и проверяет полное совпадение состояния/представлений. Другой backend
станции не может принять этот checkpoint как собственный.

## Использование

```python
from atomic_model_station import CoreConfig, PWRCoreSession

station = PWRCoreSession(
    core=CoreConfig(kind="diffusion", cells=4, axial_bias_reactivity=1e-4),
    max_step_s=0.2,
)
observation = station.advance(0.5, {"load_fraction": 0.95})
print(observation["core"]["fission_by_cell_w"])
saved = station.checkpoint()
restored = PWRCoreSession.restore(saved)
assert restored.advance(0.1) == station.advance(0.1)
```

`CoreConfig()` выбирает точечную модель. Геометрия и сечения
конфигурации действуют только в пространственном варианте. Для пространственной явно
задаются `kind="diffusion"` и 2…8 ячеек. Внешние группы энергии,
геометрия реальных сборок, пространственное движение банков,
выгорание и спектральная обратная связь здесь не реализованы.

## Локальная программа приёмки

```bash
python -m pytest -q tests/test_station_core.py
python -m scripts.qualify_station_core --output artifacts/my-station-core
```

До расчёта сохраняются критерии и происхождение кода. Программа включает:

- 3600 с станции с четырёхъячеечной зоной и синтетическим осевым смещением;
- точечный предел и сравнение с прежней станцией при нагрузке/движении стержня;
- три настройки интегратора для связанного перехода;
- замороженный нейтронный переход против независимо собранной плотной
  матрицы и её экспоненты;
- сравнение 2/4/8 ячеек при одной функции смещения;
- JSON-restart и короткую совместную потерю электропитания.

Сравнение сеток проверяет ограниченное расхождение; формальный порядок
пространственной сходимости связанного станционного решения не заявлен.
Прежняя самостоятельная квалификация диффузионного решателя не заменяет
экспериментальную валидацию нового связанного объекта.

Повтор установленного wheel вне checkout доступен с
`--reference /absolute/path/to/source-run`: все JSON-результаты должны
совпасть. Сеть и CI не нужны; переиспользуются локальные научные зависимости.
В этой области принимается только NPP-03.04. Полные пакеты B/C,
станционная R1 и пространственная валидация реальной установки остаются открытыми.
