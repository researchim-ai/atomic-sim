# Разбор фазового расхождения: коэффициенты IF97 и время события

Продолжение: [производные насыщения и устранение остаточных 135 нс](MSL_SATURATION_TANGENT_RU.md).
Следующий блок объяснил различие касательной Клапейрона и производной
реализованной IF97-кривой. Диагностическая копия с обоими исправлениями
принимает 8/8 времён; приведённые ниже исходные и коэффициентные результаты
сохранены как история контролируемого эксперимента.

## Причина установлена для проверенной версии MSL

В используемой копии **Modelica Standard Library 4.1.0**, commit
`7a4bf7de77a3986e8eb1e88cbb515d646f78f834`, девять литералов идеальной части
функции `BaseIF97.Basic.g2` отличаются от нормативных значений.
Сравнение выполнено с **таблицей 10, уравнением 16**, стабильного региона 2
[IAPWS R7-97(2012)](https://iapws.org/technical-guidance/release/IF97-Rev.download).
Коэффициенты метастабильного уравнения 18 здесь не применяются.

Например, нормативное второе значение `10.086655968018`, а в проверенном
MSL-выражении записано `10.0866556801800`. Все девять пар, показатели степеней
и SHA конкретного файла сохранены в протоколе аудита. Это вывод о проверенном
исходнике; он не распространяется автоматически на другие версии Modelica.

Разность идеальных частей даёт аналитическую разность энтальпии,
внутренней энергии, энтропии и теплоёмкости. Она не зависит от давления.
`scripts.audit_msl_if97` непосредственно вызывает исходную MSL через `omc`,
без динамического интегратора и без интерполированного CSV-вывода.
Во всех **16 состояниях** различия объяснены коэффициентами:
максимальный остаток атрибуции энергии около **1,18e-9 Дж/кг**;
плотность согласуется с относительным остатком около **2,67e-15**.
Аудит: `artifacts/msl-coefficient-audit-v1/report.json`.

Прежние **0,0912401 Дж/кг** у парового перехода объясняются этой разностью
EOS. Предварительная гипотеза о несогласованности внутренних переменных или
интерполяции CSV больше не нужна для объяснения данного остатка. Состояние,
согласованное с одной реализацией EOS, не обязано удовлетворять другой с
изменёнными коэффициентами. Предыдущие отрицательные результаты остаются
историческими измерениями, но их интерпретация уточнена.

## Явный контрольный эксперимент

Оригинальная MSL не изменяется. Команда `--counterfactual-copy` создаёт новую
копию с отдельным manifest. Меняется ровно один `.mo`-файл: в конце `g2`
добавляется аналитическая поправка к `gamma`, `gamma_tau`, `gamma_tautau`.
Производные по давлению не меняются, поскольку поправка зависит только от tau.
Остальные файлы проверяются по SHA, baseline проверяется повторно.
Неизвестная версия выражения отклоняется, существующая выходная директория
не перезаписывается. Значения для поправки взяты из IAPWS, не подгонялись
по динамическим траекториям.

Внешний runner распознаёт manifest и помечает каждый итог как
`peer_library_variant=counterfactual`. Такая копия не становится неизменённым
независимым эталоном. Общие условия остаются прежними: одинаковые масса и
энергия, ClosedVolume, DASSL/IDA, пять общих времён, исходные численные бюджеты.

Полная контрольная матрица при tolerance1e-12 приняла **40/40 случаев**:
32 заданных тепловых цикла и восемь сравнений с конечной стенкой. Фазовые
метки у прежних двух отрицательных случаев совпали. Отчёт:
`artifacts/modelica-counterfactual-v1/report.json`.
Это контролируемая проверка причины расхождения, а не повышение исходного
benchmark 38/40 и не экспериментальная валидация.

## Корень фазового перехода

`scripts.verify_phase_event` определяет событие через сохраняемые величины:
при фиксированной начальной плотности внутренняя энергия достигает точной
энергии насыщенного конца `x=0` либо `x=1`. Точка сравнения не выбирается
по ближайшему CSV-отсчёту и не зависит от соглашения об имени самой границы.

Независимые ориентиры:

- Квадратура `dt/du = 1 / ((G/m) · (T_wall(u) − T_fluid(rho,u)))` до нулевого
  смещения энергии, с прямым решением IF97.
- DOP853 и Radau с явным корнем события `energy_offset=0`.

Native HEM использует монотонную бисекцию из одного checkpoint до перехода.
Каждая проба восстанавливает те же запасы и историю; верхняя граница
дополнительно проигрывается точно. Ширина временного интервала ≤5e-10 с,
допуск сравнения с ориентиром 2e-8 с. Проверяются две сетки, два caps и четыре
направления перехода. Это проверка равномерного замкнутого объёма со стенкой,
а не всей пространственной теплогидравлики.

Для внешнего события требуется настоящий вывод обеих сторон с одинаковым
временем и разными метками. Префикс, NaN, неверный порядок, несколько переходов
и смена метки между разными отсчётами не принимаются как точное время события.

Все **16/16 native корней приняты**, максимальная ошибка **4,45e-10 с**.
Три независимых ориентира согласовались. Отчёт:
`artifacts/phase-event-roots-v1/report.json`.
Повторная исходная MSL и контрольная копия запущены с одинаковыми драйвером,
физическим источником и tolerance1e-12; отличается ровно один library-файл.
Сравнение пяти отсчётов: **38/40 → 40/40**.

Более строгая приёмка времени события остаётся отдельной:
исходная MSL приняла **4/8**, контрольная копия — **6/8**.
Максимальная ошибка уменьшилась **9,1284e-6 → 1,3544e-7 с**, примерно в 67 раз.
Оставшиеся два паровых выхода не проходят заранее заданные 2e-8 с.
Положительный результат 40/40 на пяти отсчётах не закрывает этот новый gate.
Отчёт: `artifacts/phase-event-roots-v1/matched-campaign-events.json`.

Дополнительно испытан другой выбор переменных MSL: `--stock-states`
выбирает плотность/внутреннюю энергию вместо плотности/температуры.
По умолчанию конфигурация не меняется. Этот вариант **не принят**:
для исходной/контрольной библиотек прошли соответственно **3/8 и 4/8**.
В нескольких случаях `omc` сообщает успешное завершение, но CSV не содержит
полной общей временной сетки; встречается неоднозначность метки в событии.
Runner отклоняет такие выходы. Отчёты:
`artifacts/modelica-stock-baseline-v1/report.json` и
`artifacts/modelica-stock-counterfactual-v1/report.json`.
Смена переменных интегрирования не объявлена готовым исправлением.

## Команды

```bash
python -m scripts.audit_msl_if97 \
  --omc /path/to/omc --library /path/to/MSL \
  --output artifacts/my-msl-audit \
  --counterfactual-copy artifacts/my-explicit-msl-copy

python -m scripts.benchmark_modelica_cycles \
  --omc /path/to/omc --library artifacts/my-explicit-msl-copy \
  --include-wall --tolerance 1e-12 --output artifacts/my-control

python -m scripts.verify_phase_event \
  --campaign artifacts/my-original-wall-campaign \
  --output artifacts/my-phase-events
```

`--include-wall --wall-only` у динамического runner позволяет отдельно
выполнять восемь wall-сравнений. Любой альтернативный выбор состояния
попадает в protocol/report; исходные отчёты не перезаписываются.

Counterfactual — отдельный диагностический вариант, не параметр физической
библиотеки Atomic. Runtime-зависимости продукта не расширялись. Численная
проверка не закрывает экспериментальную валидацию, choking/slip/post-CHF
и внешнее сравнение всей установки.

## Поставка и свидетельства

Полная локальная проверка: **708 passed, 0 failed/errors/skipped**, восемь фаз,
1426 файлов wheel, 788 ресурсов. Отчёт:
`artifacts/local-phase-event-delivery-v2/report.json`.
На свежем wheel вне checkout с Python `-I` повторены прямые 16 MSL-вызовов,
все 40 контрольных динамических сравнений и один native-корень с точным
совпадением интервала бисекции и restart. Все эти проверки прошли:
`artifacts/installed-phase-event-v1/report.json`.
Повторять исходную библиотеку исправленной копией и повышать её вердикт
установленный runner не позволяет.

[Публичная машинная сводка: коэффициенты, остатки, корни, все отказы и SHA](benchmarks/msl_if97_event_benchmark_v4.json).
Большие исходники MSL, её диагностическая копия, C/ELF/CSV, venv и промежуточные
отчёты остаются в игнорируемой `artifacts/`. В Git сохраняются инструменты,
тесты, компактная измеренная фикстура и отчёт. CI и отдельный ИИ-рецензент
не добавлялись.

Сдвиг 135 нс локализован и устранён в следующем диагностическом варианте
без ослабления временного бюджета. Надёжная альтернативная конфигурация
состояний и неоднородный проточный канал остаются отдельными задачами.
Промышленная и объектная аттестация не заявлены.
