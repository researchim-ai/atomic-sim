# Адаптивная точность нелинейной динамики v78

Дата: 17 ноября 2026.

[Исследование v77](STATION_NONLINEAR_RESOLUTION_RU.md) показало, что на
подробном радиальном базисе прежний шаг времени не обеспечивает выбранный
допуск. Новый компонент `atomic_model_station_adaptive` добавляет управление
точностью к неизменённому нелинейному интегратору v76.

**Временной допуск 10⁻⁷ для выбранной конечномерной задачи v77 достигнут
относительно независимого адаптивного эталона.** Пространственная и
граничная квалификации этим результатом не закрыты.

## Контроль ошибки через удвоение шагов

На каждом пробном интервале h вычисляются три независимых продолжения
из одного исходного состояния:

1. Один шаг h.
2. Первый шаг h/2.
3. Второй шаг h/2 из результата первого половинного шага.

Для метода второго порядка локальная ошибка подробного продолжения
оценивается как:

```text
estimated_error = norm(u_two_halves - u_full) / 3
budget = atol + rtol * max(norm(u_before), norm(u_two_halves))
```

Норма — радиальная L2-норма полного знакового спектра, вычисленная
через матрицы массы и кратности канонических мод. Её определение совпадает
с v77: без усреднения на площадь сечения.

Принимается **реальная траектория двух половинных шагов**. Поправки
Ричардсона к коэффициентам скорости нет. Условие приёмки — отношение
оценки ошибки к бюджету не выше 1. Следующий шаг выбирается с безопасным
множителем и ограничением изменения; минимальный, максимальный шаг
и число повторных попыток задаются явно.

Эта оценка локальная. Контроллер не объявляет её строгой глобальной
границей ошибки: итоговая точность проверяется независимо.

## Нелинейная сходимость и атомарность

Каждый пробный подшаг проходит собственные проверки v76: нелинейный
остаток, энергия, мощность адвекции и восстановление давления.
При несходимости нелинейной итерации контроллер уменьшает шаг.
Некорректная сила и другие ошибки входов не скрываются уменьшением шага.

При исчерпании числа попыток или достижении минимального шага возникает
`AccuracyError` с диагностикой. Время, скорости, журналы и статистика
контроллера остаются прежними.

`advance_to(target)` атомарен для всего запрошенного интервала:
если интервал не удалось пройти в пределах бюджета, промежуточные
кандидаты не становятся состоянием объекта. Время не переписывается
искусственно ради совпадения с целью. Допускается только представимое
округление конечной эпохи, его величина записывается.

Если остаток интервала меньше разрешённого минимального шага и больше
округления, возвращается отказ. Это проверено отдельно от общего
исчерпания бюджета шагов.

## Сила, давление и воспроизведение

Сила задаётся отображением обобщённых нагрузок либо детерминированной
функцией `force(midpoint_time)`. При нестационарной силе полный и два
половинных шага получают разные соответствующие средние времена.

Возвращаемое давление относится к последнему фактическому половинному
шагу, а не к средней точке всего адаптивного интервала. Квитанция содержит
его время, длительность и checkpoint начала этого последнего подшага.
Это позволяет независимо проверить сильный импульс с правильным ускорением.

Checkpoint контроллера сохраняет базовое состояние, допуски, следующий
предлагаемый шаг, счётчики приёмок и отказов, границы шагов и идентичность
алгоритма. Точное продолжение, включая давление и выбор шага, проверено.
История внешней силы не сериализуется; для воспроизведения требуется та же
детерминированная последовательность входов. Внешние побочные эффекты
пользовательского callback не входят во внутреннее состояние контроллера.

## Исправление временного отказа v77

Используется тот же физический начальный профиль: полоса 2,
радиальный порядок 9, квадратура 64, alpha=0,628319, nu=0,05,
конечное время t=0,1. Пространство модели не меняется.

Независимый эталон — DOP853 той же полудискретной системы с прямой
свёрткой. Он вычисляется дважды с ужесточёнными допусками; расхождение
эталонных решений контролируется отдельно. Это независимость временного
интегратора, а не экспериментальная валидация или проверка непрерывного PDE.

Фиксированный шаг 0,00125 даёт разницу около **1,944·10⁻⁷** с эталоном,
выше выбранного допуска 10⁻⁷. При atol=10⁻¹¹, rtol=10⁻⁸ и максимальном
пробном интервале 0,0025 адаптивный расчёт даёт около **1,640·10⁻⁸**.
Точность улучшена примерно в **11,9 раза**; временной допуск этой задачи
пройден.

Потребовались **193 принятых интервала и 2 отклонения**. Принятые интервалы
содержат два реальных половинных шага. Дополнительные пробные полные шаги
в физическую траекторию и её журналы не включаются.

На последнем фактическом подшаге сильный граничный остаток остаётся
около **0,00609**, выше допуска 10⁻⁸. Уменьшение временной ошибки не закрыло
радиальную/граничную проблему. Следующая работа должна проверять базис,
граничные операторы и их совместную сходимость при контролируемом времени.

## Границы приёмки

Принятие временного допуска относится к выбранной фиксированной
Galerkin-системе. Контроллер не меняет число мод или порядок базиса,
не исправляет алиасинг неверной пространственной схемы и не квалифицирует
произвольную турбулентную или станционную динамику.

В отчёте разделены:

```text
selected_temporal_target_qualified = true
spatial_convergence_qualified = false
general_strong_wall_qualified = false
thermal_model_supported = false
station_usable = false
```

Прежние отрицательные результаты v77 сохранены: это результаты прежних
шагов, а не переименованные адаптивные расчёты.

## Локальное воспроизведение

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH="$PWD/src:$PWD" \
  .venv-layout/bin/python -m scripts.qualify_station_adaptive \
  --output artifacts/my-adaptive-time

OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  .venv-layout/bin/python -m pytest -q tests/test_station_adaptive.py \
  tests/test_station_adaptive_qualification.py
```

Директория вывода новая. Проверка заново выполняет фиксированную,
адаптивную и две эталонные траектории; она заметно дольше проверки
одного ядра адвекции. Нужны только Python и научные зависимости.

Новые тесты проверяют принятие двух фактических половинных шагов,
времена силы и давления, отказы точности и нелинейного solve,
атомарность целого интервала и точный restart. Они включены в общий
локальный профиль библиотеки.

[Машинная квитанция v78](benchmarks/station_adaptive_v78.json) содержит
критерии, независимые сравнения, историю принятых шагов, граничный аудит
и проверку установленной поставки.

Следующий блок — радиальная и граничная доработка при уже контролируемой
временной ошибке, затем общая пространственная приёмка, тепловая/плавучая
связка и длительная статистика.

Станционный статус сохраняется: **48/76 приняты, 28 открыты**.
NPP-11.03/04 и общая R1 остаются открытыми.


Поставка: **330 целевых тестов пройдены без пропусков, включая 23 новых**.

полным прогоном v78. В свежем Python `-I` вне checkout после установки wheel
без сети все четыре научных JSON совпали побайтно. Проверены байты
