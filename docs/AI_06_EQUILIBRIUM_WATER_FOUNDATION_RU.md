# Равновесная вода и пар: EOS и жёсткий закрытый объём

Версия блока 1.65.0, 5 ноября 2026. `atomic_model_hem` начинает AI-06.01/02/04: строгий интерфейс равновесного IF97 и отдельный компонент с динамическим давлением. Полная проточная HEM-постановка остаётся в работе.

## Область и источник

Используется существующая реализация `physics/materials/iapws.py`, основанная на [IAPWS R7-97(2012)](https://iapws.org/technical-guidance/release/IF97-Rev). Новые коэффициенты воды не вводились. Выбранный адаптер ограничен областями 1, 2 и равновесной смесью 4, давлением 0.1–10 MPa и температурой 300–900 K. Области 3/5, критическая область и метастабильные ветви не поддерживаются. Диапазон компонента уже полной области IF97; он не охватывает все режимы реакторной установки.

Две опубликованные контрольные точки таблицы 5 IF97, находящиеся в этом диапазоне, включены с атрибуцией International Association for the Properties of Water and Steam. Это проверка реализации формуляции, а не экспериментальная валидация компонента. Самостоятельная реализация коэффициентов IF97 для межкодового сравнения не добавлялась.

## Строгий термодинамический интерфейс

- `pt(p, T)` задаёт однофазное состояние. На насыщении требуется явное паросодержание, а не угадывание ветви по p/T.
- `px(p, x)` задаёт равновесное насыщенное состояние, где x — массовая доля пара. Значения вне [0,1] отклоняются; `void_fraction` возвращает отдельную объёмную долю пара.
- `rho_u(rho, u)` обращает консервативные координаты через прежний IF97 inverse с `allow_projection=False`. Принятый результат повторно собирается из прямой ветви и проверяется по плотности и энергии: относительная невязка rho не более 2e-9, абсолютная невязка u не более 0.002 J/kg. Поля проекции/mismatch запрещены.

Преобразование Pa/MPa может дать несколько ulp за границей диапазона. Для такой двухфазной точки проверяется отдельное решение точно на границе давления: оно принимается только при выполнении обеих тех же консервативных невязок. Произвольного clipping давления или паросодержания нет; запасы массы и энергии не переписываются.

Возвращаются p, T, rho, u, h, s, phase, region и quality, равное null вне насыщения. Средневзвешенные однофазные cp и скорости звука смеси не публикуются как её равновесные свойства.

## Производные

`derivatives(state)` строит Якобиан прямого фазового chart: (p,T) для одной фазы, (p,x) для смеси. Центральные разности проверяются на половинном шаге; затем применяется обратный Якобиан для получения d(p,T)/d(rho,u). Это численные производные с контролем stencil, не аналитические производные новой формуляции.

Равновесная скорость звука вычисляется как:

```text
c² = (dp/drho)|u + (dp/du)|rho * p/rho²
```

Положительность и конечность проверяются. В двухфазной области производная T получается через линию насыщения. На фазовой границе и при касании границы температурного/давленческого stencil двусторонние производные отклоняются. Численная усреднённая производная через смену фаз не изобретается. Акустические волны компонентом сосуда не решаются.

В тестах однофазное c² сопоставляется с фундаментальным IF97, двухфазное — с отдельным изоэнтропическим корнем по насыщенным свойствам. Эти проверки разделены с проверками самого conserved inverse.

## Закрытый жёсткий объём

`RigidEquilibriumVessel` имеет постоянные массу и объём. Управление — предписанная мощность нагрева или охлаждения. Давление, температура и фазовое состояние выводятся из запасов:

```text
dM/dt = 0
U(t + dt) = U(t) + power * dt
rho = M/V
u = U/M
```

Энергетическое изменение хранится относительно исходной рамки. При постоянной на вызове мощности интегрирование этой модели точно по построению; это не достижение временной сходимости пространственного решателя. Нулевые mass/energy balance residual относятся к этому учёту. Отдельные `eos_mass_residual_kg` и `eos_energy_residual_j` показывают невязку состояния EOS относительно тех же запасов.

Фазовые границы определяются пересечениями постоянного удельного объёма с насыщенной жидкой/паровой ветвью. Времена прохождения этих запасов считаются из заданного теплового потока. Зафиксированная начальная граничная точка не записывается повторно как событие нулевого времени. Кроме границ проверяются промежуточные состояния по ограниченному энергетическому разбиению. Это ограниченное семплирование области, не интервальное доказательство допустимости всей траектории.

Энтропия выводится как свойство состояния и изменение этого свойства. Отдельный независимо вычисляемый журнал переноса/производства энтропии в данном компоненте отсутствует; второй закон этим отчётом не объявляется квалифицированным.

## Управление, откат и сохранение

```python
from atomic_model_hem.vessel import RigidEquilibriumVessel

model = RigidEquilibriumVessel(request)
model.advance(600.0)
model.step(-20000.0, 600.0, expected_revision=1, controller_state={"tick": 1})
checkpoint = model.checkpoint()
```

Все операции одного экземпляра сериализованы. Состояние внешнего контроллера — явный конечный JSON до 32 KiB. Физика, история фазовых событий, мощность и состояние контроллера фиксируются совместно. Ошибка EOS после испарения, ресурсный отказ, неразрешимое приращение энергии/времени или устаревший revision оставляют исходное состояние без изменений.

Checkpoint ограничен 4 MiB и 128 принятыми вызовами. Restore повторно выполняет все вызовы и сравнивает весь checkpoint. Источники адаптера/сосуда/CLI, IF97 и сериализации, версии Python/NumPy/SciPy входят в идентичность. Хеши не являются подписью автора. На вызов допускается до 512 энергетических интервалов; фазовые границы добавляются отдельно. Общая история — до 256 событий.

## Запуск и проверка

```bash
atomic-hem demo --output artifacts/my-hem
atomic-hem replay artifacts/my-hem
atomic-hem qualify --output artifacts/my-hem-qualification.json
```

Эквивалентный запуск из исходников: `python -m atomic_model_hem ...`. Demo выполняет 600 s нагрева смеси и 600 s обратного охлаждения. Получаются полное испарение и последующее возвращение в смесь, с двумя фазовыми событиями и динамическим давлением. Вход и результат сохранены как JSON; `run input.json --output folder` поддерживает собственную программу той же схемы.

Квалификация включает две опубликованные точки таблицы 5, 25 двухфазных точек обращения с изменённым начальным приближением, производные и три программы сосуда. Каждая программа выполнена при трёх ограничениях энергетического семплирования: 9 путей. Для цикла фактические числа проб — 60/119/236; для охлаждения пара — 59/116/230. Малое возмущение жидкости даёт одну пробу на всех ограничениях и не считается тремя различными сетками.

Отдельный reference обращает прямые IF97 charts через pressure-bracket/двумерный root и не вызывает production rho/u inverse. Коэффициенты IF97 общие: это независимая проверка алгоритма обращения, не независимое уравнение состояния. Событие полного испарения дополнительно проверено корнем по температуре насыщения, а production использует корень по давлению.

Проверены точное продолжение из середины процесса и с самой фазовой границы, обратное охлаждение, подмена rehashed checkpoint, реальный выход за область после испарения, искусственный поздний отказ inverse и отказ проекции. Установленный wheel воспроизводит demo, полный qualification и тесты вне checkout в локальной venv с унаследованными зависимостями. Независимая ОС/машина этим не проверены.
