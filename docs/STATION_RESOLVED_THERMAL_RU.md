# Разрешённый нагреваемый трёхмерный пример v81

Дата: 18 ноября 2026.

В [v80](STATION_THERMAL_COUPLING_RU.md) связанные тепловые уравнения
и временной эталон прошли проверку, но нагреваемый 3D-пример не прошёл
радиальное уточнение, сильные граничные и физические тепловые проверки.
Новый компонент `atomic_model_station_thermal_resolved` расширяет
разрешение, сохраняя прежние уравнения Буссинеска и исходное поле.

**Для выбранного примера при t=0,05 теперь совместно проходят радиальное,
Fourier- и временное уточнение, сильные проверки на стенке в конечный
момент и интегральный физический тепловой баланс от t=0.**
Это приёмка объявленного короткого случая, а не всей станционной модели.

## Причина прежнего ограничения

Нулевая температура на стенке ещё не означает начальную совместимость
с её постоянной температурой. При отсутствии скольжения на стенке:

```text
theta = 0, u = 0, theta_t = 0
kappa*lap(theta) + Q = 0
```

Начальное поле v80 имеет максимальное рассогласование последнего
условия 0,012. Оно не менялось ради прохождения теста. Диагностика
`initial_wall_compatibility` измеряет эту величину и возвращает
`state_modified=False`; исправления коэффициентов или источника нет.

Короткий переход возле стенки требует дополнительного разрешения.
В v81 тепловой бюджет интегрируется от t=0, включая этот переход:
начальный интервал не отбрасывается, время не переименовывается,
энергетические журналы не корректируются после расчёта.

Сильная граничная приёмка при t=0 не заявлена. На всём временном пути
контролируются интегральные бюджеты на принятых шагах BDF; граничная
пространственная диагностика квалифицирована в конечный момент.
Строгих непрерывных оценок между шагами эти проверки не дают.

## Расширенные базисы и независимые версии

Новая фабрика скорости поддерживает порядки до 32, температуры — до 48,
|k|≤5 и m=0..5. Сохраняются порог обусловленности 10¹⁰,
проверки несжимаемости, положительности диффузии и разрешённости квадратуры.
Не каждая комбинация разрешённых целых параметров проходит эти проверки.
Например, скорость порядка 32 при m=4 отклоняется по обусловленности.

Окончательный случай использует Fourier-диапазон 4 — 81 знаковую моду:

- Внутренние моды с max(|k|,m)≤3: порядок скорости 32, температуры 40.
- Внешний слой max(|k|,m)=4: оба порядка 24.
- Общая квадратура — 128 точек, сравнение полей — независимые 160 точек.

Отдельно проверены внешний слой 20→24 и температурный порядок 40→48.
Это обосновывает выбранное неодинаковое разрешение слоёв, сохраняя
численные ограничения. Ядро скалярного переноса расширено до 121
знаковой моды; FFT сравнивается с независимой прямой свёрткой.

Для общих малых порядков фабрики делегируют прежним реализациям.
Матрицы, идентификаторы базисов и низкопорядковая временная траектория
проверены на точное совпадение. Исходники и научные JSON v80 сохранены.
Новый интегратор отдельно версионирован; старые пределы API не расширяются
неявно. Ограничение нового связанного состояния — 6144 комплексных
коэффициента, с прежними ограничениями на рабочую FFT-сетку.

## Совместная проверка одного физического поля

Семь случаев включают повтор прежнего расчёта v80 и шесть новых вариантов.
Максимальное начальное L2-расхождение полей — 2,390·10⁻¹⁵.
Дополнительные начальные Fourier-моды равны нулю. Нормы включают
отсутствующие моды и используют меру r dr без нормировки на площадь.

Результаты окончательного варианта:

- Радиальное уточнение 28/32→32/40: разницы скорости 1,873·10⁻¹²
  и температуры 1,388·10⁻¹⁴, допуск 10⁻⁷.
- Fourier-диапазон 3→4: 2,144·10⁻⁸ и 2,311·10⁻⁹, допуск 10⁻⁷.
- Ужесточение временных допусков BDF: 2,628·10⁻¹¹ и 1,842·10⁻¹³,
  допуск 10⁻⁸.
- Невязка импульса на стенке: 4,932·10⁻¹⁰ при допуске 10⁻⁸.
- Температурная невязка на стенке: 7,476·10⁻¹¹ при допуске 10⁻⁸.
- Максимальный дефект физического тепла на принятых шагах от t=0:
  4,443·10⁻¹¹ при допуске 10⁻¹⁰.

Температурный порядок 48 даёт тепловой дефект 1,520·10⁻¹¹;
более точное время также сохраняет прохождение критериев.
Максимальный дефект кинетической/скалярной квадратичной нормы во всём
наборе — 8,205·10⁻¹³, слабый остаток давления ≤1,132·10⁻¹⁵.
Скалярная квадратичная норма по-прежнему не объявляется внутренней энергией.

Сильная диагностика использует прямые парные свёртки вместо FFT
интегратора, аналитические лапласианы и физический градиент восстановленного
давления на 129 радиальных точках, включая стенку. Проверка относится
к сохранённым модам; давление за пределами спектра не реконструируется.

Временное сравнение подробных случаев использует два допуска одного
BDF, а не независимый временной алгоритм. Независимые аналитические
решения и сравнение DOP853/прямой свёртки с BDF/FFT остаются проверками
v80; новый общий низкопорядковый путь точно совпадает с v80.

## Непройденные случаи и явная приёмка

Прежний расчёт v80 сохраняет тепловой дефект 1,219·10⁻⁷ и граничные
остатки выше допусков. Даже более подробный вариант 28/32 ещё отклоняется:
дефект тепла 1,638·10⁻¹⁰, импульс на стенке 1,417·10⁻⁸.
Порогов ради этих расчётов не меняли.

`resolve_thermal` возвращает исследовательский кандидат. Отдельная
функция `accept_resolved(system, result)` проверяет физический тепловой
бюджет и сохранённые граничные остатки. При отказе возникает
`ThermalQualityError` с диагностикой в `receipt`. Ни исходное состояние,
ни кандидат не меняются. Пространственное уточнение выполняет отдельный
квалификационный протокол: одна успешная приёмка кандидата не заменяет
сравнения разных разрешений.

```python
from atomic_model_station_thermal_resolved import resolve_thermal, accept_resolved

result = resolve_thermal(system, end_time=0.05)
receipt = accept_resolved(system, result)
```

История BDF не сериализуется; побитовый restart, общая сильная сходимость
PDE, развитая турбулентная статистика и экспериментальная валидация
не заявлены. Станционная приёмка остаётся **48/76, открыто 28**;
NPP-11.03/04 и R1 открыты. Следующие этапы — проверка более длинных
тепловых траекторий и восстановления с бюджетами всего пути,
статистическая сходимость и применимость к станционной конфигурации.

## Локальное воспроизведение без CI

Из корня проекта с установленной библиотекой, в новом каталоге результата:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
python -m scripts.qualify_station_thermal_resolved --output artifacts/my-resolved-thermal
python -m pytest tests/test_station_thermal_resolved.py tests/test_station_thermal_resolved_qualification.py
```

Четыре JSON содержат протокол, случаи, сравнения и итог с контрольными
суммами исходников. Параметр `--reference artifacts/my-resolved-thermal`
сравнивает повторный запуск побайтно. Такая воспроизводимость проверяется
для зафиксированного локального Python/NumPy/SciPy-окружения; равенство
байтов между всеми BLAS и платформами не заявляется.

[Машинный отчёт и проверка установленной поставки](benchmarks/station_thermal_resolved_v81.json).


Поставка: **407 целевых тестов без пропусков, включая 24 новых**.
В свежем Python `-I` вне checkout после установки wheel без сети
четыре научных JSON совпали побайтно; проверены байты 861 Python-модуля
и скрипта. Исходники и квитанция v80 сохранены. Полный прогон всей
библиотеки v81 не выполнялся; 2261 тест v69 — историческое свидетельство.

Исторические результаты v81 сохранены; непрерывная история BDF и станционная приёмка не заявлены.
