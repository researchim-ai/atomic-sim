# Воспроизводимый отсев водяных CHF-измерений

Проверен набор KAERI uniform CHF, версия v3, DOI
[10.5281/zenodo.23566164](https://zenodo.org/records/23566164).
Это опубликованная оцифрованная и исправленная компиляция измерений из
KAERI/TR-1665/2000 с сохранением исходных экспериментальных групп.
Метаданные репозитория подтверждают открытый доступ и
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
README содержит единицы, определения усреднённого/локального CHF,
исправления и неразрешённые вопросы происхождения отдельных рядов.

Получены и проверены первичные для этой версии файлы:

- `uniform_standardized.xml`: SHA256
  `e87c2e0a7324408f77076554ae44291c7aee06034d933f7a3113d7a0c50cb281`;
- `README_uniform.md`: SHA256
  `13c44bcf7e90b077175ba19c09fc10ea5fca823cb47db3b026a65e8a1fd723ef`.

При загрузке дополнительно сверены опубликованные Zenodo MD5. Метаданные
версии, оба исходных файла и отчёт находятся в
`artifacts/kaeri-chf-screening-v1/`. Они не заменены сгенерированными рядами.
Файлы не встроены в wheel; исходные ссылки остаются публичными:
[XML](https://zenodo.org/records/23566164/files/uniform_standardized.xml?download=1),
[README](https://zenodo.org/records/23566164/files/README_uniform.md?download=1),
[метаданные JSON](https://zenodo.org/api/records/23566164).
При распространении файлов нужно сохранять атрибуцию и CC BY 4.0.

## Локальная проверка после получения файлов

```bash
python -m scripts.screen_chf_measurements \
  --xml artifacts/kaeri-chf-screening-v1/uniform_standardized.xml \
  --readme artifacts/kaeri-chf-screening-v1/README_uniform.md \
  --record artifacts/kaeri-chf-screening-v1/record.json \
  --output artifacts/kaeri-chf-screening-repeated.json
```

Сам проверяющий инструмент работает без сети. Он требует неизменных
контрольных сумм XML/README, правильной версии/DOI, открытого доступа
и лицензии, ожидаемой структуры и 651 уникального TestID. Числа в SI
сохраняются без пересчёта и округления; отрицательное равновесное качество
не проецируется на ноль. Неопределённое локальное CHF превращается из
опубликованного `NaN` в JSON `null`, а не в фиктивный ноль.

Для каждого опыта сохраняются исходная группа, текст происхождения,
давление, расход на единицу площади, диаметр, длина, качество, мощность,
периметр и CHF. Алгебра `Power/(Perimeter × Length)` проверяется как
диагностика производных величин, а не независимое измерение.

## Результат

Обработаны **651 опыт из девяти групп**, без потери строк. В 27 случаях
публикация не устанавливает локальный CHF; они сохранены с соответствующим
признаком. **Ни одна точка не попала в численную область текущих Biasi-INL
или table1995.**

Для Biasi 633 точки выходят по массовому потоку, 508 по качеству, 38 по
давлению, 4 по длине. Причины не исключают друг друга и не суммируются
как число опытов. Для table1995 все диаметры отличаются от строго 8 мм;
кроме того, ни один тройной набор p/G/x не попал в две разрешённые области.
Диаметры не округлялись, геометрические поправки не изобретались,
корреляции за пределами диапазона не вычислялись.

Даже совпадение численного диапазона означало бы лишь кандидата: отдельно
нужны проверка ориентации/геометрии/места CHF, неопределённости и ковариации,
а также независимость от данных настройки корреляции. Поэтому отчёт имеет
`screening_completed=true`, но `experimental_validation_admitted=false`,
`validated=false`, `plant_referenced=false`. Код возврата 0 означает успешный
отсев данных, а не успешную валидацию физики. Подгонки нет.

Тесты инструмента проверяют синтетические контрактные примеры отдельно
от этого реального набора. Они не выдаются за экспериментальные свидетельства.
AI-09.02/06 остаются открыты для **применимых** измерений и held-out проверки.
