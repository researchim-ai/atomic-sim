# Локальные скорости волн HLLC

Срез: 10 ноября 2026. В `ContactHEMNetwork` добавлен отдельный режим
`scheme='hllc-local'`. Прежние `hllc` с фиксированной границей волн и `rusanov`
сохраняют свои формулы. Режим по умолчанию не переключён.

## Изменение потока

Для каждой грани вычисляется симметричная оценка
`B = 1.01 * max(abs(v_left) + c_left, abs(v_right) + c_right)`,
где скорость звука получена из производных IF97. Затем применяется тот же
HLLC-поток с сигналами `−B`, `+B`. После обращения EOS обеих звёздных областей
проверяется `abs(v_contact) + c_star <= B` для каждой стороны.

Граница не увеличивается автоматически и не заменяется Русановым при отказе.
Если входные состояния или восстановленные звёздные состояния не укладываются
в ограничения, шаг отклоняется. В частности, встречный поток ±8 м/с при
4 МПа и 440 К проходит проверку входных акустических скоростей, но отклоняется
по звёздному состоянию. Это существенная дополнительная проверка.

Одних входных скоростей недостаточно для доказательства охвата произвольного
нелинейного веера. Даже дополнительная проверка приблизительных звёздных
состояний не заменяет такого доказательства. Для объявленных физических
случаев охват внешних волн проверяется отдельно по нелинейному эталону.
При сложной или неподдерживаемой волновой структуре применимость не заявляется.

Глобальная граница `wave_speed_bound_m_s` остаётся верхним ограничением:
локальная оценка должна быть не больше неё. Шаг CFL по-прежнему вычисляется
по глобальной границе. Увеличение шага или ускорение времени расчёта этим
изменением не заявляется.

## Результат по физическому эталону

[Нелинейный решатель](LIQUID_RIEMANN_ORACLE_RU.md) использует кривые Гюгонио
и изоэнтропическое разрежение, а не HLLC. Для 15 случаев проверяются невязки
эталона, соответствие диагностическому потоку и охват его внешних волн.
Для 12 случаев с перепадом давления дополнительно требуется ошибка массового
потока менее 3% и улучшение относительно фиксированной границы 2500 м/с.

На начальном разрыве 14/2 МПа при 441/439 К относительная ошибка мгновенного
массового потока снижена с **41,97% до 1,98%**. Для умеренного перепада:
**42,56% → 1,16%**. Для слабых изоэнтропических волн:
**37,63–56,77% → около 0,99%**.

Это ошибки потока на начальной грани, не ошибки всей траектории. Для встречных
сжатия и разрежения с температурным контрастом сопоставимого улучшения нет:
относительная ошибка малого результирующего потока остаётся около 60%.
Эти случаи сохраняются в отчёте, но не маскируются общим обещанием 3% точности.

## Граф, балансы и restart

Стенд `scripts/verify_local_hllc.py` проверяет новый режим на графе:

- 16 сравнений с независимой сборкой абсолютных запасов и DOP853/Radau:
  два волновых сценария, 2/4 ячейки, два ограничения шага.
- Неподвижные температурные контакты на сетках 2/4/8/16/32.
- Три запуска до 0,01 с: прямой, обратный и широкий перепады на двух ячейках.
  Это десятикратный горизонт прежнего стенда, не длительный режим установки.
- Положительность массы, жидкостная область, балансы массы/энергии,
  энтропийный критерий, отсутствие внешнего нагрева и точный restart.

Временные допуски прежнего строгого Python-стенда не расширены. Независимая
сборка не вызывает производственную функцию потока; EOS общая.
Неподвижный контакт проверяется отдельно с пределом 1e-9 К.

Схема включена в identity и checkpoint. Перенос checkpoint между `hllc` и
`hllc-local` отклоняется; повтор из checkpoint восстанавливает тот же режим.
Ошибочная команда не меняет состояние. Появление нового кода меняет подпись
контактного семейства: старые source-bound отчёты и checkpoint не объявляются
действующими для новых исходников. Квалифицированное основание не изменено.

## Использование

```python
from atomic_model_hem_contact import ContactHEMNetwork

model = ContactHEMNetwork(request, scheme='hllc-local')
result = model.advance(0.001)
checkpoint = model.checkpoint()
```

```bash
python -m scripts.verify_local_hllc --output artifacts/my-local-hllc
python -m pytest -q tests/test_local_hllc.py
```

Область остаётся однофазной адиабатической жидкостью без трения и внешнего
нагрева. Новый режим не переносит на себя 48 старых Modelica-сравнений
фиксированной схемы. Внешний локальный HLLC, пространственная сходимость
относительно физического эталона, более длительные режимы, теплообмен и
двухфазность остаются отдельными следующими этапами.
`validated=false`, `plant_referenced=false`, `global_wave_bound_proved=false`.

фаз завершены. Wheel содержит 1439 файлов, проверены 788 ресурсов.
[Sealed JSON](benchmarks/local_hllc_benchmark_v10.json) содержит протокол,
все критерии/вердикты и SHA локальных отчётов.

Весь стенд повторён из установленного wheel вне checkout с Python `-I`.
Все строки отчёта совпали с запуском из исходников. Полные артефакты:
`artifacts/local-hllc-qualification-v2/`,
`artifacts/local-local-hllc-delivery-v2/`, `artifacts/installed-local-hllc-v1/`.

12 новых тестов проверяют физический охват волн, ориентацию, энергетический
сдвиг, отказ по звёздному состоянию, checkpoint и rollback. Первая сборка
стенда и первый общий прогон обнаружили ошибку выбора cap в вызывающем
коде/тесте. Исправлено создание запроса; физические допуски не менялись.
Исторический отрицательный отчёт сохранён.
