# Пространственная и граничная точность нелинейной модели v79

Дата: 17 ноября 2026.

В [v77](STATION_NONLINEAR_RESOLUTION_RU.md) радиальное уточнение и
граничная невязка не прошли выбранные пороги. [v78](STATION_ADAPTIVE_TIME_RU.md)
закрыл временной допуск прежней конечномерной задачи. Новый компонент
`atomic_model_station_refined` обеспечивает более подробный регулярный базис
и жёсткое интегрирование для отдельной исследовательской постановки.

**Выбранный короткий нелинейный тест теперь проходит радиальное,
Fourier- и временное уточнение вместе с проверкой импульса на стенке.**
Это результат для объявленного начального поля без внешней силы,
вязкости 0,05 и конечного времени 0,1 в безразмерных переменных.

## Что изменилось

Отдельная фабрика расширяет полиномиальный порядок до 24 и спектр
до |k|≤5, 0≤m≤5. Регулярность на оси, отсутствие скольжения и
аналитическая несжимаемость заданы базисом. Сохраняются проверки
обусловленности, положительности вязкого оператора и ограничения
числа коэффициентов. Низкие порядки используют прежнюю фабрику с
побайтно совпадающими матрицами и идентификаторами.

Не вся комбинация параметров внутри числовых границ допустима:
например, порядок 24 при m=5 отклоняется по обусловленности.
Поэтому последний Fourier-слой имеет порядок 16; достаточность
этого слоя проверена отдельным сравнением порядков 12 и 16.

Для 121 знаковой моды реализованы прямая свёртка и FFT с достаточным
дополнением. Их независимое сравнение и суммарная мощность адвекции
проверяются тестами. Старое ограничение 81 моды у прежнего ядра не меняется.

Временная эволюция использует SciPy BDF с разделением действительных
и мнимых коэффициентов. Это существенно: сопряжённые Fourier-поля
делают правую часть неголоморфной. Разреженная квазиньютоновская
матрица содержит точный вязкий блок и производную энергетического
журнала; производная нелинейной адвекции в неё не включена.
Точность определяется фактической правой частью и отдельным
ужесточением временных допусков.

Интегратор возвращает новое состояние, производную и восстановленное
давление. Входные коэффициенты не меняются. Продолжение из результата
проверено в пределах допуска; **побитовый restart истории BDF не заявлен**.
Прежние интеграторы и их точный restart сохранены.

## Проверка на одном физическом поле

Десять расчётов начинаются с проекции одного полиномиального поля v77;
максимальное начальное расхождение — 2,960·10⁻¹⁵. Квадратура базиса
содержит 96 точек; сравнение полей использует независимую квадратуру
из 128 точек. Норма включает отсутствующие моды:

```text
L2 = sqrt(sum_signed_modes integral_0^1 |delta u|^2 r dr)
```

Результаты при неизменных порогах:

- Радиальные порядки 20→24 на окончательном спектре: 3,687·10⁻¹¹ < 10⁻⁷.
- Внешний Fourier-слой, порядки 12→16: 3,222·10⁻¹² < 10⁻⁷.
- Fourier-диапазон 4→5: 2,031·10⁻⁹ < 10⁻⁷.
- Ужесточение BDF с rtol=10⁻¹⁰, atol=10⁻¹³ до 2·10⁻¹², 2·10⁻¹⁵:
  разница скоростей 2,718·10⁻¹¹ < 10⁻⁷.
- Максимальная сохранённая модальная невязка на стенке:
  3,678·10⁻⁹ < 10⁻⁸; на более точном времени результат сохраняется.
- Максимальный дефект энергии по всем принятым шагам и всем расчётам:
  1,854·10⁻¹² < 10⁻⁹; слабый остаток давления ≤2,781·10⁻¹⁶.

Граничный баланс вычисляется в фактический конечный момент времени
из ускорения, независимой прямой свёртки, градиента давления и
аналитического векторного лапласиана на 101 радиальной точке,
включая стенку. Давление восстанавливается из слабой реакции;
сильный баланс проверяется отдельно, а не навязывается восстановлением.

Грубые отказы сохранены. Для диапазона 2 порядки 12, 16 и 20 дают
граничные остатки 4,868·10⁻⁴, 1,082·10⁻⁵ и 2,277·10⁻⁷.
Fourier-расширение 3→4 даёт 1,196·10⁻⁷ и ещё не проходит порог.
Именно поэтому окончательная проверка использует следующий диапазон.

## Независимое аналитическое решение

Дополнительно проверен затухающий вязкий вихрь:

```text
u_theta(r,t) = J1(a r) exp(-nu a^2 t),  J1(a) = 0
partial_r p = u_theta^2 / r
```

Давление вычисляется независимой адаптивной квадратурой с нулевым
средним по сечению. При t=0,1 максимальные ошибки скорости и давления
составляют 1,038·10⁻¹² и 1,060·10⁻¹²; остаток на стенке — 4,674·10⁻¹².
Это аналитическая верификация нелинейного центробежного члена и
вязкой динамики, а не экспериментальная валидация.

## Воспроизведение и область результата

Локальный запуск без CI, из корня проекта с установленной библиотекой:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
python -m scripts.qualify_station_refined --output artifacts/my-refined-study
python -m pytest tests/test_station_refined.py tests/test_station_refined_qualification.py
```

Каталог результата должен быть новым. Четыре JSON содержат протокол,
случаи, сравнения и итог с контрольными суммами исходников.
Для побайтного сравнения повторного расчёта доступен параметр
`--reference artifacts/my-refined-study`. Точное повторение чисел
проверяется в зафиксированном локальном Python/NumPy/SciPy-окружении;
переносимость между всеми BLAS и платформами не заявлена.

Приёмка поставки и число пройденных тестов записаны в
[машинном отчёте](benchmarks/station_refined_v79.json).

Неподдержанные утверждения исключены из отчёта: общая сильная
сходимость PDE, нагрев и плавучесть, развитая турбулентная статистика,
применимость к реальной установке. Диагностика показывает ненулевой
нелинейный хвост вне сохранённого спектра; давление этого хвоста не
восстанавливается. Поэтому даже малый сохранённый остаток не объявляется
полным остатком всех мод бесконечномерной задачи.

Станционная приёмка остаётся **48/76, открыто 28**; NPP-11.03/04 и R1
открыты. Следующий этап — тепловая и плавучая связка с отдельными
балансами, затем более длительные режимы, статистическая сходимость и
возврат к общей станционной матрице на одной версии backend.


Поставка: **354 целевых теста без пропусков, включая 24 новых**.
В свежем Python `-I` вне checkout после установки wheel без сети
четыре научных JSON совпали побайтно; проверены байты 846 Python-модулей
