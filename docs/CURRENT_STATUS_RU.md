## Статус плана

**Принято 106/109 задач.** AI-11.06 закрыт по уточнённому пользователем критерию:
воспроизводимая локальная проверка установленной библиотеки, без обязательного
удалённого CI. Никакой запуск на другой физической машине не заявлен.

Оставшиеся три направления относятся к научным свидетельствам и не блокируют
установку, тестирование и использование исследовательской библиотеки:

- **AI-09.02** — Найти разрешённые отдельные эксперименты и системные ряды; сохранить исходные файлы, лицензии, конфигурацию, единицы и качество измерений.

- **AI-09.06** — Разделить неопределённость данных, параметров, замыканий, сетки и интегратора; проверить покрытие интервалов на held-out случаях.

- **AI-09.08** — Выпустить validation report с отказавшими случаями, границами применимости и независимым техническим разбором.

Для этих направлений сохраняются отчёты, классификация данных и численные инструменты.
Экспериментальная валидация связанной установки и соответствие реальному блоку
не заявлены. Отдельный ИИ-рецензент не запускался по решению пользователя.

## Пользовательский интерфейс PWR для агентов

Добавлен `atomic_pwr_agent`: единый Python Episode и Gymnasium-адаптер
`ControlledPWREnv` поверх основного `pwr-reduced-flow-controlled`.
Наблюдения имеют версию, имена полей и единицы; действия используют существующую
проверку команд SDK и observation_id для защиты от устаревших запросов.
Поддержаны source-bound checkpoint/replay и экспорт принятого журнала в training case.
Учебная Gym-среда и существующий JSONL server не подменяются новой моделью.

[Сквозной пример и контракт](PWR_AGENT_QUICKSTART_RU.md).
Локально прошли 11 новых тестов, включая Gymnasium checker, реальный restart,
сравнение с campaign runtime и отказ от некорректных действий. Собран wheel;
его Python API, restart и Gymnasium проверены после установки вне checkout.
Новые тесты включены в профиль `scripts.verify_local_library`.
Полный прежний отчёт на 238 тестов остаётся историческим: после этого изменения
полная процедура проверки поставки заново не запускалась.
Научные статусы и число принятых задач старого плана этим блоком не повышаются.
Дополнительно прошёл регрессионный запуск интерфейса, training campaign и
release engineering: 78 тестов; два последующих граничных теста включены
в отдельный успешный запуск всех 11 новых тестов.

## PWR в локальных LLM tools — протокол 1.2

Новый backend явно выбирается через `create_controlled_episode` /
`step_controlled_episode`; `export_controlled_case` передаёт принятый журнал
в существующий training runtime. Полное состояние помечено `full_model_state`.

handles, cancel/close, перенос хостом между процессами, guard от устаревших
действий и пробный эпизод без фиксации при ошибке решателя.
