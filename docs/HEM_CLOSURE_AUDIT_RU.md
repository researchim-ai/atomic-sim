# Паспорта и проверка применимости замыканий

```bash
python -m scripts.audit_hem_closures --output artifacts/closure-audit/report.json
```

Команда выполняет восемь встроенных программ квалифицированного HEM и
сохраняет source-bound контракт, паспорта и наблюдения замыканий в начальном
состоянии и после каждого шага программы. В отчёт включены EOS, однородное
трение, Chen и два варианта CHF. Источники, диапазоны, обязательные допущения
и отсутствие калиброванных вероятностных неопределённостей заданы явно.

Для собственного входа используется `--input input.json`; файл должен
содержать ровно поля `request` и `program`. Первое — обычный вход
`QualifiedHEMNetwork`, второе — список из 1–100 вызовов вида
`{"duration_s": 0.00002, "command": null}`. Неявное переписывание управления
не выполняется. Неподдержанные режимы отклоняет существующий решатель;
аудитор не расширяет его область и не исправляет входные данные проекцией.

Табличные CHF-области сохраняются двумя раздельными параллелепипедами:
0,3–0,5 МПа / 1000–1500 кг/(м²·с) / x=0–0,05 и 15–16 МПа /
1000–2000 кг/(м²·с) / x=0–0,1, строго для диаметра 8 мм. Промежуток между
ними не становится допустимым. Для Biasi используется отдельный ограниченный
диапазон реализации. Chen также требует проверки Re/Pr, перегрева стенки,
ориентации, геометрии и запаса до CHF; одной проверки давления недостаточно.

В выборочных состояниях сохраняются Re, вязкость, диссипация и изменение
силы трения при замене McAdams на Cicchitti. Это чувствительность к выбору
модели, а не доверительный интервал. Для кипящей стенки сохраняются
тепловой поток, CHF, доля CHF и положительный остаток до объявленного
предела. Внутренние стадии проверяет штатный решатель; отчёт аудитора содержит
только запрошенные моменты, а не все внутренние экстремумы.

Паспорт привязан к хешам исходников. Он не является паспортом универсальной
двухфазной корреляции: post-CHF, slip/two-fluid, метастабильное вскипание,
критическое сопло и корреляция теплоотдачи при конденсации не поддержаны.
Старые признаки `validated=false` и `plant_referenced=false` сохраняются.
