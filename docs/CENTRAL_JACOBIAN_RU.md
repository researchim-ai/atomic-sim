# Часовой номинал: центральный якобиан BDF

Дата: 30 октября 2026. Продолжение [сохранения истории BDF](BDF_CONTINUATION_RU.md).

Позднее тот же переход завершён с явным выбором Radau и проверен на нескольких
точностях: [отчёт перехода нагрузки](RADAU_TRANSIENT_RU.md). Ниже сохранены результаты этапа BDF.

## Изменение

Добавлен явный параметр `solver.jacobian_relative_step`. При его наличии BDF
получает центральный разностный якобиан с возмущением
`h_i = relative_step * max(abs(y_i), 1)`. Используются фактические расстояния
между представимыми числами. После проб RHS возвращается к исходному состоянию,
чтобы восстановить изменяемую алгебру установки. Если одна проба вне области,
используется односторонняя разность; если обе — расчёт завершается с DomainError.
Ошибки solver, отмены и программы не считаются выходом проб за область.

Настройка доступна обычному интегратору, continuation, SDK experiment и
сценариям. Смена настройки сбрасывает историю BDF. Стандартный якобиан SciPy
остаётся режимом по умолчанию. Значение настройки входит в manifest.
Счётчик RHS для явного якобиана включает его дополнительные вызовы; legacy
`n_steps` сохраняет прежний смысл nfev SciPy. Для стандартного численного
якобиана SciPy его внутренние разностные вызовы в nfev не включены.

Результаты согласуются с гипотезой о чувствительности стандартных малых
разностных возмущений к точности обратного EOS. Это не доказательство
единственной причины затрат во всех режимах. Физические коэффициенты и законы
не изменялись; контроль ошибки интегратора не отключался.

## Завершённые расчёты

- `artifacts/central_jacobian_hour`: 3600 из 3600 с за **10.26 с**,
  rtol=1e−5, atol=1e−4, шаг вывода 5 с, шаг якобиана 1e−5.
- `artifacts/central_jacobian_hour_tight`: 3600 из 3600 с за **21.28 с**,
  rtol=3e−6, atol=3e−5, шаг вывода 2.5 с, шаг якобиана 5e−6.
- В обоих случаях выполнены бюджеты энергии, массы и бора. У первого
  глобальная невязка энергии около **0.090 Дж** при валовом потоке порядка
  2.19e13 Дж. На почти неподвижном номинале это в значительной степени
  проверка сохранения равновесия и округления, а не физической точности.

Сравнение всех 721 общей точки с заранее заданным
`validation/hour_nominal_budget.json` прошло: относительная разница мощности
не более **1.49e−11**, температура топлива **5.79e−9 K**, давление первого
контура **0.000219 Па**, ПГ **0.000097 Па**, расход **5.18e−8 кг/с**.
Эти величины — согласие двух численных решений одной модели.

Проверенный результат: `validation/central_jacobian_hour_verified.json`.
Скрипт проверки контролирует хеши input/report/CSV, завершение горизонта,
монотонность и конечность выбранных данных. Отсутствующие точки reference
не интерполируются. Запуски с командами не принимаются как номинал.

Воспроизведение:

```bash
python -m sdk.experiment scenarios/vver_nominal_hour_central.yaml --output artifacts/hour_new --wall-limit-s 60
python -m sdk.experiment scenarios/vver_nominal_hour_central_tight.yaml --output artifacts/hour_tight_new --wall-limit-s 60
python -m scripts.compare_hour_nominal artifacts/hour_new artifacts/hour_tight_new --output validation/hour_new.json
```

Выходные каталоги и файл сравнения должны быть новыми. Времена измерены без
изоляции аппаратной нагрузки; промышленная realtime-пригодность не установлена.

## Нерешённые ограничения

Переход `artifacts/central_jacobian_throttle_120s`: прикрытие турбины до 0.98
на 10-й секунде, запрос 120 с. Достигнуты только **25 с** за wall-limit **45 с**.
Этот переход не принят. Следующая работа — профиль именно этого перехода,
проверка масштаба разностей у границ и кусочно гладких управляющих законов,
затем сравнение завершённых траекторий на нескольких точностях.

Часовой номинал теперь численно подтверждён в указанном режиме. Это не
экспериментальная валидация, не квалификация аварийных расчётов и не доказательство
превосходства над другими кодами. В run_manifest добавлен отдельный признак
`numerical_full_horizon_accepted`; промышленный `accepted_full_horizon`
остаётся false. Аналогичный консервативный флаг внутри ledger не изменён.

## Проверки

Основной набор: **265 passed, 1 deselected за 111.76 с**. Не повторялся
неизменённый внешний OpenMC/MPI particle-run. Одно предупреждение SciPy BDF
в старом `test_restart_matches_continuous_run`; тест прошёл. Ещё три проверки
нового сравнения прошли отдельно. Тесты якобиана проверяют аналитические
производные и сходимость разностей, границу области, проброс ошибок, счётчики
RHS, перезапуск истории и откат состояния. Покрытие не измерялось.

Всего пройдены 268 уникальных проверок. Ruff и проверка wheel прошли:
установленная вне checkout поставка выполнила два CLI-сценария по 0.4 с,
включая continuation с центральным якобианом и загрузку нового YAML из пакета.
Сводка: `validation/central_jacobian_checks.json`.
