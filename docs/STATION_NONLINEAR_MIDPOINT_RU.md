# Связанная нелинейная динамика средней точки v76

Дата: 17 ноября 2026.

В [v75](STATION_NONLINEAR_ADVECTION_RU.md) были проверены пространственные
ядра адвекции. Новый `atomic_model_station_nonlinear` связывает их с вязкой
динамикой регулярных Fourier–Galerkin-мод и восстановлением давления.

**Принят выбранный нелинейный временной интегратор конечномерной модели.**
Это уже эволюция взаимодействующих мод, а не только вычисление нелинейного
члена. Пространственная сходимость всей динамики, сильный граничный баланс,
тепловая модель и станционная интеграция остаются открытыми.

## Уравнение шага

Для каждой сохранённой канонической моды решается:

```text
M (q_new-q_old)/dt + nu K q_mid = Z* [f_ext - load(N(u_mid))]
q_mid = (q_new+q_old)/2
N(u_mid) = (u_mid·grad)u_mid
```

Все моды связаны через N. Спиновые регулярные базисы v72 обеспечивают
прилипание и аналитическое ограничение несжимаемости; после шага нет
отдельной проекции или подгонки скорости.

Состав сохранённых мод фиксирован. Новые моды не добавляются автоматически;
нужную полосу задают заранее, включая моды с нулевыми начальными коэффициентами. Для произведений строится полный
сопряжённый спектр реального поля, затем сохраняются требуемые Galerkin-моды.
FFT использует достаточное дополнение v75. Альтернативный метод — прямая
свёртка, без FFT. Оба метода сопоставлены на целых траекториях.

Сохранение энергии усечённой системы не означает достаточности полосы
спектра для реального течения: пространственная модальная сходимость
этой версии ещё не принята.

## Нелинейная итерация и отказ

Используется итерация Пикара. На каждой итерации нелинейный член
вычисляется по средней точке текущего кандидата; вязкая часть решается
неявно. Остановка определяется остатком уравнения импульса, а не только
малостью изменения коэффициентов.

Норма остатка каждой моды делится на максимум 1 и норм её ускорения,
вязкой нагрузки и силы; используется максимум по модам.
Допуск по умолчанию — 10⁻¹², лимит — 40 итераций. Политика ограничена
допусками 10⁻¹³…10⁻¹⁰ и 1…100 итерациями.

Безусловная сходимость итерации для любого шага не обещается. При
исчерпании лимита `NonlinearConvergenceError` содержит число итераций
и остаток. Кандидат не принимается. Автоматического изменения шага,
урезания мод или ослабления допуска нет.

До приёмки проверяются также конечность данных, энергетический баланс,
мощность адвекции и восстановление давления. Любой отказ оставляет
скорости, время и все журналы прежними.

## Давление с учётом адвекции

В каждой сохранённой моде алгоритм v73 восстанавливает давление из:

```text
G p = f_ext - load(N_mid)
      - M_full (c_new-c_old)/dt - nu K_full c_mid
```

Это безразмерное кинематическое давление в интегральном уравнении
импульса. Средняя мода имеет явную нулевую калибровку.
Давление вычисляется в средней точке шага и не является дополнительной
интегрируемой координатой.

Поле давления вне сохранённой полосы не восстанавливается. Приёмка
интегрального давления не заменяет сильное уравнение на стенке;
соответствующие квалификационные флаги остаются ложными.

## Энергетический журнал

Для канонической моды используется кратность 2, кроме средней моды
(k,m)=(0,0) с кратностью 1. Это эквивалентно полному знаковому спектру.
Контролируется баланс:

```text
E_new-E_old = W_external - D_viscous - W_advection + residual
E = sum_modes multiplicity * (q* M q)/2
```

Внешняя работа, положительная вязкая диссипация и вычисленная работа
адвекции хранятся отдельно. В идеальном непрерывном и согласованном
Galerkin-переносе мощность адвекции равна нулю; её фактическая малая
численная величина сохраняется в журнале, а не удаляется коррекцией.
Проверяются шаговый и накопленный балансы.

## Матрица траекторий

Выполнены пять расчётов по десять шагов 0,01 до t=0,1:

- Невязкая динамика с сохранением энергии.
- Вязкая динамика с FFT-адвекцией.
- Та же вязкая динамика с прямой свёрткой.
- Более широкая сохранённая полоса мод.
- Возбуждение внешней силой с отдельным учётом положительной работы.

Использованы полосы 1/2, порядок регулярного базиса 3, радиальная
квадратура 32 и безразмерная вязкость 0 либо 0,05. Это не утверждение
о Re=5300 или параметрах конкретной АЭС.

Во всех случаях выполнен restart после пяти шагов с точным продолжением,
включая восстановленное давление и квитанции.

Максимумы на выбранной матрице:

- Остаток нелинейного решателя: **5,166·10⁻¹³**.
- Невязка накопленного энергетического баланса: **6,026·10⁻¹⁶**.
- Невязка интегрального восстановления давления: **1,046·10⁻¹³**.
- Модуль мощности адвекции: **1,220·10⁻¹⁹**.

Расхождение целых FFT- и свёрточной траекторий по конечным коэффициентам —
**4,343·10⁻¹⁹**. Вязкие невозбуждаемые расчёты затухают, а невязкий
сохраняет энергию в пределах допуска.

## Независимая проверка времени и физический эталон

Временные шаги 0,02/0,01/0,005 сравниваются с адаптивным DOP853 той же
полудискретной системы. Его правая часть независимо собрана через прямую
свёртку, а не через итерацию средней точки. Две настройки точности
адаптивного решателя отличаются по конечному состоянию на **2,586·10⁻¹⁴**.

Минимальный наблюдаемый порядок по времени — **2,00087**.
Это проверка временной схемы относительно той же конечномерной системы,
а не экспериментальная валидация или доказательство пространственной
сходимости уравнений Навье–Стокса.

Отдельно проверено стационарное центробежное равновесие v75:

```text
ut=r(1-r²), ur=uz=0, nu=0
p=r²/2-r^4/2+r^6/6-1/8
```

Нелинейный шаг сохраняет коэффициенты скорости точно и восстанавливает
давление с ошибкой **3,748·10⁻¹⁶**. Это независимое известное нелинейное
равновесие, а не изготовленная правая часть из проверяемой временной матрицы.

## Restart, входы и границы API

Моды хранятся в детерминированном каноническом порядке. Обязательны
средняя мода, общая точная радиальная квадратура и alpha. Ограничены
число мод и суммарная размерность: не более 41 канонической моды и
256 комплексных приведённых коэффициентов; действуют ограничения v75
на полный знаковый спектр и FFT-рабочий набор.

Checkpoint фиксирует спецификации и численные fingerprints базисов,
коэффициенты, политику решателя, вязкость, время и энергетические журналы.
Проверяются идентичности кода и численного окружения. Несовместимый базис,
повреждённый бюджет, неполные коэффициенты и непредставимый прирост
времени отклоняются.

Внешняя сила передаётся полным отображением канонических мод в обобщённые
нагрузки. Для нестационарной силы вызывающий код должен задавать её в
средней точке шага. История силы не сериализуется внутри checkpoint;
для воспроизведения передаётся та же последовательность нагрузок.
Поскольку это обобщённые нагрузки, они сами по себе не определяют
поточечную физическую силу на стенке.

## Пример API

Проверенное стационарное центробежное равновесие:

```python
import numpy as np
from atomic_model_station_regular import regular_mode
from atomic_model_station_nonlinear import NonlinearSession

model = regular_mode(0, 0, .628319, order=6)
r = model.radius
velocity = np.zeros((3, len(r)), dtype=complex)
velocity[1] = r * (1 - r*r)
session = NonlinearSession([(model, model.fit(velocity))], viscosity=0.)
receipt, pressures = session.advance(.01)
pressure, gradient = pressures[(0, 0)].evaluate(r)
restored = NonlinearSession.restore(session.checkpoint())
```

Для взаимодействующих мод передаётся список таких пар `(model, q)`;
их квадратура и alpha должны совпадать.
