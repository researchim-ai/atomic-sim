# Экспериментальные свидетельства для гидравлического трения HEM

Дата: 5 ноября 2026. Статус: ограниченное сравнение производственного коэффициента и независимой однофазной опорной формулы; динамическая и двухфазная HEM не валидированы.

Пакет `atomic_model_hem_validation` вызывает реальный API `atomic_model_hem_closures.darcy_factor(reynolds, relative_roughness)` для каждого из 38 измерений. Производственный коэффициент использует неявное уравнение Colebrook. Отдельно пакет независимо реализует турбулентную формулу Хааланда и знаковый закон Дарси:

`delta_p = f (L/D) rho u |u| / 2`.

С экспериментом сравнивается безразмерная величина `2 delta_p D / (rho u² L) = f`. Подстановка произвольной нормировки в размерную функцию проверяет согласованность реализации; плотность, скорость и длина нормировки не являются экспериментальными данными. Измеренный перепад в Па не восстанавливается. Сопоставление проверяет производственный компонент коэффициента, но не интеграцию в HEM/сеть, свойства воды, размерный перепад, ламинарную ветвь или динамику. Все экспериментальные точки лежат в турбулентной области; ламинарная ветвь этим набором не проверяется.

## Данные и происхождение

Без изменений переиспользован набор `atomic_model_validation/data/nist_tn2294`: исходный PDF, NOTICE, протокол, векторные координаты, CSV и манифест. Первичный источник: [NIST TN 2294](https://doi.org/10.6028/NIST.TN.2294), рис. 18, печатная стр. 23. Republished courtesy of the National Institute of Standards and Technology. Условия переиспользования сохранены в исходном NOTICE. Описание исходной оцифровки: [AI-09](AI_09_NIST_PIPE_EXPERIMENT_RU.md).

Используются все 38 маркеров четырёх повторных серий одной установки: прямая медная труба D=0,02011 м, принятая шероховатость 1,5 мкм, Re примерно 14296–100594. Маркеры являются оцифрованными опубликованными измерениями, а не сырыми записями датчиков. Подгонки и отбора по остатку нет. Независимость от данных разработки корреляции не установлена.

Хеш неизменяемого исходного манифеста закреплён в коде. Перед расчётом проверяются состав, хеши и совпадение CSV с векторами. Тест повторно извлекает векторы из PDF посредством существующего digitizer. Набор не требует сети и не перезаписывается.

## Результат и неопределённость

Производственный Colebrook: все 38 центров проходят унаследованный инженерный screening-порог 5%; максимальная относительная ошибка 2,12586967%, средняя знаковая ошибка +0,60423129%, RMS 1,07158083%. Независимый Haaland: максимальная ошибка 2,56131554%, средняя знаковая −0,54058320%, RMS 0,94191043%. Каждая из четырёх серий отдельно проходит критерий для обеих формул. Метрики находятся раздельно в `comparisons.production_colebrook` и `comparisons.independent_haaland`; корневой `passed` и код CLI определяются только производственным компонентом. Успех baseline не может скрыть отказ производства. Это не критерий NIST и не доверительный интервал. В отчёте сохраняются остатки, средняя и RMS относительные ошибки, метрики каждой серии, границы чтения и расстояние между интервалами. Координатные границы вычисляются по размерам маркеров; пересечение интервалов не отменяет отказ критерия по центру.

В первичном PDF, стр. 17–18, приведены характеристики расходомеров, плотности и вязкости; стр. 22 даёт пример стандартной неопределённости среднего давления. Аудит сохраняет эти сведения как контекст, не назначая их каждому маркеру. Полного бюджета для каждого коэффициента на рис. 18 нет: отсутствуют исходные значения, ковариации наклона давления, геометрии и расхода. Для распространения неопределённости нужна совместная ковариационная матрица входов формулы `f = pi² rho D⁵ delta_p / (8 L mass_flow²)`; независимость входов нельзя предполагать автоматически. Полоса ±3% характеризует согласие с Colebrook, а не погрешность измерений. Поэтому `experimental_uncertainty_complete=false`, критерий по измерительной неопределённости заблокирован.

## Матрица валидации

Машиночитаемая матрица находится в `report.json`, поле `validation_matrix`:

- Стационарное однофазное трение: `compared_limited`, только указанные условия и безразмерный коэффициент.
- Испарение: `blocked_missing_real_data`; нужны реальные временные ряды теплового потока, массы/энергии и паросодержания.
- Конденсация: `blocked_missing_real_data`; нужны состояние входного пара, теплоотвод, конденсат и давление.
- Вскипание при снижении давления: `blocked_missing_matched_dynamic_data`; первичный кандидат указан ниже, но нужны согласованные динамические данные, энтальпия, качество/пустотность и расход.
- Blowdown: `blocked_missing_matched_dynamic_data`; первичный кандидат указан ниже, но нужны согласованные геометрия, закон открытия, запас массы, граничное давление и временные ряды расхода, давления, температуры.

Для всех недостающих режимов также нужны прослеживаемая калибровка и неопределённость измерений. Синтетические расчёты не заполняют эти пробелы. `validated`, `dynamic_hem_validated`, `two_phase_hem_validated`, `plant_referenced` остаются false при любом результате screening.

## Воспроизведение и аудит

Из корня репозитория, в новый каталог:

```bash
python -m atomic_model_hem_validation run /tmp/hem-experiment-audit
python -m atomic_model_hem_validation verify /tmp/hem-experiment-audit
pytest -q tests/test_hem_validation.py tests/test_experimental_pipe.py
ruff check atomic_model_hem_validation tests/test_hem_validation.py
```

Коды CLI: 0 — screening пройден, 2 — отказ критерия или аудита. Создание поверх существующего каталога запрещено. Результат содержит точную копию исходных свидетельств, численный отчёт, снимок исходников замыкания `closure_source/` и хеш-манифест. Снимок — свидетельство версии, а не код, который verify исполняет или восстанавливает поверх рабочего пакета. Verify проверяет состав, отсутствие симлинков, хеши данных, исходников нового пакета, производственного пакета замыканий и digitizer, совпадение сохранённого снимка с текущим производственным кодом, затем заново рассчитывает весь отчёт. Подмена чисел или статусов с пересчётом манифеста не проходит. Хеши обеспечивают локальную воспроизводимость, а не криптографическую подпись автора. Тесты с произвольными размерными числами проверяют только алгебру и знак; экспериментальными они не называются.


## Фиксация производственной версии

Схема отчёта 2 фиксирует `production_closure_version` и SHA-256 каждого Python-файла пакета замыканий в `source.production_closure_sources` одновременно в отчёте и манифесте. Изменение рабочего пакета после фиксации требует нового аудита; старый отчёт не получает квалификацию автоматически. Проверка использует текущий производственный API и пересчитывает обе серии сравнений по сохранённым экспериментальным данным. Изменение любого остатка, статуса матрицы, исходного снимка или идентичности источников отвергается даже при переписанном артефактном манифесте. Хеши проверяются до и после вычисления, чтобы не сохранить отчёт при параллельной правке исходников.


## Первичный кандидат flashing/blowdown, без экспериментальной приёмки

В матрицу встроены только метаданные `alamgir-kan-lienhard-1980-figure4`:
Alamgir, Kan, Lienhard (1980), [An Experimental Study of the Rapid Depressurization of Hot Water](https://engines.egr.uh.edu/sites/engines/files/talks/ExperimentalStudyOfDepressurization.pdf).
Основание приёма метаданных: `validation/ai06_dynamic_data_candidate_v1/manifest.json` и [поисковый аудит](AI_06_DYNAMIC_DATA_SEARCH_RU.md).
Четыре опыта HW-18, HW-17, HW-20, HW-27 сохранены как факты Table 1, а не временные ряды. Числовые истории давления с Fig. 4 не оцифрованы. Динамика открывающей пробки, начальные/граничные условия и метастабильность с задержкой нуклеации пока не согласованы с равновесной HEM. Полного бюджета неопределённости нет.

Поэтому flashing/blowdown имеют статус `blocked_missing_matched_dynamic_data`, `comparison_performed=false`, `experimental_acceptance=false`. Наличие реального первичного кандидата не равно отсутствию любых экспериментальных свидетельств, но также не является готовым benchmark. Испарение и конденсация сохраняют `blocked_missing_real_data` в этой матрице. Никакая новая экспериментальная приёмка не выполняется.

Метаданные находятся в Python-модуле `atomic_model_hem_validation.evidence`, входящем в wheel; при выполнении матрицы файлы поиска, CSV, manifest и PDF из checkout не читаются. SHA-256 CSV — идентификатор принятого извлечения, а не заявление о его повторной проверке при каждом запуске. Исполняемый модуль включён в собственную идентичность аудита. Сохранённый экспериментальный отчёт обновляется только после фиксации версии замыканий.
