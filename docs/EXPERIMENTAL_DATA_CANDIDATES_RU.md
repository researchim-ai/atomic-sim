# Поиск экспериментальных данных: результаты отбора

Проверено 8 ноября 2026. Машинный реестр:
`validation/experimental_candidates_v1.json`. Это перечень кандидатов и
причин недопуска, не набор измерений и не validation report.

Отдельное продолжение поиска дало реально полученные **651 водяной CHF-опыт**
из открытой версии KAERI v3. Выполнен побайтово проверяемый импорт и полный
численный отсев; ни одна точка не попала в области текущих CHF-моделей.
[Файлы, лицензия, команды и причины](CHF_MEASUREMENT_SCREENING_RU.md).
Эта проверка хранится отдельно от первоначального реестра четырёх кандидатов.

1. **MARVIKEN-CFT.** Первичный каталог NEA описывает полномасштабные критические
   истечения воды/пароводяной смеси, измерения и документацию погрешностей.
   Пакет имеет статус `Masterfiled restricted` и выдаётся по запросу.
   Разрешение и исходные ряды не получены; текущий конечный приёмник также
   не реализует критическую сопловую модель. Данные не импортированы.
   [Каталог NEA](https://www.oecd-nea.org/tools/abstract/detail/csni1001/).
2. **DEBORA.** Описание производителя в исследовательском репозитории указывает
   R-12 и локальные измерения структуры кипящего потока. Это другой флюид,
   а IF97 в библиотеке описывает воду. Результат поиска сохранён как
   отклонённый кандидат; прямое чтение страницы завершилось timeout,
   лицензия и файлы не проверены. Переносить значения в водяной расчёт нельзя.
   [Репозиторий CEA](https://entrepot.recherche.data.gouv.fr/dataset.xhtml?persistentId=doi%3A10.57745%2FTCAMME).
3. **NASA FBCE.** Первичное описание проекта указывает normal perfluorohexane
   C6F14 и исследования влияния микрогравитации. Такая серия не подтверждает
   текущие водяные замыкания вертикального потока; первичные данные не
   импортировались. [Описание NASA](https://www.nasa.gov/glenn/glenn-expertise-space-exploration/physical-sciences-program/fluid-science/flow-boiling-and-condensation-experiment-fbce/).
4. **TUM HIPER, DOI 10.14459/2025mp1839312.** Метаданные распространителя
   описывают водяные опыты при 15,5–21 МПа с CHF и post-CHF, включая сведения
   о неопределённостях. Первичный mediaTUM ответил HTTP 429; первичные файлы,
   лицензия, геометрия и совместимость отдельных точек не подтверждены.
   Это перспективный кандидат для дальнейшей проверки, а не допущенный
   held-out набор. Большая часть заявленного давления выше предела 16 МПа
   квалифицированного HEM, post-CHF не поддержан.
   [Первичный DOI](https://doi.org/10.14459/2025mp1839312),
   [метаданные распространителя](https://data.europa.eu/data/datasets/10-14459-2025mp1839312?locale=en).

Ранее сохранённый pool-boiling B-274 остаётся отдельным материалом для
проверки происхождения и обработки данных. Он не соответствует проточному
Chen при G>0; подгонка по нему не выполняется. Причины сохранены в
`atomic_model_phase_assessment.assessment`.

Для допуска нового эксперимента нужны доступные первичные файлы с разрешением
на использование, геометрия, воздействие, единицы, часы/события, описание
датчиков и неопределённостей, сопоставление с поддержанными уравнениями и
разделение настройки с проверкой по независимым сериям. Найденная публикация
сама по себе не закрывает AI-09.02 или AI-09.06. Независимый технический
разбор AI-09.08 также не заменяется этим поиском.
