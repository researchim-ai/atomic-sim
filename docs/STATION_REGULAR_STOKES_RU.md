# Регулярная вязкая динамика с прилипанием и несжимаемостью v72

Дата: 17 ноября 2026.

После [аудита операторов давления v71](STATION_PRESSURE_OPERATORS_RU.md)
реализован отдельный Fourier–Galerkin-компонент
`atomic_model_station_regular`. Он рассчитывает **линейную динамику Стокса
одной комплексной Fourier-моды** при постоянной вязкости. Регулярность
векторного поля у оси и прилипание на стенке задаются пространством
скоростей; несжимаемость сохраняется при каждом шаге вязкой эволюции.

Это следующий проверенный шаг после скалярного давления. Принят выбранный
линейный эталон, а не полная нелинейная динамика нагреваемой трубы или АЭС.
Исходный Openpipeflow и станционный backend не изменены.

## Регулярность векторного поля

Для моды exp(i m theta + i alpha k z) используются спиновые компоненты:

```text
u_plus  = ur + i*ut = r^(m+1) F_plus(r²)
u_minus = ur - i*ut = r^|m-1| F_minus(r²)
uz                  = r^m Fz(r²)
```

Здесь m≥0, а F — полиномы. Степени следуют из регулярности декартовых
компонент: ux+i*uy имеет угловую моду m+1, ux-i*uy — m-1.
Так задаётся гладкое продолжение через ось, включая ненулевую допустимую
компоненту u_minus для m=1. Одной чётности отражённых узлов для этого
недостаточно.

Каждая F представлена через `(1-s) P_j(2s-1)`, s=r², с полиномами Лежандра.
Множитель (1-s) обеспечивает нулевые скорости на стенке. Первые производные
вычисляются аналитически. Для диагностики около оси спиновые компоненты
вычисляются напрямую: вычитание ur±i*ut может терять точность, когда два
слагаемых почти равны.

Дивергенция записывается как `r^m` на полином от s. Для каждой из трёх групп
базисных функций коэффициенты этого полинома вычисляются аналитически:

```text
plus:  (m+1) P + s P'
minus: P', при m>=1; P+s P', при m=0
axial: i*alpha*k P
```

Здесь P уже включает множитель (1-s). Матрица C отображает коэффициенты
скорости в коэффициенты полинома дивергенции. Разложение SVD строит базис Z
нулевого пространства `C Z = 0`; затем он нормируется по матрице массы.
Все рабочие скорости представлены как `c=Z q`. После временного шага
нет отдельной проекции или исправления поля.

## Вязкая форма и совместная реакция ограничения

Радиус трубы равен единице; модель безразмерная. В проверках ν=0,1.
Это не объявление Re=5300 и не перенос коэффициентов исходного DNS.

Матрица массы задаёт интеграл `|u|² r dr`. Вязкая матрица построена по
полному градиенту в цилиндрических координатах, включая геометрические
члены:

```text
|du/dr|²
+ (|i*m*ur-ut|² + |i*m*ut+ur|² + |i*m*uz|²)/r²
+ (alpha*k)² |u|²
```

Квадратура Гаусса применяется по s=r² с мерой `r dr = ds/2`.
Порядок квадратуры ограничен снизу относительно порядка полиномов.
Проверяются обусловленность матрицы массы, положительность вязкой формы
и невязка ограничений.

Шаг неявной средней точки решает систему в пространстве Z:

```text
M (q_new-q_old)/dt + nu K (q_new+q_old)/2 = Z* f
```

Одновременно проверяется остаток полного уравнения импульса: он должен
лежать в образе `C*`. Это дуальная реакция ограничения несжимаемости.
Её работа на допустимой скорости равна нулю с точностью вычислений.
**Реакция не переименовывается в физическое поле давления:** такое поле
этот компонент пока не восстанавливает.

Контролируется дискретный энергетический баланс:

```text
E_new-E_old = dt Re(c_mid* f) - dt nu (q_mid* K q_mid)
E = 1/2 integral |u|² r dr
```

Нормировка относится к одной комплексной моде; сюда не включены объёмный
множитель и кратность сопряжённых мод полного реального поля.
Для неявной средней точки сохраняется энергетическая устойчивость,
но это не означает подавления всех жёстких мод без временного уточнения.

## Проверенные траектории

Выполнены 12 расчётов: m=0/1/2/4, порядки базиса 4/6/8; k=0 для средней
моды и k=2 для остальных, alpha=0,628319. Каждый расчёт содержит 80 шагов
по 0,0025 с постоянной обобщённой силой и восстановление после 40 шагов.
Все поля и сравниваемые квитанции продолжения совпадают точно.

Максимумы на выбранной матрице:

- Скорость на стенке: **1,031·10⁻¹⁸**.
- Аналитическая дивергенция: **3,855·10⁻¹⁶**.
- Невязка накопленного баланса энергии: **1,017·10⁻²⁰**.
- Относительная невязка реакции ограничения: **7,632·10⁻¹⁶**.
- Модуль работы реакции: **5,270·10⁻²⁰**.

В отличие от v70, здесь ограничения удерживаются во время выбранной
вязкой эволюции, а не только в начальной точке. Но это другая численная
модель; отрицательные результаты внешнего интегратора не отменяются.

## Независимые эталоны и временное уточнение

Пространственная проверка использует осесимметричный вихрь:

```text
ut(r,t) = J1(j_1,1*r) exp(-nu*j_1,1²*t)
ur = uz = 0
```

Первый корень J1 обеспечивает прилипание на стенке. Это независимое
решение цилиндрической вязкой диффузии, не изготовленная правая часть
из проверяемой матрицы. Ошибка в радиальной L2-норме при порядках
3/5/7/9 уменьшается примерно от 1,683·10⁻⁴ до **2,428·10⁻¹⁵**.
Для отделения пространственной ошибки от временной здесь используется
матричная экспонента полудискретной системы.

Отдельная проверка шага 0,01/0,005/0,0025 сравнивает динамику с независимой
матричной экспонентой той же системы. Минимальный наблюдаемый временной
порядок — **1,99980**. Это проверка порядка интегрирования; сама по себе
она не заменяет независимый пространственный эталон Бесселя.

## Restart и откат

Checkpoint содержит комплексные коэффициенты, спецификацию базиса,
энергетический журнал и время. Отдельно проверяются контрольная сумма
содержимого, идентичность модели, численных матриц и кода интегратора.
Изменение численного окружения может изменить базис SVD; такой restart
отклоняется вместо продолжения в несовместимых координатах.

Неверная сила, неконечные данные, недопустимый шаг, повреждённый баланс
или шаг, который не может продвинуть представимое время, вызывают отказ.
Состояние и журнал меняются только после проверки кандидата.

## Локальное воспроизведение и область приёмки

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH="$PWD/src:$PWD" \
  .venv-layout/bin/python -m scripts.qualify_station_regular \
  --output artifacts/my-regular-stokes

OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  .venv-layout/bin/python -m pytest -q \
  tests/test_station_regular.py tests/test_station_regular_qualification.py
```

Выходная директория новая. Нужны только Python и научные зависимости;
Fortran, сеть и сторонние checkpoints не требуются.

Пройдены **181 целевой тест, включая 44 новых**. Два новых файла тестов
включены в общий локальный профиль. Полный прогон 2261 теста остаётся
исторической проверкой v69 и не объявляется полным прогоном v72.
[Машинная квитанция](benchmarks/station_regular_v72.json) сохраняет критерии,
12 траекторий, уточнения и подтверждение установленного повтора.

Закрыта исследовательская проверка совместных кинематических ограничений
для выбранной линейной модели Стокса. Остаются:

1. Восстановление и проверка физического давления, включая границу.
2. Нелинейная адвекция, взаимодействие мод и контроль алиасинга.
3. Температура, плавучесть и согласованная передача энергии.
4. Пространственно-временная квалификация всей связанной динамики,
   затем длительный тепловой прогрев и статистика.
5. Применимость и интеграция в станционную модель.

Станционный счётчик не повышен: **48/76 приняты, 28 открыты**.
NPP-11.03/04 и общая R1 остаются открытыми.


Поставка проверена в свежем Python `-I` вне checkout после установки wheel без сети. Все четыре научных JSON совпали побайтно; проверены байты 820 Python-модулей/скриптов. Исторические исходники v69 и v71 сохранили свои идентичности.
