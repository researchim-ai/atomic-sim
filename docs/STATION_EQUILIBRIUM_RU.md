# Согласованное начальное состояние всей станции

Новый режим `equilibrium_start=True` строит горячее состояние до начала
рабочей истории. Он решает уравнения всей собранной станции, включая
реактор, теплоноситель, стенки, питание, паровой коллектор, две ступени
турбины, промежуточный перегрев, конденсатор и охлаждение.

Режим включается явно. Прежний старт остаётся по умолчанию и сохраняет
смысл исследовательского переходного процесса. Стационарный старт не
позволяет переписать состояние уже работающей установки.

## Причина прежнего дрейфа

Отдельные компоненты имели собственные согласованные номинальные точки.
После добавления коллектора, ступеней и перегрева их сочетание уже не
являлось стационаром полной установки. В прежней начальной точке
перегреватель отбирал около 220 МВт у стенки ПГ, ротор набирал около
69 МВт, а запас конденсатора — около 151 МВт. Эти внутренние переносы
почти компенсировались в суммарном балансе. Дополнительно нагревался
питательный бак из-за работы насосов и потерь.

Поэтому хорошая суммарная невязка энергии не означала нулевых производных
каждого запаса. Регуляторы постепенно меняли состояние и перераспределяли
воду между конечными баками. Нейтральная полоса уменьшала мелкие запросы,
но сама не согласовывала тепловой режим всех компонентов.

## Что решается

Для текущей топологии с точечной кинетикой имеется 78 координат.
Из нелинейной задачи исключаются производные алиасы, накопительные
счётчики, изолированные резервы и выбранные неактивные направления.
Остаются **49 независимых неизвестных**.

Решатель сохраняет суммарную массу первого контура, суммарную массу
второго контура вместе с коллектором и баками, циркулирующий бор,
запасы бора в компенсаторе и ПГ. Массы и энергии изолированных баков
подпитки/дренажа и резерв батареи фиксированы. Энтропия компенсатора
задаёт дополнительную термодинамическую опору.

Заданные значения номинальной точки — тепловая мощность делений
3,15 ГВт, давление коллектора 6,3 МПа и скорость вала 157 рад/с.
Совместно определяются состояния M/U, температуры, расходы и начальные
положения стержней, впуска и байпаса. Насосные, теплопередающие и
турбинные коэффициенты не подгоняются: их реестр до и после решения
должен совпасть.

Система не заменяет балансы нормированными штрафами «по желанию». Часть
линейно зависимых строк заменяется физическими условиями сохранения и
опорами. После решения **все независимые размерные производные**,
включая заменённые строки, проверяются повторно. В частности, ненулевой
запрос спрея нельзя скрыть тем, что его расход выбран равным нулю.

Номинальные критерии включают 1e-6 кг/с для водяных запасов, 1 Вт для
тепловых запасов, 0,01 Па для гидравлического напора и сохранение общих
масс/бора относительно исходного задания. Производные температур
переводятся в мощности через соответствующие теплоёмкости. Отдельно
проверяется малая внешняя мощность накопления всей установки.

## Численный метод и область

Используется ограниченный по работе Newton с уравновешиванием строк и
столбцов, конечными разностями и поиском допустимого уменьшающего шага.
Недопустимые EOS, фазы, направления потока или положения приводов не
проецируются на границы. Для производной допускается противоположная
сторона, если первая проба выходит из области. Если допустимого шага
нет, состояние не принимается.

В конце вычисляется SVD уравновешенного ограниченного якобиана.
Требуется ранг 49/49. Это локальная проверка постановки; она не доказывает
глобальную единственность решения и не заменяет динамический расчёт.

Текущая ветвь предполагает неактивные спрей/сброс и нулевой стационарный
расход в соединении компенсатора. Это не запрет таких режимов в динамике.
Если заданная точка требует другой активной ветви, инициализатор отказывает.
Например, проверка 3,12 ГВт обнаружила требуемый спрей и была отклонена;
нулевая производная не была объявлена вопреки физическому регулятору.
Пространственное ядро этим инициализатором пока не поддерживается.

## Начальная энергия и рабочая история

Согласованная точка имеет другую начальную энергию, чем прежний шаблон.
Для номинального решения разность составляет около 6,13 ГДж. Она явно
записывается как `initial_energy_change_j` при декларации нового состояния
до `t=0`. Это не накопленное тепло во время работы и не воспроизведение
физического процесса вывода установки на режим.

API отказывает, если уже прошёл физический такт, есть рабочая история,
команды или защёлкнутая защита. Повторная инициализация решённой точки
также запрещена. Исходный объект не меняется даже при неудаче: задача
решается на копии. Энергетический нуль задаётся один раз для вновь
объявленного начального состояния; массы и бор не списываются.

## Регуляторы и пользовательские интерфейсы

До первого измерительного кадра ссылки уровней, feed-forward расходов
и начальные bias согласуются с решённой точкой. Усиления PI не меняются.
Это устраняет командный скачок от ссылок другого стартового состояния.
После начала истории работают обычные уравнения и ограничения.

```python
from atomic_model_station_faults import FaultSession

station = FaultSession(equilibrium_start=True, inventory_deadband_m=.0002,
                       tick_s=5., history_budget_steps=8192)
station.step(modes={name: "auto" for name in station.control.loops})
```

Весь цикл прогрева/выдержки тоже поддерживает этот режим:

```bash
python -m atomic_model_station_hot --equilibrium-start \
  --maximum-warmup-s 600 --hold-s 3600 --output artifacts/hot-equilibrium-new
```

Для агента и кампаний:

```python
from atomic_model_station_env import StationEnv, EnvConfig
from atomic_model_station_campaign import Episode

env = StationEnv(EnvConfig(equilibrium_start=True, inventory_deadband_m=.0002))
observation, info = env.reset()
episode = Episode("nominal", 720, tick_s=5., equilibrium_start=True,
                  inventory_deadband_m=.0002)
```

```bash
python -m atomic_model_station_env --equilibrium-start --inventory-deadband-m .0002
python -m atomic_model_station_equilibrium --output artifacts/equilibrium-state-new
```

Наблюдение агента остаётся измерительным: отчёт решателя и полный M/U
не добавляются в публичные каналы. Checkpoint хранит рецепт и версию
инициализации; native restore заново решает исходную задачу, затем
повторяет рабочую историю и сравнивает полный результат.

## Полная номинальная проверка

Программа фиксирует критерии до вычисления и выполняет **весь час с t=0**,
а не только установившийся хвост. Проверяются все 601 окна по 600 с,
измеренные цели, полный часовой размах физического вектора, локальные
и глобальные балансы, фазовые ограничения и численное уточнение.
Само решение при `t=0` не считается доказательством устойчивости часа.

```bash
export OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
export PYTHONPATH="$PWD/src"
python -m scripts.qualify_station_equilibrium --output artifacts/equilibrium-hour-new
python -m scripts.verify_local_library --output artifacts/equilibrium-library-new
python -m scripts.verify_station_equilibrium_delivery \
  --output artifacts/equilibrium-installed-new \
  --source-evidence artifacts/equilibrium-hour-new \
  --library-evidence artifacts/equilibrium-library-new
```

Исходная копия выполняет coarse и fine. Установленная поставка заново
исполняет fine и весь coarse-путь через native restore префикса 1800 с
с последующим точным сравнением хвоста до 3600 с. Исходные coarse-файлы
в установленном дереве являются проверяемыми входами, а не выдаются за
дополнительный независимо выполненный прогон. Квитанция native replay
хранится отдельно от неизменяемого математического дерева.

Только совокупность этих проверок позволяет принять выбранный номинал.
Остальные изменения нагрузки, останов/выбег и полная матрица R1 требуют
собственных испытаний. Реальные измерения установки и экспериментальная
валидация этим алгоритмом не создаются: модель и её коэффициенты остаются
исследовательскими.

## Результат квалификации v59

Номинал 3,15 ГВт / 6,3 МПа / 157 рад/с прошёл непрерывные 3600 с
с шестью автоматическими контурами и нейтральной полосой 0,2 мм.
Оба расчёта (max_step 1 с / rtol 10⁻⁷ и 0,5 с / 2·10⁻⁸)
прошли все 601 скользящее окно по 600 с и проверку полного часа.
Максимальные нормированные размахи — 1,295·10⁻⁹ и 1,111·10⁻⁹;
расхождение физических координат при уточнении — 8,478·10⁻¹⁰.
Накопительные счётчики исключены из критерия стационарности, бюджеты
проверены отдельно. Никакого сброса времени, PI или состояния в часе нет.

Из wheel вне checkout независимо исполнен уточнённый час и полный
native replay основного расчёта: реальное восстановление префикса
0–1800 с и точное сравнение всех шагов 1805–3600 с и конечного checkpoint.
Все 18 JSON научного дерева совпали побайтно. Скопированные coarse-файлы
явно являются входными эталонами установленного повтора.

Пройдены 1871 тест и восемь локальных фаз. Закрыт **NPP-11.01**
в этой объявленной исследовательской области: **47/76**, открыто **29**.
NPP-11.02/03/04, полная R1 и экспериментальная валидация остаются открытыми.
Данные: [машинный отчёт v59](benchmarks/station_equilibrium_v59.json).

Поля `feed_design.initial_state` и `steam_design.inherited_sizing` описывают
исходный шаблон подбора коэффициентов оборудования. Фактическое новое
начальное состояние задаёт рецепт `equilibrium_initialization`.
