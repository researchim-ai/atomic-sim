# ADR 0001. Жёсткий интегратор на BDF из SciPy

## Контекст

Точечная кинетика и сеть сжимаемой жидкости жёсткие. Явный RK4 на тепловой скорости нейтронов требует запретительно малого шага. SUNDIALS IDA рассматривался как открытый кандидат для DAE и не подключён зависимостью.

## Решение

Для ODE используется `scipy.integrate.solve_ivp` с методом BDF. Допустимы также Radau и LSODA. Алгебраические величины (давление, температура, паросодержание) восстанавливаются из запасов внутри правой части, поэтому индекс системы на уровне интегратора — явная ODE.

Неуспех шага поднимает `SolverError`. Шаг не повторяется с обрезанным состоянием.

## Контроль

Линейная задача `y' = -y` на методе Radau и кинетика против `expm` входят в `tests/test_industrial_core.py`.

## Следствия

Пока внешний DAE-решатель не подключён, формулировки с явным алгебраическим остатком должны либо разрешаться внутри правой части, либо получать отдельный паспорт.
