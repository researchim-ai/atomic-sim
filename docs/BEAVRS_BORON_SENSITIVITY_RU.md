# BEAVRS: чувствительность калибровки и экстраполяция

Срез: 11 ноября 2026. Продолжение [условной борной компенсации](BEAVRS_BORON_COMPENSATION_RU.md).
Уменьшение ошибки после настройки одного параметра не показывает,
насколько устойчив этот параметр к составу калибровочных данных.
Новый анализ проверяет именно эту зависимость.

## Фиксированные диагностические варианты

Используется тот же проверенный по SHA-256 первоисточник BEAVRS, без новой
ручной таблицы и без изменений физического ядра. До анализа объявлены три
варианта: настройка только по D, только по CD и по D/CD совместно.
Измеренная концентрация ARO остаётся общей заданной опорой 975 ppm.

Ни один вариант не выбирается по ошибке на ABCD/ALL. Результат содержит
`selected_view=null`. Эти состояния уже изучались в предыдущем опыте и
теперь являются открытыми данными разработки, а не новым независимым test.
Измеренные эффективности стержней по-прежнему задаются на входе.

Получены следующие значения:

- Только D: коэффициент 10,79452 pcm/ppm, проверочная MAE 73,71 ppm.
- Только CD: коэффициент 12,06667 pcm/ppm, MAE 26,09 ppm.
- D/CD: коэффициент 11,85842 pcm/ppm, MAE 33,18 ppm.

Различие ошибок не используется для замены основного коэффициента. Выбор
варианта CD по наименьшей ошибке означал бы настройку по уже просмотренным
проверочным данным. Такой выбор здесь не выполняется.

## Проверочные состояния находятся вне калибровочного диапазона

Совместная калибровка использует измеренные концентрации 810 и 902 ppm.
Проверочные значения — 686 и 508 ppm. Все прогнозы трёх вариантов также
находятся вне их собственных диапазонов калибровочных концентраций.
В отчёте отдельно сохранены признаки выхода измерения и прогноза за диапазон.
Этот диапазон построен по состояниям настройки D/CD, без заданной опоры ARO.
Включение опорных 975 ppm расширяет только верхнюю границу и не меняет
вывод об экстраполяции проверочных состояний в область меньших концентраций.

Это не проверка интерполяции. Успех на двух точках экстраполяции не подтверждает
постоянство коэффициента на всём диапазоне бора, во времени или при других
температурах и конфигурациях зоны.

## Локальная чувствительность без выдуманной неопределённости

Для `x_i = B_ARO - B_i`, `S = sum(x_i**2)` коэффициент равен
`b = sum(x_i * W_i) / S`. Аналитически вычисляются:

- `db/dW_i = x_i/S`;
- `db/dB_i = (2*b*x_i - W_i)/S`;
- `db/dB_ARO = sum(W_i - 2*b*x_i)/S`.

Для прогноза `B_pred = B_ARO - W_eval/b` сохраняются производные по каждому
калибровочному измерению и заданной эффективности проверочного состояния.
Общая опорная концентрация учитывается дважды причинно: напрямую в прогнозе
и через изменение калибровочного коэффициента. Поэтому полная производная
по ней равна `1 + W_eval/b**2 * db/dB_ARO`.

Это локальный отклик модели на изменение входа. Он не является стандартным
отклонением, доверительным интервалом или вероятностью ошибки. Без
применимых неопределённостей и ковариаций измерений распространение
неопределённости не выполняется. Численные производные по центральным
разностям проверяют аналитические выражения в тестах.

## Описательные секущие не заменяют физические коэффициенты

Для всех четырёх состояний отдельно вычислено отношение измеренной
эффективности к снижению критической концентрации от ARO:

- D: 10,79452 pcm/ppm;
- CD: 12,06667 pcm/ppm;
- ABCD: 12,83737 pcm/ppm;
- ALL: 12,93790 pcm/ppm.

Секущие ABCD/ALL используют проверочные концентрации и запрещены как вход
в прогноз этих же концентраций. Они имеют только описательный смысл.
Их различия нельзя однозначно приписать зависимости борной эффективности
от концентрации: одновременно меняются конфигурация стержней и предположения
об аддитивности последовательных измерений. Четыре точки не разделяют эти
причины и неизвестные корреляции измерений.

## Воспроизведение

```bash
python -m pytest -q tests/test_beavrs_boron_sensitivity.py
python -m scripts.analyze_beavrs_boron --output artifacts/my-beavrs-sensitivity
```

Сохраняются протокол и полный отчёт с калибровками, прогнозами, производными,
признаками экстраполяции и ограничениями. Числа извлекаются из установленного
первичного файла; сеть не нужна. Порядок строк не влияет на результат.
Неполная матрица, смешение настройки и оценки, нечисловые значения и
вырожденная калибровка отклоняются.

Следующий физический этап — согласованные условия HZP, отдельные банки и
предсказание их эффективности, а также применимые неопределённости.
Добавление более гибкой кривой по этим четырём точкам без независимых
данных не устраняет пробел в физической проверке.

## Проверка поставки

14 новых тестов проверяют аналитические производные центральными разностями,
вклад общей опорной концентрации, независимость настройки от проверочных
концентраций, точный канонический порядок и отказ при некорректных данных.
Пройдено 1319 тестов полного локального профиля и восемь фаз поставки.
Весь диагностический отчёт точно повторён из установленного wheel вне
checkout. Протокол совпал после нормализации абсолютных путей драйверов;
хеши исходников совпали без нормализации. [Машинный результат](benchmarks/beavrs_boron_sensitivity_v30.json).
`validated=false`, `plant_referenced=false`; распространение неопределённости
и полная модель энергоблока не заявлены.
