# Реестр кандидатов физических данных — v110

[English](STATION_DATA_CANDIDATES_EN.md)

`atomic_model_station_evidence` собирает версионированные метаданные источников, уже имеющихся в библиотеке. Для каждого кандидата заданы условия, наблюдаемые величины и единицы, версия и первоисточник, раздельные права на публикацию и исходные измерения, смысл неопределённости и недостающие сведения.

```bash
python -m atomic_model_station_evidence --output results/candidates.json
```

```python
from atomic_model_station_evidence import candidate_registry

registry = candidate_registry()
```

Реестр работает офлайн из wheel. Он проверяет контрольные суммы перечисленных артефактов внутри установленных пакетов. Копии публикаций и лицензии не дублируются; используются уже поставляемые ресурсы. Изменившийся файл, неподдержанные единицы, отсутствующая неопределённость или попытка добавить неизвестный флаг приёмки приводят к отказу чтения. Существующий выходной файл не перезаписывается.

## Три разные области данных

- [BEAVRS](https://github.com/mit-crpg/BEAVRS/tree/1ccae04dc3830a5977f08ed7f5f7e1e51ded0d22): закреплённая таблица последовательных стоимостей банков в cycle 1 HZP. Она не заменяет согласованный паспорт станции.
- [NIST TN 2294](https://doi.org/10.6028/NIST.TN.2294): компонентные данные стационарного трения; границы чтения символов не заменяют инструментальную неопределённость.
- [MOTEL](https://publikationen.bibliothek.kit.edu/1000187398): публикация об интегральном стенде. Открытая лицензия статьи не означает наличие прав на не поставляемые исходные измерения.

Поля условий сохраняют различия между последовательными приращениями реактивности и отдельными банковыми измерениями, экспериментальными показаниями и оцифровкой рисунка, а также статьёй и исходными временными рядами. Для BEAVRS отдельно указано, что полный UQ-пакет здесь не импортирован; это не утверждение об отсутствии таких сведений у первоисточника.

## Чего реестр не делает

Контрольные суммы подтверждают сохранность зафиксированных файлов. Они не подтверждают применимость модели, полноту измерений или право переносить параметры между установками. `admitted_for_station_validation`, `experimental_validation` и `full_r2_accepted` остаются ложными независимо от факта наличия публикации.

Перечисленные пробелы — вход для NPP-13.02/03: согласованные границы и геометрия, применимые коэффициенты, измерительные часы, неопределённости и их корреляции, независимое разделение калибровки и проверки. Численную проверку пространственного отклика на синтетических коэффициентах нельзя выдавать за сравнение с этими измерениями.

## Зафиксированные ресурсы

Записи содержат имена пакетов, относительные пути и SHA256. Допущен только явный список пакетов-источников. Абсолютные пути, переходы `..` и непереносимые имена отклоняются. Все данные возвращаются новой копией, поэтому изменение результата вызывающим кодом не меняет следующего чтения.

Права записаны в объёме сохранённых исходных уведомлений. Для новых файлов и новых потоков измерений нужна отдельная проверка условий использования. Реестр не загружает новые данные и не расширяет лицензии публикаций по предположению.

## Приёмка v110

Проверены три кандидата и 11 закреплённых артефактов. Реестр из установленного wheel совпал целиком с исходным JSON; 15 новых тестов реестра входят в 44 повторённых теста двух новых модулей. Общий целевой прогон — 153 теста. Полного прогона библиотеки не было.

NPP-13.01 принят как реестр кандидатов с явными пробелами. Статус станции — 52/76 задач, открыто 24. NPP-13.02/03/04 и вся R2 остаются открытыми; ни одна запись не получила автоматической физической приёмки. [Машинный протокол](benchmarks/station_data_candidates_v110.json).
