# Консервативное сопряжение нейтроники и тепловых ячеек — v123–124

Обновление v125–126: [локальные температуры и остаточное тепло подключены к отдельным core/staged PWR-сессиям](PWR_DISTRIBUTED_FUEL_RU.md). Ниже сохранена область исходной тестовой задачи v123–124.

[English](CONSERVATIVE_CORE_CHANNELS_EN.md)

Реализован общий оператор переноса между несовпадающими одномерными сетками.
Он используется существующей стационарной многопроцессной связкой и новой
нестационарной тестовой задачей. Исправлен старый `conserve_integral`: NaN,
неверные размеры и некорректная геометрия теперь отклоняются до расчёта.

## Один оператор, разные физические величины

`coupling.ConservativeMap(source_faces, target_faces)` строит матрицу длин
перекрытия ячеек. Обе сетки должны покрывать один физический отрезок с точно
совпадающими крайними координатами. Поддерживаются 1–512 ячеек на каждой
сетке; плохо разрешимые в float64 интервалы отклоняются. Входы копируются,
матрицы доступны только для чтения и безопасно разделяются при deepcopy.

Для интегральной мощности ячейки используется `P[j,i] = overlap[j,i]/width[i]`:
`powers_th = P @ powers_n`. Сумма мощностей сохраняется, положительный источник
не создаёт отрицательного нагрева. `integrals` отдельно допускает знаковые
интегральные источники. Метод `averages` работает со средними значениями и
делит перекрытие на ширину **целевой** ячейки. Это разные интерфейсы:
среднюю плотность источника нельзя принять за мощность ячейки.

Обратная температура передаётся как `temperature_n = P.T @ temperature_th`.
Тот же оператор обеспечивает согласованность пары: скалярное произведение
исходной мощности на возвращённую температуру равно произведению перенесённой
мощности на целевую температуру. Это алгебраическая согласованность обмена,
а не новый закон термодинамики; произведение мощности и температуры само
по себе не является энергией.

Геометрия одномерная. Перенос по длине не заменяет трёхмерные пересечения
объёмов или модель переменной площади сечения.

## Совместимость существующего кода

`coupling.maps.conserve_integral` сохраняет прежний смысл: принимает плотность
источника и ширины ячеек, возвращает среднюю плотность на целевой сетке.
Допускается только расхождение сумм длин на уровне округления. Крайняя
координата согласуется в этом узком допуске; внутренние границы и значения
поля не масштабируются. Геометрическое расхождение 1e-9 м при длине 1 м
больше не скрывается старым допуском 1e-8.

Отклоняются NaN/Inf, комплексные и логические значения, нулевые/отрицательные
ширины, неверная размерность и непредставимый интеграл. Ошибки выдаются как
`DomainError`. Обёртки `atomic_model_multiphysics.coupled` сохраняют прежние
`ValueError` для своих некорректных входов. Их расчёт мощности и температур
теперь использует общий оператор; внутри стационарной итерации геометрия
собирается один раз.

Паспорт `atomic_model_multiphysics.provenance.identity()` дополнен SHA файла
общего оператора. Изменившаяся реализация переноса не может незаметно
переиспользовать старый checkpoint стационарной связки. Старые запечатанные
квитанции не переписываются: для новой версии выполняется новая проверка.

## Нестационарная тестовая задача

`coupling.core_channels` содержит `ChannelConfig`, `CoreChannels` и
`ChannelSession`. Нейтроника использует существующий синтетический
одногрупповой отражающий `DiffusionCore`: 2–8 ячеек и шесть **нейтронных**
семейств предшественников в каждой ячейке. Состояния предшественников
интегрируются локально; они не заменяются усреднённым точечным состоянием.

На другой сетке находятся тепловые ёмкости с проводимостью к заданному
неизменному теплоотводу. Нагрев приходит из пространственной мощности через
`P`, температура возвращается через `P.T`. Обратная связь — явно заданный
синтетический линейный коэффициент реактивности по температуре. Это не
измеренные сечения и не доплеровская таблица конкретного реактора.

Решается единая система нейтроники, температур и интегралов тепла. Нативный
метод — неявный Эйлер с аналитическим якобианом и демпфированным Newton.
Проверяются области состояния, баланс нейтронов/предшественников и тепла.
Состояния не обрезаются и не перенормируются. Объявленное межсеточное усреднение остаётся частью модели; флаг отсутствия проекции означает отсутствие скрытого исправления состояния решателя. При позднем отказе отменяется
весь запрошенный интервал, включая уже вычисленные пробные подшаги.
Checkpoint содержит источник, конфигурацию и историю; JSON-restart выполняет
точный replay и отклоняет изменённый, даже заново запечатанный, вектор состояния.

**Вся тепловая мощность деления в этой задаче выделяется мгновенно.** Нейтронные
предшественники не являются моделью остаточного тепловыделения. Здесь нет
теплоносителя с запасами массы/импульса, адвекции, EOS, фазовых переходов,
банков управления или интеграции в StationEnv. Эту задачу нельзя использовать
как модель SCRAM и длительного остаточного теплоотвода.

## Область численной приёмки

Проверяются три конфигурации с четырьмя нейтронными ячейками: равномерное
возмущение без температурной связи; локальные возмущения с обратной связью;
тот же локальный случай с пятью несовпадающими тепловыми ячейками вместо трёх.
Горизонт — 0,2 с. Нативные шаги — 0,02/0,01/0,005 с; эталоны — Radau и BDF
на том же RHS и с аналитическим якобианом. Дополнительно равномерный случай
сверяется с матричной экспонентой независимой точечной шестигрупповой модели.

Получены девять нативных траекторий, шесть опорных траекторий и три пары
restart. Минимальный измеренный порядок временной сходимости конечного
состояния — 0,9884. Наименьший шаг даёт максимальную нормированную ошибку
менее 1,91e-5. Температурная шкала ошибки — 1 К; шкала интегралов тепла —
номинальная мощность, умноженная на 1 с. Остальные компоненты используют
нормировку существующей нейтронной модели.

Уточнение проверяет конечное состояние в трёх заданных конфигурациях,
а не равномерную оценку ошибки для любых траекторий. Разные IVP-алгоритмы
не означают независимые физические данные. Экспериментальная валидация
остаётся ложной.

## Локальное воспроизведение

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  .venv-layout/bin/python -m scripts.qualify_core_channels \
  --output artifacts/my-core-channels
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  .venv-layout/bin/python -m pytest -q tests/test_conservative_exchange.py \
  tests/test_core_channel_transient.py tests/test_multiphysics.py
```

После установки wheel квалификация запускается через `python -I -m
scripts.qualify_core_channels --output <новый каталог>` вне checkout.
Отдельно повторяется штатная квалификация `python -I -m atomic_model_multiphysics
--output <новый файл>`. Новые и существующие результаты сравниваются целиком,
включая источники и checkpoint, без удаления научных полей.

Протокол: [квитанция v123–124](benchmarks/core_channel_exchange_v123_v124.json).
Предварительный общий тестовый план был остановлен защитой исходников после
добавления зависимости в паспорт; его результаты не смешиваются с финальным
прогоном. Два процесса финального прогона прервались с SIGTERM до итоговой
квитанции; обе попытки сохранены и повторены на неизменных исходниках.

**NPP-12.03 остаётся открытым.** Готова проверенная основа обмена и отдельная
нестационарная задача. До принятия станционной связи нужны её подключение
к владельцам тепловых/гидравлических запасов PWR, полное тепловыделение,
применимые обратные связи и квалификация совместных переходов. Статус плана
остаётся 58/76, открыто 18 задач; R1/R2 не объявляются завершёнными.
