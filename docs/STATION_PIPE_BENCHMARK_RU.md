# Переходный радиальный benchmark восходящей нагреваемой трубы

`atomic_model_station_pipe` воспроизводит аналитическую базу и радиальное
инвариантное подпространство задачи Marensi, He, Willis (2021).
Реализован переходный совместный расчёт скорости и температуры с явными
регуляторами расхода и теплового стока, балансами и native-восстановлением.
Это следующий проверяемый компонент после [смешанной конвекции v64](STATION_MIXED_CONVECTION_RU.md).
Станционная плёнка v63 и инструменты v64 не изменены.

## Постановка и нормировка

Первичный источник: [Marensi, He, Willis, JFM 919, A17, 2021](https://doi.org/10.1017/jfm.2021.371),
уравнения 2.6, 2.9–2.12. PDF открыт по лицензии
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Нормировки, знаки и коэффициенты сверены по оригинальной странице 6.
Источник задаёт постоянные температуру стенки и средние величины,
регулируемый однородный тепловой сток и периодическое осевое направление.

Радиальное сокращение исключает осевые и азимутальные возмущения:

```
du/dt     = [L(u) + 4(1 + beta + C Theta)] / Re
dTheta/dt = [L(Theta) - 4 Nu_sink] / (Re Pr)
L(f)      = (1/r) d[r df/dr]/dr
u_wall = 0, Theta_wall = 1
area_mean(u) = 1/2, area_mean(Theta) = 1/2
C = Gr / (16 Re)
Nu_sink = epsilon / epsilon0
```

В последней строке — отношение регулируемого теплового стока к его
ламинарному значению. Это **не hD/k**, и не величина Nu=48/11 из UHF-задачи v64.
Температурное ограничение реализовано как среднее по площади; оно согласовано
с опубликованным базовым профилем Theta=r² и нормировкой температуры.
Смешанная температура, взвешенная расходом, выводится отдельно: в вынужденном
пределе она стремится к 1/3, тогда как среднее по площади равно 1/2.
Названия этих двух средних не используются взаимозаменяемо.

Единицы: длина R, скорость 2Ub, время **R/(2Ub)**. Горизонт 800 в этой программе
не означает 800 секунд станционного расчёта. Непосредственный перенос
этой нормировки на установку требует заданных геометрии и режима.

Аналитическая база:

```
u(r) = 1 - r² + C (r²/3 - r⁴/4 - 1/12)
Theta(r) = r²
beta = -C/3
Nu_sink = 1
```

Полиномы и библиографические сведения хранятся в небольшом упакованном
ресурсе `data/jfm2021_base.json`. Это аналитический эталон из публикации,
а не оцифрованные DNS-профили или измерения установки.

## Переходный решатель и явный энергетический учёт

Кольцевые конечные объёмы имеют точные геометрические веса. На каждом шаге
схема Кранка–Николсона совместно решает скорость, температуру и два множителя:
регулятор давления beta и тепловой сток Nu_sink. Предписанные средние входят
в систему как ограничения; профили после шага не прижимаются к границам
и не проецируются на заданное среднее.

Изменение давления, необходимое для сохранения расхода, учитывается явно.
При C>3 установившийся градиент может быть направлен против потока;
отрицательная работа давления допустима. Это не равнозначно локальному
обращению скорости. Контролируются положительные скорости во всех ячейках,
выбранный интервал Theta∈[0,1] и невязки ограничений. Нарушение отклоняет
весь внешний переход с откатом времени, профилей, истории и накопленных величин.
Положительность между узлами сетки и трёхмерная устойчивость этим не доказываются.

Для каждого шага накапливаются стеночный теплоприток и управляемый сток,
работа давления, работа плавучести и вязкая диссипация. Проверяются:

```
изменение интеграла температуры = теплоприток - сток
изменение кинетической энергии = работа давления + работа плавучести - диссипация
```

Для кинетической энергии схема использует средние значения обоих концов
шага, поэтому квадратичное энергетическое тождество согласовано с CN.
Тепловой сток — явно идеализированный внешний регулятор выбранного benchmark.
Это не конечный запас станционного DHR. Тепловой и механический балансы
относятся к сокращённым уравнениям Буссинеска; сумма не объявляется полным
термодинамическим балансом АЭС. Вязкое нагревание в тепловое уравнение не добавлено.

Работа ограничена: до 4096 подшагов за вызов, до 8192 за историю, 256 внешних
команд и времени 10000. Все интервалы времени здесь безразмерны.
Checkpoint содержит исходное состояние, конфигурацию, команды, профили,
регуляторы и накопленные балансы. Native-восстановление заново выполняет
историю и проверяет точное совпадение, а не доверяет записанному профилю.

## Три независимых численных сравнения

1. **Пространство.** Пять базовых профилей C=0, 3, 5, 7,5, 10 сравниваются
   с опубликованными полиномами на сетках 32, 64, 128. На подробной сетке
   максимальная абсолютная ошибка нормированных профилей — 1,98329·10⁻⁴;
   минимальный наблюдаемый порядок — 1,99692. Давление и тепловой сток
   сравниваются со своими аналитическими значениями отдельно.
2. **Время.** Для Pr=0,7 и Pr=1 переход после изменения C сравнивается
   с независимой матричной экспонентой той же пространственной системы.
   Прямой CN-решатель решает седловую систему с регуляторами; эталон
   исключает регуляторы в производной и интегрирует аффинную матрицу.
   Использованы шаги 10, 5, 2,5. Максимальная ошибка подробного расчёта —
   1,35875·10⁻⁶, минимальный порядок — 2,00027. Это независимая проверка
   временного алгоритма, а не другая физическая модель или сетка.
3. **Радиальные времена диффузии.** Для возмущения с нулевым средним
   аналитическая форма J0(kr)−J0(k) даёт условие J2(k)=0. Спектр FV-оператора
   в подпространстве нулевого среднего сравнивается с корнями Бесселя.
   Ошибка первой моды на сетке 128 — 1,64656·10⁻⁴; порядок — не ниже 1,99888.
   При Re=5300 и Pr=0,7 получены времена первой моды около 200,984
   для скорости и 140,689 для температуры в единицах R/(2Ub).

Последние числа — масштабы отдельных диффузионных секторов. Они не задают
универсального времени установления связанной системы: возможны связанные
ненормальные переходы, в частности при совпадении времён для Pr=1.
Осевые/азимутальные моды и механизм подавления турбулентности не исследованы.

## Вся траектория и восстановление

Полный пример на 800 единиц R/(2Ub) содержит четыре участка C=3, 5, 7,5, 0
с 32 сохранёнными переходами. Начальное возмущение задаётся с нулевым
дискретным средним. Каждая последующая строка сравнивается с независимой
матричной экспонентой, максимальное расхождение — **1,48715·10⁻⁵**.
В исходной серии максимальные абсолютные невязки теплового и кинетического
накопленного учёта — соответственно 9,27037·10⁻¹⁵ и 4,19110·10⁻¹⁵.

На 400 единицах сохранён checkpoint. Native-повтор точно восстановил его,
заново выполнил следующие 400 единиц и сравнил каждый профиль, регулятор,
баланс и конечный checkpoint. Отдельные отрицательные тесты проверяют
отказ позднего подшага, нечисловое решение, искажённый checkpoint, нарушение
среднего и исчерпание бюджета. Неуспешный переход не оставляет частичного
изменения владельца состояния.

## Как использовать

```python
from atomic_model_station_pipe import PipeCase, PipeSession

flow = PipeSession(PipeCase(reynolds=5300, prandtl=0.7, cells=64))
frame = flow.advance(200, buoyancy_c=5)
saved = flow.checkpoint()
restored = PipeSession.restore(saved)
```

Локальная программа:

```bash
python -m pytest tests/test_station_pipe.py tests/test_station_pipe_qualification.py
python -m scripts.qualify_station_pipe --output artifacts/my-radial-study
python -m scripts.verify_local_library --output artifacts/my-library --phase-timeout-s 7200
python -m scripts.verify_station_pipe_delivery --output artifacts/my-installed-radial --source-evidence artifacts/my-radial-study --library-evidence artifacts/my-library
```

Квалификатор создаёт восемь научных JSON. Установленный повтор выполняет
расчёты заново в свежем Python -I вне checkout, сравнивает все файлы точно
и проверяет наличие ресурса с аналитической базой в wheel. Операционные
журналы и время ОС отделены от научных данных. CI не требуется.

## Что остаётся до станционного замыкания

При большом Re здесь всё равно решается радиальное инвариантное подпространство.
Это не DNS, не RANS и не доказательство ламинарного режима. В стационаре
Nu_sink стремится к 1 независимо от C; турбулентного усиления теплопереноса
в этом компоненте нет. Полные трёхмерные состояния и статистика исходной
публикации пока не воспроизведены, сравнения с экспериментами не заявлены.

Следующий шаг — независимые турбулентные данные той же тепловой постановки,
проверка вынужденного предела и подавления/восстановления турбулентности,
согласованные определения Nu и неопределённость. Затем нужен перенос к
тепловому условию и явно заданной геометрии станции, совместное замыкание
теплоотдачи и импульса и повтор полного выбега 1800 с. Новый `film_model`
не подключён; NPP-11.03/04 и R1 остаются открытыми.
