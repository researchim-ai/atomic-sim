# BEAVRS: условная проверка температурной обратной связи

Срез: 11 ноября 2026. Продолжение проверок [борной компенсации](BEAVRS_BORON_COMPENSATION_RU.md)
и [чувствительности калибровки](BEAVRS_BORON_SENSITIVITY_RU.md). Новый опыт не
подгоняет параметры по температурным измерениям.

## Источник и единицы

Из проверенного по SHA-256 файла MIT BEAVRS извлекаются изотермические
температурные коэффициенты таблицы `tbl:meas_c1phys` для первого цикла:

- ARO: −1,75 pcm/°F, или −3,15 pcm/K;
- D: −2,75 pcm/°F, или −4,95 pcm/K;
- CD: −8,01 pcm/°F, или −14,418 pcm/K.

Для коэффициента на градус Фаренгейта переход к коэффициенту на кельвин
требует умножения на 1,8. Для самой температуры используется обычное
аффинное преобразование. Эти два преобразования отдельно проверены тестом.
[Первичный файл с фиксированной ревизией](https://github.com/mit-crpg/BEAVRS/blob/1ccae04dc3830a5977f08ed7f5f7e1e51ded0d22/docs/specifications/expdata/expdata.tex).

В соседней таблице конфигурации HZP приведена входная температура 560 °F,
то есть 566,48333 K. Она используется только как температурная опора
условного опыта. Не подтверждено, что каждый ITC-замер сделан точно при
этой температуре. Давление в данном опыте не восстановлено из паспорта
измерений: 15,0 / 15,7 / 16,0 МПа — объявленные условия диагностического
сканирования модели, а не неопределённость давления BEAVRS.

## Проверяется настоящий метод реактивности

На свежем экземпляре `SourceBoundPWR` задаётся термодинамический путь:
одинаковая температура топлива и жидкости, постоянные давление,
концентрация 975 ppm и координата стержней. Метод `reactivity()` вызывается
при температурах `T-h` и `T+h`. Свойства жидкости вычисляются существующим
IF97-ядром, температура не подменяется линейной зависимостью плотности.

Это диагностические состояния для вычисления слагаемых реактивности.
Гидравлическое равновесие всей установки, критичность HZP, её мощность,
расход, геометрия и динамическая траектория этим не воспроизводятся.
Координаты 0 / 0,5 / 1 — проверка редуцированной модели, а не соответствие
реальным отдельным банкам ARO/D/CD.

Производная центральной разностью сравнивается с аналитической суммой:

`d(rho_reactivity)/dT = doppler_coef/(2*sqrt(T)) + density_coef*d(rho_water)/dT`.

Плотностная производная берётся из термодинамического якобиана IF97:
`d(rho_water)/dT = -rho_water**2 * d(v)/dT` при постоянном давлении.
Концентрация удерживается постоянной, поэтому линейное борное слагаемое
в эту производную не входит. Коэффициенты обратных связей не изменяются.

## Численная квалификация отдельно от физического соответствия

Матрица включает три давления, три шага 0,2 / 0,1 / 0,05 K и три координаты
стержней — 27 проб. Проверяются полнота матрицы, конечность значений,
уменьшение абсолютной ошибки при уменьшении шага и ошибка тонкого шага
менее `1e-5 pcm/K` относительно аналитической производной.

Первая версия приёмки требовала того же допуска от всех трёх шагов и
не прошла: на крупном шаге ошибка достигала `4,34e-5 pcm/K`. После этого
критерий явно разделён на сходимость и допуск тонкого шага. Сам допуск,
термодинамика, коэффициенты и шаги не изменены; тонкий шаг даёт ошибку
не более `2,72e-6 pcm/K`. Первая версия отчёта и её драйвер сохранены с
проверяемым исходным хешем. Это изменение численного критерия, а не новое
подтверждение экспериментального соответствия.

## Выявленное физическое ограничение

При 15,7 МПа условная производная равна примерно −32,01206 pcm/K.
Она одинаково сопоставляется со всеми тремя измерениями, поскольку в
текущем замыкании стержневая реактивность аддитивна и не меняет
температурные коэффициенты. Изменение координаты стержней в матрице меняет
численную производную лишь на уровне около `3,5e-12 pcm/K`.

Условные остатки относительно измерений: −28,86 pcm/K для ARO,
−27,06 для D и −17,59 для CD. Они не являются оценкой ошибки полной модели
BEAVRS: точные условия измерений и соответствие банков не восстановлены.
Тем не менее текущая структура замыкания не может самостоятельно передать
наблюдаемое различие коэффициентов между конфигурациями при одинаковых
заданных температуре и давлении.
В самих измеренных конфигурациях различаются также концентрации бора,
а точные условия каждого ITC-замера здесь не восстановлены. Поэтому
различия измерений нельзя однозначно приписать только положению стержней.
В текущем линейном борном слагаемом температурной зависимости также нет.

Умножение одного постоянного коэффициента на поправку не устраняет этот
структурный пробел. Нужны согласованные состояния отдельных банков,
состав/геометрия зоны и зависящие от состояния нейтронно-физические обратные
связи. Полная BEAVRS-конфигурация остаётся открытой задачей.

## Воспроизведение

```bash
python -m pytest -q tests/test_beavrs_temperature.py
python -m scripts.benchmark_beavrs_temperature --output artifacts/my-beavrs-temperature
```

Исходник с лицензией уже входит в wheel; сеть не нужна. Протокол сохраняет
явные предположения, численный критерий, идентичность модели и хеши драйверов.
`passed` относится только к вычислительной квалификации и целостности.
Неопределённость измерений не назначается. Сохраняются `validated=false`,
`plant_referenced=false`, `whole_plant_compared=false`.

## Проверка поставки

16 новых тестов проверяют исходные ITC-значения, преобразование единиц,
аналитическую производную, уточнение шага, независимость замыкания от
координаты стержней и строгую приёмку полной численной матрицы.
Пройдено 1335 тестов полного локального профиля и восемь фаз поставки.
Из установленного wheel вне checkout точно повторены все 27 проб и отчёт.
Протокол сверён после нормализации абсолютных путей драйверов; хеши
исходников совпали без нормализации.
