# Пространственный температурный отклик реактивности

Срез: 12 ноября 2026. В [условной проверке BEAVRS](BEAVRS_TEMPERATURE_FEEDBACK_RU.md)
обнаружено, что аддитивное стержневое слагаемое старой PWR-модели не меняет
её температурный коэффициент. Новый самостоятельный компонент
`atomic_model_neutronic_response` вычисляет отклик через прямой и
сопряжённый пространственные потоки существующего диффузионного ядра.
Старая PWR-модель и её параметры не изменены.

## Что реализовано

При заданных геометрии и многогрупповых коэффициентах решается задача
`L * phi = (1/k) * F * phi`. Затем решается транспонированная задача для
сопряжённого потока `psi`. Обе пары принимаются только после проверки
невязки; их собственные значения должны согласоваться.

Для реактивности `rho = 1 - 1/k`, при фиксированном операторе рождения,
получается чувствительность к поглощению в группе g и ячейке c:

`d(rho)/d(Sigma_a[g,c]) = -psi[g,c] * phi[g,c] * width[c] / (psi.T * F * phi)`.

Полная температурная производная в текущей области поддержки — сумма
этих весов, умноженных на заданные `d(Sigma_a)/dT` в единицах 1/(м·K).
Отклик возвращается в 1/K и pcm/K. Нормировки потоков не являются
независимыми физическими параметрами: знаменатель устраняет их произвол.

Входная производная может быть знакопеременной. Она не обрезается до
отрицательного или положительного отклика. Нулевой вход даёт нулевой
коэффициент. Требуются точная форма «группа × ячейка», конечные значения
и явно заданное происхождение производных. Переполнение, вырожденная
нормировка и незавершённая итерация не дают принятого результата.
Входные спецификации и массивы не изменяются.

## Почему отклик зависит от поглотителя

Поглотитель меняет оператор потерь и распределение потоков. Поэтому
изменяются веса температурных производных даже при неизменных заданных
производных фонового поглощения. Не требуется вручную назначать отдельную
поправку температурного коэффициента каждому положению стержня.

Это проверка механизма, а не доказательство правильной зависимости для
реальной зоны. Точный знак и величина эффекта зависят от геометрии,
сечений, их производных и принятой модели переноса.

## Независимая численная проверка

Использован существующий синтетический неоднородный двухгрупповой слой
длиной 1 м. Положение поглотителя 0 / 0,37 / 0,71 м задаётся через точное
перекрытие ячеек, без округления до ближайшего узла. На сетках 12 / 24 / 48
ячеек получено девять конфигураций. Производная поглощения задана только
в тепловой группе: `1e-5 * (1 + 3*x)`; в быстрой группе она нулевая.
Это явно численная функция, не оценённые ядерные данные.

Для каждой конфигурации собственное значение сверяется с плотным
независимым решателем. Он отдельно собирает операторы через матрицу
инцидентности и не читает производственные разреженные матрицы.
Температурный отклик проверяется центральной разностью его собственных
значений для шагов 2 / 1 / 0,5 K — всего 27 разностных сравнений.

Максимальная относительная ошибка сопряжённого отклика относительно
плотной разности — около `2,81e-8`, при допуске `1e-6`. На сетке 48 ячеек
отклики составили:

- поглотитель не введён: −23,53120 pcm/K;
- положение 0,37 м: −24,37582 pcm/K;
- положение 0,71 м: −18,93219 pcm/K.

Эти величины не сравнивались с BEAVRS и не подгонялись под его измерения.
Начальное k синтетической задачи не обязано быть единицей; это не
воспроизведение критического состояния установки.

Проверки на трёх сетках относятся к точности алгебраического отклика на
каждой сетке. Порядок пространственной сходимости и ошибка относительно
континуума этим опытом не приняты: дробное перекрытие поглотителя и
неоднородности требуют отдельной программы уточнения. В отчёте явно
сохранено `spatial_order_established=false`.

## Библиотечный интерфейс

```python
from atomic_model_neutronic_response import absorption_temperature_response

result = absorption_temperature_response(
    specification,
    derivative_per_m_k,
    derivative_provenance="Источник, версия и условия получения производных",
)
coefficient = result["temperature_coefficient_pcm_per_k"]
weights = result["absorption_gradient_m"]
```

`specification` имеет контракт существующего `atomic_model_spatial.Model`.
Возвращаются k, реактивность, прямой и сопряжённый потоки, ячеечные
чувствительности, невязки, число итераций и идентичность реализации.
Строка происхождения не удостоверяет физическую точность данных: её
применимость и неопределённости проверяются отдельно.

## Область поддержки и следующий этап

Сейчас меняется только поглощение. Температурные производные рождения,
спектров, диффузии, рассеяния и геометрии не учитываются. Компонент не
подключён к динамическому PWR, не формирует пространственные коэффициенты
из паспортных параметров и не является полной моделью BEAVRS.

Следующий шаг — производные остальных операторов и согласованные
многогрупповые данные по состояниям. Для BEAVRS затем нужны геометрия,
отдельные банки, условия HZP и независимые наблюдения. Синтетическая
квалификация не превращает коэффициенты в оценённые ядерные данные.
Сохраняются `validated=false`, `plant_referenced=false`.

## Воспроизведение

```bash
python -m pytest -q tests/test_neutronic_response.py
python -m scripts.qualify_neutronic_response --output artifacts/my-neutronic-response
```

Новый пакет должен быть установлен. Для запуска из исходников без
обновления editable-установки можно использовать `PYTHONPATH=src`.
Драйвер фиксирует входную матрицу, допуски и источники до расчётов,
публикует полный результат в новом каталоге. Сеть не нужна.

## Проверка поставки

11 новых тестов проверяют сопряжённую производную независимой плотной
разностью, локальный ячеечный градиент, влияние поглотителя, нулевые и
знаковые производные, неизменность входов и отказ при некорректных данных
или незавершённой итерации. Пройдено 1346 тестов полного локального профиля
и восемь фаз поставки. Протокол, все девять конфигураций и весь отчёт
точно повторены из установленного wheel вне checkout.
[Машинный результат](benchmarks/spatial_neutronic_response_v32.json).
