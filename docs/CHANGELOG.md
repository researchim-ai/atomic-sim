# Changelog

Все значимые изменения в проекте будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] - 2025-10-10

### Добавлено
- ✅ Модель отравления ксеноном и йодом (`reactor/poisoning.py`)
- ✅ Нелинейная S-образная кривая ценности стержней (`reactor/rod_worth.py`)
- ✅ Gymnasium обёртка для RL (`envs/gym_reactor.py`)
- ✅ Генератор датасетов (`generate_dataset.py`)
- ✅ Система сценариев в YAML (`scenarios/`)
- ✅ Параметр `deadband` в ПИД-регуляторе
- ✅ Конфигурационные файлы (`configs/`)
- ✅ Расширенный набор тестов (`tests/`)
- ✅ `pyproject.toml` для правильного packaging
- ✅ Поддержка экспорта датасетов в Parquet/JSONL/CSV

### Изменено
- 🔧 Исправлена численная стабильность (dt = 0.001)
- 🔧 Улучшена структура проекта (директория `tests/`)
- 🔧 Обновлен `requirements.txt` (добавлены gymnasium, pandas, pytest)
- 🔧 Улучшена документация (README, QUICKSTART)

### Исправлено
- 🐛 Исправлен порог срабатывания ПИД (использование параметра `deadband`)
- 🐛 Исправлено начальное критическое состояние (rod_position = 1.0)
- 🐛 Удален лишний символ из QUICKSTART.md
