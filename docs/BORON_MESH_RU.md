# Пространственная проверка борного обмена — v138

[English](BORON_MESH_EN.md) · [Компонент борного обмена](PWR_BORON_RU.md)

Пакет проверяет конечный борный обмен при совместном уточнении сеток,
сохраняя один физический набор коэффициентов и геометрию. Для каждой подачи
0 и 2000 ppm используются три разрешения:

- 2 нейтронные / 2 жидкостные / 4 тепловые ячейки;
- 4 нейтронные / 4 жидкостные / 8 тепловых ячеек;
- 8 нейтронных / 8 жидкостных / 16 тепловых ячеек.

Длина — 4 м, дополнительный K канала — 1. Тепловая сетка согласована
с источниками и жидкостью; гидравлика включает обе граничные половины.
Подающий и приёмный баки, насос, состав, расход и исполнительный механизм
остаются прежними. Источники и исходные параметры не подгоняются к подробной
сетке.

## Химический перенос отдельно от исходного распределения

Сохраняются 22 поля совместной PWR-проверки и два новых поля:
изменение концентрации в жидкостных ячейках и на нейтронной сетке.
Для каждой сетки берётся её собственное начальное состояние:

```text
delta_c(x,t) = c(x,t) - c(x,0)
```

Начальные плотности и массовое распределение могут отличаться между
дискретизациями. Сравнение только запасов бора способно оказаться нечувствительным
к малому изменению концентрации на фоне большого исходного запаса.
Дополнительные поля выделяют именно изменение состава. Нейтронные ppm
по-прежнему получаются массово-взвешенным переносом реальных M/B, без
прямого задания концентрации. Начальный опорный вектор должен принадлежать
той же сетке; недостающая ячейка не дополняется broadcasting.

Для приращений концентрации вычисляются нормы по точным перекрытиям с
масштабом **1 ppm**. Поэтому порог L2 `0.25` означает 0.25 ppm RMS,
а не четверть исходного содержания бора. Противоположные локальные ошибки
не исчезают при одинаковом интеграле.

## Сценарии и критерии

На каждом разрешении отдельно строится горячая стационарная PWR.
Начальные состояния первичного контура для двух химических случаев должны
совпадать; оборудование отличается только исходным бором подающего бака.
Станционная инициализация не объявляется физическим переходным процессом.

Подача открывается на 50 кг/с в начале и закрывается по команде в 2 с.
Наблюдения: `0`, `0.1`, `0.5`, `1`, `2`, `2.5 с`. Закрытие сохраняет точный
экспоненциальный хвост расхода. Каждый случай и разрешение запускаются
с `max_step_s=0.1, rtol=2e-8` и `max_step_s=0.05, rtol=2e-9`.
Всего **12 нативных траекторий**. Оба подробных fine-расчёта проходят точный
JSON-restart с 0.5 с; на меньших сетках дополнительные restart не заявляются.

Для всех 24 полей максимум L2 по наблюдениям должен уменьшаться:
4/8 ≤ 0.9 × 2/4. Пространственное различие должно превышать чувствительность
к настройкам времени не менее чем в 20 раз. Проверяются прежние отдельные
бюджеты полей и новый предел концентрации 0.25 ppm. Для этого активного
химического сценария бюджет расхождения полной мощности 4/8 — `0.005`
начальной мощности, полного состояния по времени — `1e-4`.
Это численные критерии данного пакета, не физическая неопределённость и
не перенос более строгого критерия другого сценария.

Дополнительно обязательны:

- глобальные масса/энергия/бор и нейтроны/предшественники;
- расходование конечных баков по точному интегралу расхода и правильный
  знак изменения первичного бора;
- локальные энергетические и энтропийные тождества теплопередачи;
- погонные теплоёмкости/UA, полная инерция, опорная кинетическая энергия,
  распределение коэффициентов по каждой гидравлической грани;
- перенос M/B и замороженная опора, базовый ранг/невязки равновесия,
  rollback неправильной команды;
- разрешимое различие мощности химических случаев на каждом разрешении.

Мощность и запасы не заменяют поля: сохраняются все значения каждого времени,
семейства и сетки. Нет оценки ошибки до непрерывного предела или заявления
о независимой экспериментальной проверке.

## Restore без повторного решения базы

`BoronExchangePWRSession.restore` сначала восстанавливает базовую PWR с
проверкой источников, повторным решением равновесия и сравнением checkpoint.
Проверенный объект копируется, новые баки заново создаются из конфигурации,
после чего воспроизводятся команды. Повторное решение той же базы удалено.
Тест проверяет один вызов базового конструктора и точное продолжение.
Непроверенные сохранённые состояния баков не используются как начальные.

Геометрический аудит первого запуска выявил ошибку диагностики: родительский
список расходов захватывал добавленные переменные баков. Срез ограничен
собственными внутренними гранями канала; новый тест проверяет длину, значения
и геометрический баланс при ненулевой подаче. Неуспешный запуск сохранён.

Изменения исходников канала и адаптера меняют source-bound подписи
канального семейства PWR. Прежние checkpoint автоматически не перепривязываются; отдельное сравнение физических
траекторий с v137 служит только численной проверкой регрессии.

Принятая поставка: **88 целевых, 78 дополнительных регрессионных тестов и 47 тестов из wheel**, восемь успешных фаз, научный JSON совпал целиком. L2 приращения нейтронной концентрации 4/8: `0.13190705 ppm` и `0.14289137 ppm`. Максимальное временное расхождение полного состояния — `1.41225e-05`. Все 13 отрицательных контролей сработали, включая ошибки обоих фронтов и начальной опоры, локального распределения коэффициентов, энергии, переноса и restart.

## Локальное воспроизведение

```sh
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:. \
  python -m scripts.verify_component_delivery --component boron-mesh \
  --output artifacts/boron-mesh-local --phase-timeout-s 1200
```

Нужен новый каталог. Профиль выполняет целевые тесты, научную матрицу,
sdist → wheel, свежую установку вне checkout и полный научный replay.
Совпадает весь научный JSON; его читатель имеет явный предел 16 MiB.
CI и сеть не используются. Результаты и хеши — в
[протоколе v138](benchmarks/boron_mesh_v138.json).

Результат относится к этим двух с половиной секундам, однофазной воде,
иллюстративному коэффициенту бора, линеаризованным бакам и активному питанию
насоса от внешней сети. Длительные режимы, регенеративная теплообменная схема
реальной CVCS, химия/растворимость, физические события исчерпания и потери
питания, StationEnv и экспериментальная валидация остаются открытыми.
Новый час и полный библиотечный профиль не выполняются.
Корневой план — **58/76, открыто 18 задач**.
