# Калибровка управления: точность и энергия

Срез: 11 ноября 2026. Продолжение [первого обучения](THERMAL_AGENT_TRAINING_RU.md),
где линейная imitation-политика немного уменьшила ошибку относительно
фиксированного PI, но потратила примерно в 2,2 раза больше энергии.
Физическое ядро и исходная Gymnasium-среда в новом блоке не меняются.

## Что изменилось

Вместо оценки одной точности вводится заранее заданная безразмерная функция:

`J = IAE / (decision_duration * target_rise) + 0.25 * energy / (decision_duration * max_power)`.

IAE измеряется в K·с, энергия — в Дж. Оба слагаемых нормированы, вес энергии
0,25 зафиксирован до test. Это исследовательское предпочтение между двумя
метриками, не цена электричества и не экономическая оптимизация установки.
Сохраняются также раздельные IAE и энергия — улучшение J может сопровождаться
ухудшением одной из них.

Imitation-веса по-прежнему обучаются только по четырём train-демонстрациям
аналитического учителя. Затем по train-переходам выбирается масштаб выхода
политики из 0,15 / 0,3 / 0,6 / 1,0. Это небольшая калибровка политики
по симуляционному objective, а не новый RL-алгоритм.

PI теперь также настраивается на train: пропорциональный коэффициент
20 / 40 / 60 / 100 кВт/К, фиксированный интегральный коэффициент и номинальный
feedforward. Добавлено условное anti-windup при насыщении запрошенной мощности.
Это лучший PI **среди четырёх указанных вариантов**, не доказанный оптимум PID/MPC.

Оба поиска имеют по четыре кандидата, четыре train-конфигурации и два общих
шумовых seed: 32 калибровочных эпизода на семейство, всего 64.
У обучаемого семейства дополнительно есть четыре исходные teacher-демонстрации;
равенство всех затрат обучения с PI не заявляется.

## Конец горизонта больше не скрывает задержанные действия

После восьми интервалов управления подаётся нулевой запрос мощности.
Моделирование продолжается ещё
`delay_steps + ceil(max_power / (slew * dt)) + 2` интервала.
Это позволяет реализоваться запросам в FIFO-очереди, снизить фактическую
мощность с учётом slew и проверить два дополнительных интервала.

Энергия и ошибка этого хвоста включаются в общий J. Отдельно сохраняются
энергия активной части и энергия после завершения управления. Эпизод не
считается завершённым, если очередь и мощность не обнулились.

Изначальное время изменения задания сохраняется: увеличение длительности
эксперимента не сдвигает переключение цели. Для этого в экспериментальном
runner используется `TailEnv`; это внутренний адаптер эксперимента,
его checkpoint не экспортируется как новый поддерживаемый формат среды.
Установившееся состояние за такой короткий хвост не гарантируется.

## Оценка без выбора по test

Выбранные параметры записываются в `training.json` **до** оценочных расчётов.
Test содержит прежние четыре открытые конфигурации, теперь по три шумовых
seed. На каждой паре case/seed выполняются исходная imitation-политика,
откалиброванная политика, выбранный PI и постоянная мощность: всего 48 эпизодов.
Все политики получают одинаковые шумовые последовательности на общей сетке.
Физические параметры теста не участвуют в подборе коэффициентов.

Это повторная оценка публичного корпуса, а не слепое испытание. Три seed на
четырёх объектах не равны двенадцати независимым объектам; статистическая
значимость и промышленная переносимость не заявляются.

## Проверки и запуск

10 новых тестов проверяют безразмерную функцию, отрицательные/NaN-метрики,
запрет выбора из незавершённых train-кандидатов, стабильный выбор при равенстве,
сохранение времени переключения цели и учёт энергии задержанного действия
после конца активного горизонта.

```bash
python -m pytest -q tests/test_thermal_energy.py
python -m scripts.optimize_thermal_control --output artifacts/my-thermal-energy
```

Полные train/test-трассы: `artifacts/thermal-energy-v1/`.
[Машинный протокол и результаты](benchmarks/thermal_energy_control_v23.json).

## Полученный результат

Все 48 test-эпизодов завершились без наблюдаемых нарушений с опустевшей
очередью и нулевой мощностью. Выбраны масштаб политики 0.6
и PI kp=100000 Вт/К. Относительно исходной imitation-политики
энергия откалиброванной политики уменьшилась на 28.65%,
изменение IAE составило -21.81%,
а J уменьшился на 24.21%.
Относительно выбранного PI отношения составляют: энергия
0.981, IAE 1.022.
По общему J выбранный PI пока немного лучше откалиброванной политики
(около 0,594 против 0,603). Снижение энергии на 1,86% относительно PI
сопровождается ростом IAE на 2,24%; доминирования над PI нет.
Это описательная оценка на четырёх открытых конфигурациях, не промышленное превосходство.

Метрики всех test-трасс пересчитаны из температур, мощностей и длительностей.
Пройдено 1196 тестов и восемь фаз локальной поставки. Один оценочный эпизод
с хвостом точно повторён из установленного wheel вне checkout;
полное обучение из wheel не повторялось.

## Как интерпретировать результат

Сначала проверяются завершение, наблюдаемые ограничения и балансы;
затем сравниваются IAE, фактическая энергия и J на общих случаях.
Исходная политика должна сравниваться с новой на одном и том же хвосте,
поэтому проценты из предыдущего короткого эксперимента нельзя напрямую
сопоставлять с новыми суммами энергии.

Результат одного подобранного веса энергии не является всем фронтом Парето.
Следующие работы: несколько заранее заданных бюджетов энергии, более сильный
PI/MPC, более длительное установление режима, больше физических конфигураций,
другая модель датчиков и независимая динамическая проверка. Основной горизонт
управления всё ещё 2 мс, полный — несколько миллисекунд, а не промышленный цикл.
