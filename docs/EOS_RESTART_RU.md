# EOS: восстановление checkpoint и различение области модели

Дата: 30 октября 2026. Продолжение [АЗ и выбега насоса](SCRAM_COASTDOWN_RU.md).

Позднее реализовано [уточнение допустимого префикса и контролируемый останов](MODEL_BOUNDARY_RU.md).
Получен устойчивый численный результат около 122.2026 с; физический корень
границы не считается доказанно локализованным.

## Исправленные причины

1. **Холодное обращение жидкости.** Для core/hot_leg на 120 с существовало
   решение области 1 IF97, но Newton и общий поиск из номинального состояния
   не находили его. Резервный путь локализует температуру по заданной внутренней
   энергии при фиксированном пробном давлении, строго внутри жидкой области.
   Полученное приближение передаётся Newton для решения **обоих** исходных
   уравнений объёма и энергии. Прежний порог нормированной невязки 5e−14
   сохранён. Скалярное совпадение энергии само по себе не принимается за решение.
   Быстрый путь сохраняет лимит 8 итераций; резервному разрешено до 48,
   чтобы дробление шага около насыщения не обрывало сходящийся поиск.
2. **Выход разностной пробы секущей из диапазона насыщения.** Ограничение
   основного приближения не ограничивало `guess + step`. Теперь проба вне
   реализованной области насыщения отклоняется, а поиск продолжается резервным
   путём. Это не расширение области IF97 и не подмена физического состояния.
3. **Узкий двухфазный интервал около x=0.** Редкая сетка давлений не содержала
   точек по обе стороны корня. В резервную локализацию добавлены границы,
   найденные из u_f(p)=u и u_g(p)=u. Корень объёма ищется между допустимыми
   соседними точками; через недопустимый участок скобка не проводится.
   Последний узел сетки проверяется на корень явно.

Тёплый быстрый путь сохранён. Масса, энергия, физические коэффициенты и пределы
паспорта не менялись; проекция не применялась. Двухфазные состояния насыщения
области 3 этим изменением не реализованы.

## Проверка восстановления и продолжения

Все пять ранее исследованных checkpoint восстановлены в новых сессиях с
**точным совпадением экспортированного снимка**:

- обе АЗ на 60 с;
- оба защищённых выбега на 120 с;
- checkpoint 120 с из незавершённого запроса выбега 1800 с.

Из каждого выполнено продолжение на 0.25 с. Это проверка конкретных снимков,
не гарантия восстановления произвольного состояния. Их SHA-256 и текущий
source fingerprint сохранены в `validation/eos_restart_verified.json`.
После увеличения итерационного бюджета повторены все пять восстановлений и
продолжений: `validation/eos_restart_release_checks.json`.

Дополнительно выполнен непрерывный расчёт от номинала до 120.25 с:
`artifacts/coastdown_restart_reference_120_25s`, **120.25/120.25 с за 9.97 с**,
численные бюджеты выполнены. В конечной точке результат после восстановления
старого checkpoint 120 с и продолжения на 0.25 с согласуется с непрерывным:

- относительная разница тепловой мощности **4.68e−11**;
- температура топлива **6.14e−12 K**;
- давление первого контура **9.69e−6 Па**, ПГ **1.34e−7 Па**;
- расход **2.73e−6 кг/с**.

Все прежние численные пороги выполнены. Это сравнение одной конечной точки,
а не всей траектории рестарта. Результат, хеш checkpoint, бюджета и reference
manifest: `validation/eos_restart_continuation_agreement.json`. Время запуска
не является измерением realtime/HIL-пригодности.

## Что показал длительный выбег

После исправления EOS новый пакет `artifacts/coastdown_1800s_phase_brackets`
снова запросил 1800 с. Последняя принятая точка при выводе через 5 с — **120 с**.
Попытка пройти 120–125 с остановлена сообщением **«Объёмное кипение в первичном
контуре core вне паспорта ВВЭР»**, а не несходимостью обращения EOS.

Это срабатывание ограничения модели по качеству x>1e−4. Оно не доказывает
момент кипения реального блока. Порог не повышался ради завершения расчёта.
Финальный повтор с увеличенным резервным бюджетом Newton сохранён отдельно:
`artifacts/coastdown_1800s_eos_release`.
При дополнительных продолжениях из 120 с с меньшими шагами получены последние
принятые точки:

- шаг 0.25 с: **122.0 с**, качество core около **3.09e−5**;
- шаг 0.125 с: **122.125 с**, качество около **6.73e−5**;
- шаг 0.0625 с: **122.1875 с**, качество около **9.31e−5**.

Следующие попытки во всех случаях вышли за тот же предел. Отказ мог возникать
на внутренней пробе RHS: **точное время пересечения границы не локализовано**.
Запрещено выдавать эти точки за полную приёмку 1800 с или считать пределы шагов
доказанными скобками физического события. Диагностика:
`validation/coastdown_boiling_limit_probe.json`.

Профиль из прежнего проблемного checkpoint теперь проходит restore и фиксирует
`domain_error` во время шага: `validation/coastdown_eos_resolved_profile.json`.
Предыдущие файлы `coastdown_eos_failure_profile.json` и
`scram_coastdown_restart_checks.json` оставлены историческими.

## Проверки реализации

Финальный общий прогон: **299 passed, 1 deselected за 114.13 с**, без
предупреждений в этом запуске. Он включает все 17 новых проверок холодного
обращения, фазовой границы и ограничения кипения. Не повторялся неизменённый внешний
OpenMC/MPI particle-run. Покрытие не измерялось.

Проверены холодные приближения давления 8 кПа / 15.8 МПа / 80 МПа для шести
жидких состояний, включая точки в 0.01 K от насыщения; маленькие качества
0 / 1e−6 / 2.5e−5 / 1e−4 / 1e−3; восстановление горячей жидкости; отказ
резервного жидкого поиска для пара и несовместимого объёма. Сравниваются
плотность, энергия, давление и температура, а не только флаг успеха.
Дополнительно проверены холодные приближения для недогрева 1e−5 и 1e−7 K.

Ruff прошёл. Установленный вне checkout wheel прошёл прежние CLI-сценарии
и новую проверку холодного восстановления hot_leg. Это численная верификация
одной реализации EOS; независимая экспериментальная валидация не выполнена.

## Следующие этапы

1. Добавить локализацию границы применимости с различением внутренней пробы и
   последнего принятого состояния, чтобы выдавать воспроизводимое время останова.
2. Развивать кипение и длительное остаточное охлаждение как **отдельный паспорт**:
   консервативные фазовые потоки, теплообмен при кипении, пределы замыканий,
   отдельные проверочные задачи. Нельзя просто снять существующий порог x.
3. Для естественной циркуляции нужны явные отметки геометрии и независимые
   эталоны; нынешняя эквивалентная петля их не содержит. Параметры реального
   блока не должны заменяться вымышленными значениями.
4. Принять расширенную модель по независимым данным и сравнениям кодов, затем
   повторять 1800 с. `validated` и `plant_referenced` остаются false.
