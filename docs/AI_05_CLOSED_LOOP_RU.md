# Совместное сохранение модели, регулятора и генератора измерений

`ClosedLoopRadau` из `scripts/closed_loop_radau.py` владеет одной моделью
`SupervisedRadauGraph`, памятью регулятора и локальным `random.Random`.
Это зарегистрированная политика `sampled_schmitt_v1`: дискретный двухрежимный
регулятор с зоной гистерезиса. Произвольные PID/нейросети/внешние процессы
этим контрактом не сохраняются.

```bash
python -m examples.closed_loop_radau
python -m pytest tests/test_closed_loop_radau.py -q
python -m scripts.qualify_closed_loop_radau run artifacts/ai05_closed_loop_campaign_v1.json
python -m scripts.qualify_closed_loop_radau audit artifacts/ai05_closed_loop_campaign_v1.json
```

## Вход и порядок шага

Внешний ввод: `format: atomic-closed-loop-radau`, `schema_version: 1`,
`plant` в формате `atomic-supervised-mode-graph` и `policy`:

```json
{
  "kind": "sampled_schmitt_v1",
  "sensor_node": "a",
  "low_k": 310.0373,
  "high_k": 310.1037,
  "heat_mode": "heat",
  "cool_mode": "cool",
  "initial_decision": "heat",
  "sample_period_s": 1.0,
  "noise_amplitude_k": 0.01,
  "seed": 42
}
```

Оба режима должны быть разрешены для онлайн-команд модели. На отсчёте `i`
измеряется температура текущего состояния, потребляется ровно один `random()`
из локального генератора и добавляется шум `amplitude * (2*u - 1)`.
При измерении <= low выбирается heat, >= high — cool, внутри зоны сохраняется
предыдущее решение. Нулевой шум также потребляет один отсчёт RNG.
Seed — целое 0..2^64-1, амплитуда 0..1 K. Глобальный RNG не изменяется.

Команда применяется в момент `i * sample_period_s`, затем модель рассчитывается
до `(i+1) * sample_period_s`. Внутри интервала работают её календарь и guards.
Память регулятора хранит его последнее решение; календарное переключение
модели её не переписывает. Следующее измерение может снова выбрать этот режим.
Все ограничения возраста, входа и порядка событий модели действуют также
на первую команду при t=0. Несогласованное начальное решение может привести
к отказу, а не к скрытому сбросу residence.

`run(ticks, expected_revision=...)` исполняет 1..64 отсчёта одной транзакцией;
`step(expected_revision=...)` — один отсчёт. Максимум эпизода — 1024 отсчёта.
Ревизия эпизода увеличивается один раз на успешный пакет, ревизия модели —
на каждый принятый отсчёт. Устаревшая ревизия отклоняется до потребления RNG.
Разбиение на пакеты сохраняет физику, последовательность решений и RNG;
метаданные транзакций отражают фактическое разбиение.

Если численный root-интервал находится в пределах `1e-7 s` от момента
измерения, пакет отклоняется с `ambiguous_sample_order`. Скрытого приоритета
между защитой и выбором регулятора нет. Проверка относится к численной
траектории и не является границей физической ошибки ОДУ.

## Атомарность и ресурсы

Ошибка после нескольких успешных внутренних шагов откатывает весь пакет:
состояние модели, календарный курсор, историю команд, память регулятора,
номер следующего измерения, ревизию и состояние RNG. Это относится также
к ошибке политики, итогового наблюдения и проверке исходников.

Помимо ограничений каждого шага модели действуют общие лимиты пакета:
200000 RHS, 100000 локальных вычислений корня, 20000 попыток,
256 событий и 128 физических переключений. `run` возвращает наблюдение
и `work` с суммарной работой и максимальным фактическим внутренним шагом.
`work` относится к последнему вызову, не является состоянием регулятора.

## Checkpoint и доверие

Внешний `closed-loop-radau-v1` связывает полный ввод и будущий календарь,
численные настройки, исходники, бюджет и реализацию/версию Python.
Он содержит вложенный checkpoint модели и сериализованное состояние RNG.
Восстановление проверяет последовательность измерений, решения по зоне,
принадлежность команд отсчётам, путь ревизий, квитанции модели и конечное
наблюдение. Последовательность RNG заново строится от seed и сверяется
со всем журналом и сохранённым состоянием. Предоставленный RNG-state
не исполняется как код и не передаётся произвольному плагину.

Проверяется точное продолжение в том же окружении. Хеш не является подписью
или доказательством подлинности истории. Истинные температуры промежуточных
измерений не восстанавливаются отдельным полным физическим replay при restore:
проверяются алгебра решения политики, связи хешей наблюдений и вложенное
текущее состояние модели. Для независимой проверки исполнения служит
сравнительная кампания. Нельзя считать произвольно переписанный и заново
захешированный журнал доказательством реально выполненного эксперимента.

## Численная проверка и открытые границы

Матрица: 9 программ, три разных ограничения макрошага, по 40 измерений,
до 8 узлов. Для восьмиузлового случая период 0.25 s и горизонт 10 s;
для остальных — 1 s и 40 s. Есть два seed, нулевой/ненулевой шум,
календарная пауза, смена давления, мостовая сеть и автономный защитный guard.
Фактические максимальные шаги должны различаться минимум в 1.2 раза.

Отдельный регулятор в эталоне сам вычисляет измерения и решения по своей
физической траектории. Он не получает принятые решения production-регулятора.
Для каждой программы выполняются DOP853 и Radau с независимым смешанным
гидравлическим решателем: всего 18 замкнутых эталонных траекторий.
Сравниваются все измерения, решения, порядок/времена событий и конечные
температуры, давления, расходы и энергия. Жёсткие пороги политики делают
сценарии около границы чувствительными к численной ошибке: совпадение
решений на этой матрице не обещает устойчивости любой будущей политики.

Общая сборка оборудования, инерция сети, переменные свойства среды,
экспериментальная валидация, произвольные агенты и переносимость точного
replay между платформами остаются открытыми. Вложенный checkpoint модели
отдельно не сохраняет регулятор; возобновлять эпизод нужно внешним объектом.
