# Нагреваемая замкнутая петля с плавучестью

`BuoyantInertialGraph` из `scripts/buoyant_inertial_graph.py` добавляет к
тепловой инерционной сети температурную силу плавучести. Нагреватель и
охладитель находятся на разных высотах; расход развивается из состояния
покоя без источника напора. Это редуцированная энергетически скомпенсированная
модель Буссинеска, не полная постановка переменной плотности/EOS и не
естественная циркуляция реальной реакторной установки.

```bash
python -m examples.buoyant_graph
python -m pytest tests/test_buoyant_graph.py -q
python -m scripts.qualify_buoyant_graph run artifacts/ai05_buoyant_graph_campaign_v1.json
python -m scripts.qualify_buoyant_graph audit artifacts/ai05_buoyant_graph_campaign_v1.json
```

## Контракт и область

Внешний JSON: `format: atomic-buoyant-inertial-graph`, `schema_version: 1`,
`base` в формате `atomic-thermal-inertial-graph` и `buoyancy`:

```json
{
  "expansion_per_k": 0.001,
  "reference_temperature_k": 300.0,
  "maximum_relative_density_change": 0.05
}
```

Только связные замкнутые сети с хотя бы одним контуром, одной границей
давления и нулевыми подачами массы. Граница давления фиксирует уровень
давления; её изменение не является насосом или перепадом напора.
Сохраняются постоянные rho_ref в массе, инерции, теплоёмкостях и переносе
массы; изменяется только диагностическая плотность для гравитационного
члена. Ни объёмное расширение, ни сжимаемость в эту модель не входят.

Для трубы j с концами a,b:

```text
theta_edge = (T_a + T_b)/2 - T_buoyancy_reference
rho_gravity = rho_ref * (1 - beta*theta_edge)
force_buoyancy = rho_ref*g*beta*theta_edge*(z_b-z_a)
L*qdot + Aᵀ(p + rho_ref*g*z) + loss - force_buoyancy = 0
```

Давления свободных узлов решаются совместимо с производной массовых
ограничений. Начальная проекция уже использует фактическую температуру.
Средняя температура в силе — выбранная дискретизация плотности по трубе;
это не профиль температуры, разрешённый вдоль её длины.

Проверяются договорные ограничения этой реализации: относительная аномалия
плотности <= заданного предела, максимум 5%; `abs(T-Tref)/Tref <= 0.1`;
`g*beta*height/cp <= 0.01`. Это не нормативные критерии применимости к воде.
Выход из них отклоняет весь вызов без clipping. Reference temperature
плавучести — физический параметр линейного закона, отдельный от нуля
отсчёта переносимой тепловой энергии.

## Энергия и выбранное замыкание

Работа плавучести по трубе `b_j = q_j*force_buoyancy_j/rho_ref` может быть
положительной или отрицательной. Точно тот же поток энергии поровну
вычитается из тепловых запасов её концов. При отрицательной работе кинетическая
энергия переходит в тепло. Доля трения, возвращаемая жидкости, учитывается
отдельно, как в предшествующей модели.

```text
DeltaK - W_pressure - W_gravity - W_buoyancy + F_fluid + B_export = 0
DeltaU - Q_external - H_external - F_fluid + W_buoyancy = 0
DeltaK + DeltaU - W_pressure - W_gravity - Q_external - H_external + B_export = 0
```

В последнем балансе работа плавучести сокращается, а не добавляется к внешнему
нагреву. Седьмой интеграл `buoyancy_work_j` сохраняется вместе с прежними
шестью. Сохраняется явный учёт механического, теплового и общего балансов.

Мотивация противоположных знаков обмена — разбор уравнений кинетической и
внутренней энергии в [Maruyama, 2014, §2, (19)–(24)](https://arxiv.org/abs/1405.1921).
Наше замыкание с `U = sum(rho_ref*cp*V*temperature_increment)` и разнесением
работы по конечным узлам является отдельно объявленной дискретной моделью.
Оно не реализует все термодинамические члены температурного уравнения (25)
той работы и не доказывает полный Gibbs/EOS/энтропийный баланс. Источник
не является экспериментальной валидацией нашей схемы.

## Управление и checkpoint

`advance(dt)` и `step(full_gauge_pressure, dt, expected_revision=...,
command_id=...)` сохраняют прежнюю транзакционную семантику. Меняется лишь
абсолютный уровень давления. Скачок сохраняет расходы, температуры,
кинетический/тепловой запасы и все семь интегралов. Любой отказ стадии,
ресурсов, итогового наблюдения или исходников откатывает всю операцию.

`closed-buoyant-radau-v1` связывает базовую сеть, тепловые параметры, beta,
reference temperature, предел аномалии, исходники/бюджеты, шаг и версии
библиотек. Проверяется точное продолжение в том же окружении. Старый
тепловой checkpoint без седьмого интеграла сюда не переносится автоматически.
Хеш не является подписью или доказательством подлинности всей истории.

Чистый размерный residual вычисляет импульс с силой плавучести, массу,
тепловые уравнения и семь энергетических производных. Для интегрирования
используется сохранённый C-contiguous базис массовых ограничений. Нулевая
инерция, массовые источники и несколько границ давления не поддержаны
этим семейством. Проверки области относятся к вычисляемым стадиям и
наблюдениям, не являются строгим интервальным доказательством.

## Численная проверка

Девять программ по 40 s: гидростатический покой, однородный нагрев, запуск
нагреваемой/охлаждаемой петли и её зеркальной версии, горячий старт с
противоположным расходом, отключённая гравитация, отключённое расширение,
восемь узлов и разветвлённые контуры со сменой gauge pressure.
Три фактически различных шага, 27 траекторий и 189 наблюдений.

Два независимых эталона — DOP853 и Radau — интегрируют полные расходы и
тепловые приращения, решают окаймлённую систему ускорений и давлений и
самостоятельно собирают силу/теплообмен. Они не вызывают production RHS,
проекцию, residual или базис. Сравниваются температуры, давления, расходы
и семь интегралов. Три некорректных программы должны отказать с откатом.

Дополнительно независимый root решает полные стационарные уравнения
импульса, массы и тепла для трёх ненулевых ветвей. Знак начального приближения
объявлен, единственность ветви не предполагается. Production backend
инициализируется найденными состояниями и удерживает их ещё 40 s;
это отдельные три проверки, не увеличение числа переходных траекторий.
Окончание 40 s запуска само по себе не объявляется достижением стационара.

Отдельно проверены точный начальный напор горячей/холодной ветвей,
гидростатика тёплой жидкости, оба знака энергетического обмена, переход
через нулевой расход, инвариантность к сдвигу высоты и искусственное
удаление тепловой компенсации: последнее обязано нарушить баланс и
откатить расчёт.
