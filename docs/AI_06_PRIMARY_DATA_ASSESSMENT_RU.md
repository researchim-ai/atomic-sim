# AI-06.06 / AI-09: первичные данные и проверка применимости

Добавлен отдельный `atomic_model_hem_assessment`. Исходники принятых HEM-семейств не изменены; их checkpoints и численные свидетельства сохраняют прежние идентичности. Экспериментальная приёмка двухфазной динамики не объявляется.

## Реальные измерения HIPER

Первичный источник — Oettig, Licht, Westermeier, Schifflechner, Spliethoff, TUM:
[An Experimental Study on Boiling Crises with Water: Measurement Dataset](https://mediatum.ub.tum.de/1839312), DOI [10.14459/2025mp1839312](https://doi.org/10.14459/2025mp1839312).

Встроены все **176 опубликованных XLSM, по 70 сегментов: 12 320 строк**. Числовые значения преобразованы в SI, сохраняются имена workbook, номера строк и SHA-256 каждого исходника. Данные и производный набор имеют отдельную лицензию **CC BY-SA 4.0**, атрибуция в `data/hiper/NOTICE.md`; лицензия Apache на код её не заменяет. Сжатый CSV занимает около 2,1 МБ. Полный исходный ZIP остаётся в игнорируемом кэше, для обычного запуска сеть не нужна.

Импортёр читает OOXML без запуска макросов, внешних ссылок или Excel. Отказывается от формул с непроверенными cached values, неизвестных единиц/столбцов, непарных строк неопределённости, нечисловых значений, дубликатов и небезопасных ZIP/XML. Все строки сохраняются, качество не обрезается к [0,1]: исходный X — энтальпийная равновесная величина, возможны отрицательные значения и значения выше единицы.

Выявлены и явно сохранены расхождения источника:

- веб-карточка и архив содержат 176 опытов, README упоминает 189;
- README обозначает давление в MPa, заголовки самих workbooks — **bar**; преобразование следует заголовкам и физически согласуется с диапазоном опытов;
- номинальный диаметр из описания не подменяет фактический диаметр каждой строки.

Опубликованные асимметричные абсолютные границы неопределённости сохранены для диаметра, входной/локальной/стеночной температуры, давления, энтальпии, теплового и массового потоков. Доверительный уровень и ковариации не установлены; границы не названы 95-процентными интервалами. Некоторые локальные величины — результаты обработки измерений, не независимые датчики.

## Почему набор ещё не валидирует текущую HEM

Проверка выполняется для каждой строки, независимо от возможного расхождения модели с измерением. Для существующего производственного замыкания **0 из 12 320 строк** полностью допустимы:

- длина нагрева 7,1 м выходит за текущий предел кипящего адаптера 6 м;
- диапазоны давления/массового потока и геометрия не совпадают с выбранными Biasi и ограниченными кубами CHF;
- часть строк выходит из влажного диапазона качества и допустимого перегрева стенки;
- стационарный проточный опыт не заменяет текущую замкнутую сеть с конечными запасами и не содержит нужных временных историй.

Отчёт перечисляет все причины и все опыты. Если нет сопоставимых строк, ошибка модели остаётся `null`, а не становится «нулевой». Корреляции и их диапазоны не расширены по результату screening. Требуются отдельные обоснованные замыкания/границы, независимый протокол проверки и повторная численная квалификация перед сравнением с этим набором.

## Выполненное сопоставление с акустическими измерениями

Из уже принятой Table1 Alamgir–Kan–Lienhard (1980) использованы четыре опыта. Для двух локальных начальных температур каждого опыта вычислена однофазная скорость звука IF97 и сопоставлена с опубликованной скоростью волны разрежения. Это **четыре независимых опыта и восемь локальных оценок EOS**, а не восемь независимых измерений.

Максимальное абсолютное относительное расхождение — **3,4553%**. Дополнительно сохранены четыре возмущения входов по опубликованным точностям p/T. Это чувствительность к входам, не доверительный интервал. Податливость трубы, осевой профиль температуры и способ экспериментального определения скорости не смоделированы; неопределённость измеренной скорости не установлена. Порог приёмки после просмотра результата не назначен, физическая валидация по этому screening не объявляется. Статья и её изображения в пакет не включены.

## Исполняемые проверки

```bash
python -m atomic_model_hem_assessment screen --output artifacts/hiper_assessment.json
python -m atomic_model_hem_assessment audit artifacts/hiper_assessment.json
python -m atomic_model_hem_assessment reimport /path/to/downloaded-primary.zip
pytest -q tests/test_hem_assessment.py
```

`audit` заново вычисляет отчёт и проверяет digest, исходники, данные и идентичность производственной модели. `reimport` проверяет все исходные workbooks и README, повторяет нормализацию и сравнивает CSV до сжатия; изменение упаковки ZIP не выдаётся за изменение измерений. Существующий выходной файл CLI не перезаписывает.

Python API `envelope_comparison()` сравнивает асимметричные абсолютные интервалы измерения и расчёта, возвращая невязку, расстояние между интервалами и факт пересечения. Пересечение само по себе не повышает физический статус. Нет предположения о независимых гауссовских ошибках.

`assess_target()` и CLI `target` принимают явно заявленный диапазон p/T и требования post-CHF, метастабильности и открытого протока. Непокрытые требования возвращаются отдельными причинами. Покрытие численного диапазона не равно привязке к установке; без конкретного паспорта целевой установки `plant_referenced` остаётся false.

Следующий физический шаг: проточный benchmark с соответствующими замыканиями и явным учётом гравитации/геометрии, затем заранее зафиксированный протокол по независимым опытам. Полная динамическая валидация и калибровка неопределённости остаются открытыми задачами AI-06.06/AI-09.

точечными правилами `.gitattributes`; сжатый HIPER CSV уже хранится как binary.
