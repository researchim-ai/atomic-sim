# Atomic Sim — website

Самостоятельный статический сайт проекта на русском и английском языках.
Node.js 20+, без runtime-зависимостей и внешних сервисов.

## Запуск

Из корня репозитория:

```bash
cd web
npm run dev
```

Откройте `http://127.0.0.1:4173/ru/` или `http://127.0.0.1:4173/en/`.
Раздел физики доступен по `/ru/physics/` и `/en/physics/`.
После изменения `src/` или `public/` выполните `npm run build` в другом
терминале и обновите страницу. `PORT=8080 npm run dev` меняет порт. `HOST` позволяет
явно изменить адрес привязки; по умолчанию доступ разрешён только с localhost.
Установка npm-зависимостей не нужна: проект использует стандартную библиотеку Node.js.

```bash
npm test
npm run build
npm run preview
```

`npm run build` создаёт автономный каталог `dist/`, который можно разместить
на статическом хостинге. Публикация в этой задаче не выполнялась.
Сервер должен отдавать каталоги `/ru/` и `/en/` с `index.html` внутри.
Корневой `/` показывает русскую версию. Пути к ресурсам относительные: сайт
можно разместить и в подкаталоге, сохраняя структуру `dist/`.
`serve.mjs` — локальный preview-сервер, не production web server.

## Содержание и структура

- `src/content.mjs` — оба перевода и исполняемые примеры интерфейсов.
- `src/render.mjs` — семантическая HTML-разметка, метаданные и страницы языков.
- `src/diagram.mjs` — авторская SVG-схема исследовательского PWR.
- `src/physics/content.mjs` — шесть самостоятельных глав на каждом языке,
  обозначения, вопросы для самопроверки и первичные источники.
- `src/physics/render.mjs`, `src/physics/diagram.mjs` — оглавление, страницы глав
  и шесть концептуальных SVG-схем.
- `public/styles.css` — адаптивная типографика, оформление и режим reduced motion.
- `public/app.js` — сценарии схемы, вкладки кода, копирование и мобильное меню.
- `public/physics.css`, `public/physics.js`, `public/physics-math.js` — оформление
  учебного раздела, навигация по статье и два небольших расчётных примера.
- `public/fonts/` — локальные WOFF2 и лицензии Lato / Liberation.
- `scripts/` — сборка и локальный сервер.
- `tests/` — проверки языковых страниц, примеров API и статической сборки.

Основной текст присутствует в HTML до выполнения JavaScript. Переключатель
языка ведёт на соответствующий адрес и сохраняет выбранный раздел страницы.
Сайт не использует аналитику, cookies, внешние шрифты или сторонние API.

Схема Nominal / SCRAM / Pump coastdown поясняет процессы качественно:
это интерактивная иллюстрация, не вычисление модели и не запись измерений.
Возможности и границы моделей сформулированы по исходникам библиотеки;
численная проверка не представлена как экспериментальная валидация.
Кнопки документации ведут к существующим файлам GitHub; сама документация
проекта пока на русском языке, что указано и в английской версии сайта.

## Физика: маршрут чтения

В каждой языковой версии есть оглавление и шесть глав:

1. `physics/neutronics/` — нейтронный баланс, реактивность, запаздывающие нейтроны.
2. `physics/heat-transfer/` — запас энергии, тепловая инерция и теплоотвод.
3. `physics/hydraulics/` — перепад давления, сопротивление и естественная циркуляция.
4. `physics/two-phase/` — насыщение, массовое паросодержание и объёмная доля пара.
5. `physics/plant-dynamics/` — взаимодействие процессов в двухконтурной установке.
6. `physics/verification/` — балансы, сходимость, воспроизводимость и валидация.

Главы ведут от физической причины к уравнению, затем к реализации и её границам.
Есть определения величин с единицами, мысленные эксперименты, вопросы с раскрываемыми
ответами и ссылки на исходники. Переключение языка сохраняет главу и якорь.
Основной материал и ответы доступны без JavaScript.

Интерактивный тепловой баланс использует условную теплоёмкость 20 кДж/К;
пример фазового состава — постоянные условные плотности 900 и 5 кг/м³.
Это учебные иллюстрации уравнений, а не вычисления EOS или запуск библиотеки.
Без JavaScript показаны исходные примеры, ползунки отключены. В текстах явно
разделены общая физика, поддержанные семейства моделей и экспериментальные
свидетельства; учебный раздел не расширяет область квалификации симулятора.

## Проверено в браузере

Русская и английская страницы: desktop и ширины 320, 390, 768, 1024, 1440 px;
горизонтальная прокрутка страницы устранена. Проверены смена языка и раздела,
три режима схемы, пауза анимации, вкладки кода, копирование, мобильное меню и Escape.
В интерфейсах есть focus-visible, ARIA-состояния и клавиатурная навигация вкладок.
Для `prefers-reduced-motion` декоративные анимации отключаются.

Для раздела физики дополнительно проверены **70 сочетаний**: 14 страниц
на ширинах 320, 390, 768, 1024 и 1440 px. Переполнения страницы и ошибок
консоли не обнаружено. Ползунки проверены с клавиатуры, включая чистые фазы
и переход от нагревания к охлаждению. Локальные результаты и превью сохранены
в `artifacts/website-physics/` (служебные артефакты не входят в Git).

`npm test` выполняет шесть проверок: исходные интерфейсы, сборку, полноту
переводов глав, формулы учебных примеров и все внутренние ссылки, якоря,
идентификаторы и ресурсы **18 сгенерированных HTML-страниц**. Внешние ссылки
не проверяются этим обходом; наличие файла в репозитории проверяется отдельно
для ссылок на реализацию и документацию каждой главы.

## English

Run `npm run dev` in `web/`, then open `/en/`. Build with `npm run build` and
serve `dist/` using any static host. No package installation, Python backend,
LLM account or API key is required to run the website. Project documentation
is currently Russian; both landing-page versions are fully written in their
respective languages. The circuit is an explanatory illustration, not live
reactor simulation. See the font license files before redistributing assets.
The bilingual physics guide at `/en/physics/` contains six chapters, original
diagrams, equations, self-check questions and two teaching calculators. Each
chapter distinguishes physical principles from implemented model scope.
